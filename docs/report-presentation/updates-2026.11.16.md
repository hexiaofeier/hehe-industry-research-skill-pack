## 更新内容

1. 完整吸收图表规划：只规划与规划并制作两种用法，覆盖报告、章节、页面和单项数据；保留页面作用、图文组织、选型、数据需求、状态及备选。
2. 新增十种分析图式及共同尺度小多图：哑铃、斜率、热力矩阵、Likert、直方、箱线、累计分布、点区间、区间带、龙卷风敏感性。
3. 补充关系图、执行图、选图及17页分析图表示例。示例全部采用教学模拟数据。
4. 补强图形方案与实际图元对应、类别和数值、屏幕及打印状态、普通图片和独立SVG检查；修复PPT折线、堆积标签、图片导出及负值分类标签位置。
5. 保留完整正文、来源和四种HTML形态、PDF、可编辑PPT路径，按实际对象说明编辑范围。

## 更新安装

替换整个`skills/hehe-report-presentation/`目录并新开会话。独立与组合版来自同一维护源，同名Skill只安装一份。只做规划无需制图依赖；制作、导出和实际编辑验收按交付格式准备环境。
