# PEST 外部环境分析

本 Skill 是盒子原创行业研究 Skill 组合中负责 PEST 外部环境分析的专项 Skill，回答“行业面临哪些重要的政治与政策、经济、社会和技术变化，这些变化如何影响行业，以及对行业内企业意味着什么”。

## 定位

本 Skill 支持三种分析范围：

- **完整 PEST：** 系统检查政治与政策（P）、经济（E）、社会（S）和技术（T），但没有实质影响或证据不足的维度可以简写，不机械凑满。
- **单一维度：** 只分析政策、经济、社会或技术环境中的一个维度。
- **组合维度：** 只分析与问题有关的两个或三个维度及其相互作用。

PEST 始终以行业为分析对象。企业研究调用本 Skill 时，先确定目标企业所在的行业或细分业务，再交付该行业的 PEST 分析。

涉及出海业务时，以目标国家或地区为主要地域分析其 PEST；P 维度同时检查母国与目标市场之间的国际关系、贸易与投资规则及地缘政治风险。

## 启动与工作流程

- **由 `hehe-industry-researcher` 调用：** 收到任务卡和材料索引后直接读取材料并执行，不重新启动路由。
- **用户直接调用本 Skill：** 本 Skill 单独启动，在对话中确认对象、业务范围、地域、时间、研究目的、用户已有口径和材料，再决定是否搜索。

开始执行前读取[专项工作流程](references/专项工作流程.md)，按对应路径接任务、搜索、审核、分析、自审和交付。
交付时读取[PEST 外部环境分析交付模板](references/PEST外部环境分析交付模板.md)。

**完整交付原则。** 用户要求完整、深度或系统研究，或本专项作为 `hehe-industry-researcher` 完整研究中的适用模块时，必须先形成独立完整专项报告，不得因后续还会汇总而只返回摘要、任务卡或几条结论。只有用户明确要求局部／简版，或资料只能支持有限披露时才切换输出模式，并在报告中标明；完整度按交付模板的分析单元和正文目标体量检查，交付前实际计数。

## 核心分析方法

### 1. 明确研究范围

先确认：

`目标行业或细分赛道｜包含与排除｜地域或目标市场｜观察期与判断期｜研究问题｜决策用途｜已有材料`

如果从企业研究进入，用目标企业的相关业务帮助确定行业和地域范围，但分析对象仍是该行业。用户只是希望了解一个大行业时，可以直接做外部环境扫描，不要求预先指定企业或某个经营结果。

### 2. 选择分析维度和因素

先按问题选择维度，再读取对应方法：

| 维度 | 主要分析内容 | 方法文件 |
|---|---|---|
| P 政治与政策 | 政治环境、产业政策、监管、国际关系、跨境规则、执行与退出 | [P｜政治、政策与国际关系分析方法](references/P_政策与监管分析方法.md) |
| E 经济 | 收入、就业、通胀、利率、汇率、融资、投资、成本与预算 | [E｜经济环境分析方法](references/E_经济环境分析方法.md) |
| S 社会 | 人口、家庭、迁移、教育、职业、技能、时间分配、规范与行为 | [S｜社会环境分析方法](references/S_社会环境分析方法.md) |
| T 技术 | 技术成熟度、性能成本、基础设施、标准、人才供给、替代与采用 | [T｜技术环境分析方法](references/T_技术环境分析方法.md) |

完整 PEST 检查四个维度；单一或组合任务只读取所需 reference。优先保留符合以下条件的因素：

1. 属于行业外部环境，而不是企业内部决策；
2. 可能实质影响行业需求、供给、价格、成本、投资、融资、准入、技术采用、竞争结构或区域布局；
3. 处于本次观察期或判断期内；
4. 能查清基本状态、适用范围和依据。

建立因素候选表：

`因素｜P/E/S/T｜当前状态或变化｜适用范围｜可能影响的行业环节｜重要性｜证据状态｜纳入/观察/排除｜理由`

这张表用于筛选因素，不要求最后平均分析四个维度。

### 3. 分析因素如何影响行业

对每个重要因素说明：

`外部因素及状态 → 影响行业的方式 → 已发生或可能发生的行业变化 → 受影响的企业类型 → 影响方向、强度和时间 → 依据与不确定性`

行业变化可以表现为需求、供给、价格、成本、投资与融资、准入与退出、竞争结构、技术采用、区域布局或供应链变化。影响方向使用：`正向｜负向｜双向｜暂不明确`。

同一因素可能利好一类企业、同时压制另一类企业。说明哪些企业更可能受益或受损，以及原因；不把外部因素直接写成对整个行业统一的“利好”或“利空”。

外部因素已经出现，不等于行业影响已经兑现。能找到销量、价格、成本、投资、融资、准入、退出、采用、产能或供应链等现实信号时，用它们核对判断；暂时没有时，明确写成可能影响或待观察。

### 4. 形成综合判断

综合 P、E、S、T 的结果，回答：

- 当前最重要的外部机会和风险是什么；
- 哪些因素会相互增强、抵消或前后传导；
- 哪些行业环节和企业类型受到的影响更大；
- 哪些影响已经出现，哪些仍取决于未来条件；
- 后续应观察哪些信号。

使用汇总表：

`关键因素｜所属维度｜对行业的影响｜主要受影响企业类型｜方向｜强度｜时间｜当前依据｜不确定性或观察信号`

方向和强度必须附理由。存在资料矛盾、无法区分其他原因或未来条件尚未发生时，保留不确定性，不给伪精确结论。只有任务明确要求预测或压力测试时，才增加情景分析。

## 验收清单

- [ ] 已明确行业或细分赛道、地域、时间和分析范围。
- [ ] 已说明本次做完整 PEST、单一维度还是组合维度，没有机械凑满四项。
- [ ] 企业研究调用时，交付的是目标企业所在行业的 PEST，没有改写成公司画像。
- [ ] 出海课题以目标国家或地区为主要 PEST 环境，并检查国际关系和跨境规则。
- [ ] 每个核心因素的状态、适用范围、行业影响路径、方向、时间和依据清楚。
- [ ] 已说明行业内哪些企业类型可能受益或受损，没有把影响方向写成全行业统一结论。
- [ ] 多因素共同作用时已检查增强、抵消、共同原因和重复解释。
- [ ] 政策目标、经济指标、社会信号或技术进展没有直接冒充行业效果。
- [ ] 缺口、矛盾、补证结果、限制和失效条件已经说明。
