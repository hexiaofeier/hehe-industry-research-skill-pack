# P｜政治、政策与国际关系分析方法

P 维度分析与目标行业有关的政治环境、产业政策、监管和国际关系。重点不是罗列文件，而是查清外部因素目前处于什么状态、适用于谁，以及它会怎样影响行业和行业内企业。

## 1. 找出重要的 P 因素

按课题从三类因素中选择，不要求全部覆盖：

| 类型 | 常见内容 |
|---|---|
| 政治与治理环境 | 政府发展重点、治理稳定性、行政调整、公共投资与采购方向 |
| 政策与监管 | 产业规划、准入、许可、标准、补贴、税收、环保、安全、劳动和数据监管 |
| 国际关系与跨境规则 | 双边或多边关系、关税、贸易壁垒、制裁、出口管制、投资审查和本地化要求 |

优先保留同时符合以下条件的因素：

- 与目标行业、地域和判断期有关；
- 可能改变需求、供给、成本、准入、投资、技术、供应链或竞争格局；
- 有可以定位的正式材料、公开事件或执行记录。

建立简表：

`因素｜类型｜涉及地域｜当前变化｜可能影响的行业环节｜为什么值得分析｜资料位置`

## 2. 查清当前状态和适用范围

对政策、法规或监管规则，至少确认：

`文件或条款｜当前状态｜发布日期与生效时间｜适用地域和对象｜主要要求或支持｜执行主体｜现行版本｜原文位置`

当前状态按原文填写，例如：

`讨论或表态｜草案或征求意见｜已发布待生效｜已生效｜正在执行｜修订、暂停或退出`

不要求政策依次经过所有状态，但必须区分：

- 政策目标不等于正式规则；
- 正式发布不等于已经生效；
- 已经生效不等于已经执行；
- 已有执行动作不等于行业效果已经发生。

复杂政策再按需分清谁制定、谁出资、谁执行、谁监管、谁承担义务、谁可能受益；简单政策不必绘制完整主体图。

分析政治事件或国际关系时，不套用政策文件字段。记录事件发生了什么、涉及哪些国家或地区、当前状态、时间、影响渠道和可靠来源。

## 3. 判断对行业和企业的影响

先判断因素通过什么方式影响行业，常见方式包括：

- 创造、扩大、压缩或转移需求；
- 改变行业准入、许可、标准和可参与主体；
- 改变税费、合规、原料、用工、物流或其他成本；
- 改变融资条件、公共投入、补贴、采购和投资意愿；
- 改变进出口、技术获取、数据流动、供应链和区域布局。

每个重要因素使用同一条分析链：

`政治或政策因素 → 直接改变了什么 → 行业怎样反应 → 哪类企业更可能受益或受损 → 影响方向、强度和时间 → 当前证据与不确定性`

影响方向使用：`正向｜负向｜双向｜暂不明确`。同一因素对不同环节或企业类型可能方向相反，不能直接写成对整个行业统一的“利好”或“利空”。

判断影响是否已经发生时，按题查找预算、拨付、审批、采购、执法、处罚、订单、价格、销量、成本、投资、产能、退出或供应链变化等信号：

- 只有政策目标或文件：说明政策方向及可能影响；
- 已有执行记录但缺少行业数据：说明已经执行，行业影响待观察；
- 已有行业变化：说明时间和对应关系，同时检查宏观周期、技术变化或企业策略等其他解释；
- 资料互相冲突：保留分歧并降低结论强度，不强行选边。

## 4. 处理特殊情况

以下内容只在课题相关时使用。

### 出海或跨境业务

以目标国家或地区自身的 PEST 为主要环境。P 维度另外检查：

- 母国与目标市场的双边关系及相关多边机制；
- 关税、配额、贸易救济、制裁、出口管制和实体清单；
- 外资准入、投资审查、政府采购、本地化和所有权要求；
- 数据跨境、隐私、安全、技术标准、认证和知识产权；
- 关键原料、设备、物流、结算、人员流动和供应链安全。

政治表态、外交事件、拟议法案、已生效规则和实际执法必须分开。单一事件不能直接证明整个目标市场已经开放或关闭。

### 政策依赖与退出

行业明显依赖补贴、政府采购、牌照、税收优惠或其他政策支持时，比较政策延续、收紧和退出可能造成的变化，重点判断需求、成本、准入或投资中哪个环节先受影响。非政策依赖行业不强制做此项。

### 多项政策共同作用

多项政策影响同一行业结果时，说明它们是相互增强、抵消、前后衔接还是内容重复。无法拆分单项贡献时，只判断组合影响，不制作伪精确评分。

## 验收清单

- [ ] 只纳入了与目标行业、地域和时间相关的重要因素。
- [ ] 政策或事件的状态、适用范围、时间和来源清楚。
- [ ] 出海课题以目标市场 PEST 为主，并检查国际关系和跨境规则。
- [ ] 已说明因素怎样影响行业，以及哪些企业类型可能受益或受损。
- [ ] 政策目标、正式发布、实际执行和行业效果没有混写。
- [ ] 影响方向有依据，矛盾、其他解释和不确定性已经保留。

P 维度的交付并入统一的 [PEST 外部环境分析交付模板](PEST外部环境分析交付模板.md)，不单独建立另一套报告结构。
