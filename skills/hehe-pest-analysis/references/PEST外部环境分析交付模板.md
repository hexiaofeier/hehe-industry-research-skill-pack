# PEST 外部环境分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告。用户明确不落文件时，在对话中按第二节结构完整交付。

Excel 或 CSV 只在第三节所列条件触发时生成；没有复算、持续更新或数据交换需要时，不另附表格文件。

## 二、Markdown 主报告

PEST 始终以行业为报告对象。企业研究调用时，研究目标企业所在行业或细分业务的外部环境，不另设企业版。涉及出海时，以目标国家或地区为主要环境，并在 P 维度分析国际关系和跨境经营规则。

- **完整 PEST：** 分析 P、E、S、T 四个维度；没有实质影响或证据不足的维度可以简写。
- **单一或组合维度：** 只分析用户要求或与问题直接相关的维度。

报告按以下顺序展开：

1. **核心摘要**：先给当前最重要的外部机会、风险、影响方向和时间，再列三至六项关键因素及其现实信号。
2. **研究范围**：目标行业或细分赛道、包含与排除、地域、时间、研究问题、分析维度、判断截止日和使用目的。
3. **各维度核心分析**：
   - P：政治环境、政策与监管、国际关系、跨境规则、执行与退出；
   - E：经济变量、口径、传导、时滞与现实经营信号；
   - S：社会结构或行为变化、目标群体、机制、分群与现实信号；
   - T：技术成熟度、性能成本、部署条件、采用、替代与经营影响；
4. **行业影响与企业类型差异**：各因素如何影响行业，哪些企业类型可能受益或受损，以及影响方向、强度和时间。
5. **因素交互与综合判断**：说明多个因素之间的增强、抵消或前后传导，并形成方向明确的条件化判断。
6. **观察信号与翻转条件**：列出后续观察指标、未兑现影响、替代解释及会改变判断的事件。
7. **其他说明、附录与待补证内容（按需）**：放详细因素表、口径说明、来源明细、资料限制和补证任务。

完整任务按上述顺序成文；局部问题可省略不适用的主体章节，但核心摘要和研究范围仍在前两节。完整 PEST 按重要性分配篇幅，不平均分成四块。

## 三、其他交付物

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 因素、政策版本、经济时间序列、社会分群、技术路线或情景较多，需要筛选、复算或持续更新 | `.xlsx` | 范围与口径、因素台账、时间/版本、传导与分群、情景或观察指标、来源与状态 |
| 只需交换一张已整理的因素、政策或信号长表，且没有公式 | `.csv` | 因素 ID、维度、对象、地域、时期、状态、影响路径、来源和限制 |
| 因素较少，计算和比较可在主报告中完整呈现 | 不生成附件 | Markdown 保留关键因素表、传导依据和观察信号 |

图形、PPT 和展示版只在用户明确要求时生成，不属于默认交付。
同一数据表需要公式时使用 Excel；只交换无公式长表时使用 CSV，不同时生成两份重复附件。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由时使用任务卡指定位置；单独启动时默认保存到当前任务工作文件夹；用户指定位置时按其要求保存。
- 完整或组合维度报告：`YYYYMMDD_研究主题_PEST外部环境分析.md`。
- 单一维度报告：`YYYYMMDD_研究主题_政策环境分析.md`、`经济环境分析.md`、`社会环境分析.md`或`技术环境分析.md`。
- 附件：`YYYYMMDD_研究主题_PEST外部环境分析_附件名称.扩展名`，附件名称写具体用途。
- 用户或项目另有命名规范时优先遵守。

## 五、信息缺口

出现以下情况时，标明受影响判断并定向补证：

- 核心因素缺少原文、定义、对象、时间、地域、分母或版本；
- 政策发布、生效、执行、覆盖和经营效果互相混写；
- 经济或社会指标与目标市场的对象、分群或时间不一致；
- 技术进展只有论文、演示或发布信息，缺少部署、采用或经营验证；
- 外部因素和行业现实信号存在无法解释的冲突；
- 关键结论只有媒体概述、单一案例或同期相关性。

补证任务使用：

`缺口主张/因素｜所需对象与口径｜地域与时间｜希望获得的原文或现实证据｜可接受替代｜不可接受替代｜影响的传导环节｜补到什么程度即可继续`

不影响主问题的缺口保留在对应判断中；关键传导无法成立时输出“暂不判断”。

## 六、交付条件与交付前检查

本题所选维度、重要因素、传导路径和行业影响已经回答，新增一般材料不会改变核心判断时即可交付。交付前检查：

- 核心摘要先给机会、风险与影响，研究范围单独成节；
- P、E、S、T 只保留与研究问题相关的因素，没有平均分配篇幅；
- 核心因素的状态、对象、地域、时间、口径和来源可追溯；
- 政策发布、生效、执行和经营结果没有混写，未兑现影响标为可能或待观察；
- 关键影响已与行业现实信号核对，因素交互、替代解释和失效条件已处理；
- 企业研究仍交付行业 PEST，企业类型差异没有扩成公司画像；
- 报告与附件字段、数值和版本一致，实际文件清单和链接可打开。
