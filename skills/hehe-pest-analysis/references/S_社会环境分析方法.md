# S｜社会环境分析方法

S 维度分析人口与社会结构、生活方式、规范和行为变化怎样影响目标行业的客户基础、需求场景、预算分配、劳动力与技能供给，并说明行业内哪些企业类型受到的影响更明显。公开讨论可以帮助发现态度和需求，但不能自动代表总体人群。

## 常见因素

- 人口规模、出生与死亡、年龄结构和生命周期；
- 家庭规模、婚育、照护、居住与代际关系；
- 城镇化、人口迁移、区域与城市层级分布；
- 教育程度、职业结构、劳动参与和技能供给；
- 工作、学习、娱乐、通勤和照护的时间分配；
- 消费观念、健康与安全意识、隐私态度、社会规范和信任；
- 不同群体的采用、拒绝、替代、闲聊、潜在需求和非消费行为。

## 分析要点

1. 先明确受影响的人群、家庭、劳动者、企业采购者或其他社会角色，不用“消费者”笼统代替。
2. 每个核心因素登记：`定义｜人群/样本｜地域｜时间｜分母｜调查或统计方法｜来源与版本｜证据状态`。
3. 区分人口总量与分布、存量与流量、人口结构与实际行为、公开表态与真实采用。
4. 年龄效应、出生队列效应、生命周期效应、收入差异和时期效应尽量分开；无法拆分时只列为待验证解释。
5. 社会态度必须说明材料从哪里来、谁更容易发声、谁可能沉默，以及样本选择机制。单个平台的帖子、点赞或评论只说明该平台可见样本。
6. 将社会变化连接到具体机制，例如家庭预算、可支配时间、技能供给、使用门槛、信任、规范压力或采购偏好，再核对销量、使用、续费、招聘、供给或价格等现实结果。

## 常见误区

- 用“某代人天然偏好”替代可验证变量；
- 少量访谈、帖子或媒体故事外推总体；
- 人口增加直接等于需求增加，忽略收入、场景、支付者和替代品；
- 社会关注度、搜索热度或互动量直接等于购买和持续使用；
- 全国或全体平均掩盖地区、年龄、职业、家庭和收入分群。

## S 维度交付要点

`社会因素与状态｜对象和分母｜受影响群体｜对行业的影响路径｜受影响的企业类型｜方向与时间｜行业现实信号｜反例/沉默样本｜不确定性｜证据状态`

需要比较群体时增加分群矩阵；材料只能支持定性观察时明确写明，不强行量化。
