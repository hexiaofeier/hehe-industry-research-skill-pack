# 图表规划

本模块把研究问题、页面作用、图文组织、选图和数据需求安排在同一套流程中。可用于报告、章节、单页、单项指标、单个数据点或一组数据；下拉报告按主题模块处理，不必先分页。

## 选择用法与规划范围

| 用法 | 可接收的材料 | 本次交付 |
|---|---|---|
| 只规划 | 研究框架、章节任务、文稿、数据表、已有图表或部分素材，任一项或多项 | 与请求规模相称的图表方案、布局建议、数据缺口与备选 |
| 规划并制作 | 上述材料及本次需要制作的内容、读者、用途和格式要求 | 先完成必要规划，再按本 Skill 制作和核验实际交付物 |

只规划可在正式写作或制作之前进行，直接依据现有材料提出方案。制作环境、Python、浏览器及导出软件检查安排在实际制作阶段。

先明确本次规划覆盖整份报告、一个章节、一个页面，还是单项指标、单个数据点或一组数据。已有合格方案直接接续，已有素材先判断能否承担本次表达任务。沿用用户确认的研究框架、结论和数据口径；规划负责找出适合的表达关系与证据缺口。若结论与材料存在冲突，指出具体差异及影响，继续处理不受影响的内容。

## 1. 先判断页面作用

选图前先说明：这页或模块要让读者理解什么，它在所在章节中承担什么作用，图表、分析和页面收尾如何配合。按主要任务选择以下作用：

| 页面作用 | 要解决的问题 | 图文配合 |
|---|---|---|
| 论点页 | 本页提出什么判断，判断适用于什么对象和范围 | 用主要证据支持主张，正文交代依据与条件 |
| 证据页 | 哪些材料能够支持或检验已有判断 | 图表呈现证据，解释说明证据与判断之间的关系 |
| 对比页 | 对象之间在共同维度上有何差异，差异说明什么 | 对齐对象、维度和口径，解释差异及含义 |
| 机制页 | 哪些条件、过程或主体关系导致或解释结果 | 画出材料支持的链条或结构，完整解释靠近对应环节 |
| 含义页 | 已有发现对行业、企业、用户或决策意味着什么 | 把发现与影响相连，保留成立条件 |
| 行动页 | 根据已有发现应采取什么行动，依据是什么 | 对应呈现建议、触发条件和执行事项；责任与时间以材料为准 |

页面作用尚不清楚时，先从现有章节任务和材料中写出“本页要回答的问题”和“现有证据能支持的内容”，再确定作用。只有必须改变研究目标或框架才能继续时，才提交用户决策。

## 2. 选择图文组织方法

规划常见论证页时，优先从以下三种方法考虑证据、解释和落点的配合，再由具体关系确定布局：

| 方法 | 组织顺序 | 使用场景 |
|---|---|---|
| A：单证据页 | 一个关键图表 → 围绕证据展开解释 → 对应含义 | 一个主要证据足以承担本页任务 |
| B：双证据对比页 | 证据 1 与证据 2 → 桥接分析 → 结论 | 两组证据需要比较、互相补充或共同支持一个判断 |
| C：机制解释页 | 原因链条 → 信号例子 → 商业影响 → 建议或待验证点 | 需要解释结果为何形成，以及可能影响什么 |

A、B、C 说明论述关系，已有合适的组织方式可直接沿用，连续论证等内容也可按实际阅读需要安排。解释的段落数、句数和长度由完整内容决定。页面可以安排一个主要视觉重点及必要的辅助证据；图文比例、分栏或上下阅读方式随内容调整。容量不足先调整布局，再按完整子问题拆页；同主题且合并后可读的内容可以合并。

机制页只画材料支持的关系。信号或案例用于说明链条中的具体环节；尚待验证的因果关系明确列为待验证点。

## 3. 按表达关系选图

先明确需要表达的关系，再检查现有数据能否支持。七类基础选型如下；差值、分布、区间、分组矩阵、态度结构、敏感性与小多图，继续按[分析图表选型](分析图表选型.md)选择。

| 表达关系 | 推荐图式 | 选用依据与必需材料 |
|---|---|---|
| 趋势变化 | 折线图 / 柱线双轴图 | 连续、同口径的时间序列用折线；同时观察规模与增长率等不同单位指标时可用柱线双轴，两轴分别标明指标、单位和刻度，说明它们为何需要共同观察 |
| 规模比较 | 横向条形图 / 排名表 | 同期、同口径的类别或对象数值；条形便于看差距，排名表便于查名次与精确值。条形从零线起算 |
| 结构占比 | 环形图 / 堆积条形图 | 各部分具有共同分母且分类关系清楚；环形适合展示一个整体的构成，堆积条形适合比较多个对象或时点的构成。说明总量、单位和分母 |
| 关联关系 | 散点图 / 四象限图 | 散点需要同一观测对象的成对指标；四象限还需说明坐标含义与分界依据。描述关联时不把位置或相关性直接写成因果 |
| 结构关系 | 产业链图 / 树状图 / 流程图 | 产业链表达上下游与依赖，树状图表达层级或包含，流程图表达阶段与衔接；节点、连线和方向均来自材料 |
| 地理分布 | 热力地图 / 气泡地图 | 使用可匹配地域的数值或分类，说明地域范围、时间、单位及行政区口径；区域填色适合观察区域差异，气泡大小适合表达地点或区域的数量 |
| 竞争定位 | 四象限图 / 能力矩阵 | 四象限需有可解释的两条评价轴与定位依据；能力矩阵需有统一维度和比较证据。位置、评分和优劣判断均能回到材料 |

其他已确认的关系继续使用 [版式与组件选用.md](版式与组件选用.md) 中的资金与数据流、条件分支、分支汇合、推导、泳道、甘特、旅程、瀑布和计算关系图等方法。七类选型用于覆盖常见规划任务，与现有图式共同按内容选择。

需要精确查阅或按共同维度逐项比较时用表格；需要展开定义、条件和连续推理时保留正文。材料中的关系与论证用途决定选图，不能为了使用已有数据或现成组件勉强配图。

## 4. 同步规划标题、解释、数据和布局

每页或模块一并考虑核心观点、推荐图表、图表标题、数据需求、数据状态、备选方案、布局以及页面最终落到的结论或含义。分析解释说明图中哪些差异、变化或关系支持核心观点，页面收尾承接解释。

已有证据支持判断时，图表标题尽量写成“数据对象与范围 + 核心判断”，让读者看到图表要说明什么。计划书、待采集数据和待验证主张应准确标明计划事项或待验证内容，随数据核实后确定结论性标题。

按 [商业报告视觉编排.md](商业报告视觉编排.md) 确定主要视觉重点、阅读顺序和完整解释的位置，再按 [版式与组件选用.md](版式与组件选用.md) 选择全页、左图右文、上图下文、多图并列或其他合适布局。解释沿用图中对象与顺序，来源、单位、基数及有效条件靠近相关图表。

### 数据需求与四种状态

数据需求写清所需指标或字段、观测对象、时间、地域、单位、比较口径及拟从何处获取；已有数据也要核对它是否真正支持所选图式与观点。

| 数据状态 | 判定 | 规划中的处理 |
|---|---|---|
| 已有 | 已拿到本次图表需要的数据或材料 | 核对来源、口径与适用结论，列出仍需核实的具体问题 |
| 待采集 | 所需内容尚未取得，存在明确的采集对象或来源路径 | 写清待采集字段、来源方向及该数据用于检验什么 |
| 难获取 | 已识别获取障碍或可得性有限 | 说明缺口对图表及判断的影响，给出可行替代 |
| 无法获取 | 本次条件下无法取得所需数据 | 换用能由现有证据支持的图式或表达，并说明保留与无法回答的问题 |

备选方案要对应具体缺口：缺少完整时间序列可改为已有时点比较；缺少比例或共同分母时可呈现有依据的定性结构；只有部分案例时可比较案例特征，并标明案例范围。替代证据能支持到什么程度，应与核心观点和标题保持一致。

任务包含资料补充时，先明确待证主张和所需证据，再使用当前可用的搜索、采集与资料核对方法补齐；只规划时可直接交付数据需求与备选。需要扩写正文时可由已安装的 `hehe-report-writing` 接续，也可直接依据规划撰写完整解释。

### 核心图表的数据合同

为每张核心图表附最小数据合同：

`指标｜对象/分母｜时间｜地域｜单位｜来源或证据台账键｜允许表达的结论`

来源应能回到原始材料，或回到已有证据台账中的对应记录。时间说明统计期间或时点；对象和分母说明数值覆盖谁、比例除以什么；允许表达的结论限定图表能够支持的判断。

同图混用 GMV、收入、融资、用户、合同或回款时，必须拆图或明确不可比较。案例样本比例必须在标题或脚注写出样本分母。分母不明或口径冲突尚未解决的数据，不用于大数字页。

## 5. 按请求规模交付规划

整份报告或章节规划，按现有章节和主题顺序组织，说明各页或模块的作用与衔接。单页、单项指标或一组数据的问题，直接给出适合的图式、理由、数据条件、备选和布局；篇幅随问题规模确定。

以下完整模板可用于逐页规划；保留各字段承接的内容，具体回答可以用表格或连贯文字组织：

```markdown
## [章节名称] 图表规划

### 第X页：[页面主题]

页面角色：[论点页 / 证据页 / 对比页 / 机制页 / 含义页 / 行动页]
页面模式：[A：单证据 / B：双证据对比 / C：机制解释，或说明其他合适的组织方式]
核心观点：[这页要让读者记住什么]
推荐图表：[图表类型及选用理由]
图表标题：[数据对象与范围 + 有证据支持的判断，或准确的计划/待验证主题]
数据需求：[需要什么数据或字段，从哪里获取]
数据状态：[已有 / 待采集 / 难获取 / 无法获取]
备选方案：[数据不全时如何替代，替代方案能支持什么]
布局建议：[全页 / 左图右文 / 上图下文 / 多图并列，或其他合适布局]
页面收尾：[这页最终落到什么含义或建议]
数据合同：[指标｜对象/分母｜时间｜地域｜单位｜来源或证据台账键｜允许表达的结论]
```

下拉报告将“第X页”替换为主题模块；单项指标规划以指标或数据组名称标识即可。已有明确的章节和页面安排直接沿用。

## 6. 进入制作与检查

只规划的交付在方案、数据需求和备选完整后结束。规划并制作时，将主要关系、具体图式、对应对象和完整解释的位置写入页面源的 `visual_plan`，字段及实际图形要求见 [图形优先与生成检查.md](图形优先与生成检查.md)。随后进入本 Skill 的制作、导出和实际页面核验流程。

规划可以推荐全部适用图式。实际制作时按所选图式落实图形；现成组件未覆盖的图式使用专用 SVG、HTML/CSS 或相应可编辑对象实现。生成检查覆盖方案与实际对象的一致性，选图是否恰当、结论是否成立及内容是否完整仍需对照原材料审阅。

交付前按以下常见错误逐项检查：

- 先看到数据，再勉强找图表：回到本页要回答的问题，检查所选数据与图式是否服务核心观点。
- 图表能看但结论不清：说明图中证据支持什么，页面收尾与证据保持一致。
- 一页塞太多维度：确定主要比较轴和视觉重点，调整布局；确有多个完整子问题时再拆页。
- 图表和文字各说各话：统一对象、顺序与口径，让解释直接对应图中差异或关系。
- 图表标题只有描述，没有判断：对已有证据支持的研究结论补足判断；计划和待验证事项按实际状态命名。
- 图表脚注不能回到来源、时间、地域、单位和口径：补齐数据合同，检查分母及口径冲突，纠正不合条件的大数字表达。
