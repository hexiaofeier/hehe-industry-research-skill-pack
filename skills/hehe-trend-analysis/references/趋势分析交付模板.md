# 趋势分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告。用户明确不落文件时，在对话中按第二节结构完整交付。

Excel 或 CSV 只在第三节所列条件触发时生成。趋势图、PPT 和视觉版只在用户明确要求时制作。

## 二、Markdown 主报告

### 完整度与展开要求

先确定输出模式：

- **完整专项报告：** 用户要求完整、深度或系统研究，或者本专项被纳入 `hehe-industry-researcher` 的完整研究时使用。必须覆盖本模板列出的适用主体章节。
- **局部专项答复：** 只在用户明确询问一个局部问题或明确要求简版时使用，只展开与该问题直接相关的章节。
- **有限披露报告：** 只在关键资料确实不足时使用；仍需充分分析现有证据能够支持的内容，不能只交缺口清单。

完整报告的核心主体章节不能只有标题、事实清单、新闻罗列或一张没有解释的表。每项主要结论应有相称的证据或计算，并解释关键机制、差异及其含义；成立条件或翻转点按其对判断的实际影响展开。表格之后解释最重要的差异和意义。

**读者导向的写作与删减**

- 正文围绕结论、证据、推理及其含义展开。删掉后不影响读者理解和判断的解释，直接删除。
- 会改变结论的口径、假设、条件和风险融入相应判断；同一事项集中说明一次，保留原有判断强度。
- 内部审核、资料取舍和研究执行过程留在底稿；正文只呈现其对结论的实质影响。
- 摘要、标题、正文、表格、图注及图内脚注统一执行；任何篇幅下均适用，不为字数目标补回无效解释。

**完整模式正文目标体量：** 完整趋势扫描一般为 5,000—8,000 汉字；单项趋势验证一般为 3,500—6,000 汉字。 这是完整度检查线，不是写作配额；交付前必须实际统计正文字符数并记录结果。统计只包括推进本题结论的分析；来源清单、原文摘录、附录长表、方法或交付说明、验收记录、通用边界和更新流程不计入，也不得跨专项复制或批量套用同一句式后只替换变量。低于下限时先逐项复查并补足被压缩的核心能力；实质分析已经完整且差距不超过下限 10% 时，可记录偏差后交付，不得为贴线补字。差距超过 10% 且不属于局部或有限披露模式时，不得作为完整专项报告交付。超过上限时检查重复结论和同义改写。


交付物应完整体现趋势分析链，不能只给新闻列表、阶段标签或预测。完整任务按以下顺序展开：

1. **核心摘要**：一句话回答趋势是否成立、处于什么状态及主要影响，再列三至六项关键变化、证据、限制和转折条件。
2. **研究范围**：趋势扫描或单项验证，研究对象、地域、观察窗口、判断时点、推演窗口、比较基准及必要的包含与排除。
3. **证据与变化**：候选变化、主要信号、测量角度、支持与约束，以及供给、需求、经营和结构证据。
4. **趋势判断**：方向、速度、持续性、覆盖、分化、趋势性质；适用时再给阶段与转折条件。
5. **机制与影响**：关键变量、机制链、行业或经营影响；涉及目标企业时补充企业影响与相对位置。
6. **综合结论与跟踪**：条件化结论、替代解释、领先/同步/滞后信号、证伪条件、不确定性和翻转条件，不重复摘要。
7. **其他说明、附录与待补证内容（按需）**：放完整信号台账、阶段转折卡、趋势交互表、情景表、版本差异表、来源及补证任务。

信号台账字段统一为：

```text
趋势主张｜范围与时间｜方向/状态/阶段｜转折触发｜支持/约束｜关键变量｜机制链｜行业/市场/经营影响｜信号版本/有效期｜领先/同步/滞后信号｜趋势交互｜基准/反事实｜成立条件｜证伪信号｜证据状态｜版本变化｜待补缺口
```

## 三、其他交付物

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 信号需要跨来源、跨窗口或跨版本持续更新，或情景与指标需要复算 | `.xlsx` | 范围与时间、信号池、阶段/状态、机制与影响、版本差异、跟踪与补证；输入、公式和状态分开 |
| 只需交换一张已整理的信号长表，且没有公式 | `.csv` | 信号 ID、发生期、披露期、取得日、版本、有效期、支持/约束侧、阶段映射、证据状态和失效条件 |
| 一次性趋势判断且主报告表格足以承载信号 | 不生成附件 | Markdown 保留核心信号、版本、条件和来源 |
| 用户明确要求趋势图 | 可编辑图源及展示图 | 图中的时间、阶段、信号和范围与报告一致；图形不代替趋势判断 |

互动热度和孤立新闻不得自动加权成趋势强度。完整信号台账、阶段转折卡、趋势交互表、情景表和版本差异表按上述触发条件放入报告或附件，不机械拆成多个文件。
同一数据表需要公式时使用 Excel；只交换无公式长表时使用 CSV，不同时生成两份重复附件。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由时使用任务卡指定位置；单独启动时默认保存到当前任务工作文件夹；用户指定位置时按其要求保存。
- 主报告：`YYYYMMDD_研究主题_行业趋势分析.md`。
- 附件：`YYYYMMDD_研究主题_行业趋势分析_附件名称.扩展名`，附件名称写具体用途，如`信号台账`、`趋势时间线`。
- 研究主题写清行业或细分对象，企业研究加企业名；版本号按需添加。用户或项目另有命名规范时优先遵守。

## 五、信息缺口

只有缺口会改变趋势是否成立、方向、阶段、覆盖或影响判断时，才建立补证任务：

`待补主张｜缺口为何会改变趋势判断｜对象/地域｜发生期与披露截止日｜所需证据形态｜建议检索方向｜可接受替代证据｜补充后更新哪一部分`

新增材料进入新版本；未解决缺口只限制受影响的趋势判断。

## 六、交付条件与交付前检查

趋势范围、主要变化、判断状态、机制影响和跟踪条件已经闭合，新增一般信号不会改变核心判断时即可交付。交付前检查：

- 核心摘要先给趋势结论，研究范围单独成节；
- 观察窗口、判断时点、推演窗口和比较基准明确；
- 供给、需求、交易、经营和结构信号没有互相替代，发生期与披露期已区分；
- 趋势方向、速度、持续性、覆盖和分化有相应证据，阶段只在适用时判断；
- 机制能连接可观察结果，替代解释、证伪信号和翻转条件已说明；
- 报告与附件的信号 ID、版本、状态和结论一致，文件可打开。

## 七、其他注意事项与专项要求

### 可复用结果

交付趋势对象、阶段、核心变量、机制链、时间信号、需求/价格/供给的条件性假设、触发事件、情景与证伪边界。任何复用结果都不得反向证明本轮事实或阶段判断；新增冲突进入下一版本补证。
