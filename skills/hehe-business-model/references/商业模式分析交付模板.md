# 商业模式分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告。用户明确不落文件时，在对话中按第二节结构交付完整内容。

Excel 或 CSV 只在第三节所列条件触发时生成；没有触发条件时，交付物只有 Markdown 主报告。

## 二、Markdown 主报告

### 完整度与展开要求

先确定输出模式：

- **完整专项报告：** 用户要求完整、深度或系统研究，或者本专项被纳入 `hehe-industry-researcher` 的完整研究时使用。必须覆盖本模板列出的适用主体章节。
- **局部专项答复：** 只在用户明确询问一个局部问题或明确要求简版时使用，只展开与该问题直接相关的章节。
- **有限披露报告：** 只在关键资料确实不足时使用；仍需充分分析现有证据能够支持的内容，不能只交缺口清单。

完整报告的核心主体章节不能只有标题、事实清单、新闻罗列或一张没有解释的表。每项主要结论应有相称的证据或计算，并解释关键机制、差异及其含义；成立条件或翻转点按其对判断的实际影响展开。表格之后解释最重要的差异和意义。

**读者导向的写作与删减**

- 正文围绕结论、证据、推理及其含义展开。删掉后不影响读者理解和判断的解释，直接删除。
- 会改变结论的口径、假设、条件和风险融入相应判断；同一事项集中说明一次，保留原有判断强度。
- 内部审核、资料取舍和研究执行过程留在底稿；正文只呈现其对结论的实质影响。
- 摘要、标题、正文、表格、图注及图内脚注统一执行；任何篇幅下均适用，不为字数目标补回无效解释。

**完整模式正文目标体量：** 完整行业或企业单线分析一般为 5,000—8,000 汉字；行业与企业合并分析一般为 7,000—13,000 汉字。 这是完整度检查线，不是写作配额；交付前必须实际统计正文字符数并记录结果。统计只包括推进本题结论的分析；来源清单、原文摘录、附录长表、方法或交付说明、验收记录、通用边界和更新流程不计入，也不得跨专项复制或批量套用同一句式后只替换变量。低于下限时先逐项复查并补足被压缩的核心能力；实质分析已经完整且差距不超过下限 10% 时，可记录偏差后交付，不得为贴线补字。差距超过 10% 且不属于局部或有限披露模式时，不得作为完整专项报告交付。超过上限时检查重复结论和同义改写。


默认交付一份可直接阅读的 Markdown 专项报告。
行业与企业任务分别组织。报告先给结论，再解释经营机制与证据，表格帮助比较，不以填表代替分析。字段按问题选用，缺数据写明未知及其影响，不为填满模板编数。
同时研究行业与企业时，可在一份报告中分两部分阐述，复用已有模式说明，不强制重复交付相同附件。

### 行业商业模式分析报告

1. **核心摘要**：先回答行业主要有哪些商业模式、关键差异、当前变化和核心判断；每项给出最关键的机制或证据。
2. **研究范围**：对象、业务范围、地域、时期、研究目的及必要的包含与排除。
3. **主要模式与代表企业**：说明分类依据，整理各模式做什么、谁付款、代表企业和常见程度的依据；区分成熟做法、局部做法与新尝试。
4. **各模式怎样运转**：客户购买理由、接单与交付、四流、收费、主要成本和现金特点；有数据时补单位经济与必要情境。
5. **模式组合与横向比较**：引流、盈利、留存、资源共享、交叉补贴与蚕食；比较适用条件和经济特点，解释为何共存。
6. **演变、扩张与趋势**：过去到现在的变化、触发因素、扩张所需能力及成本、未来方向和反例。
7. **护城河与行业判断**：模式结构优势、代表企业实际能力、复制或绕开方式、成立条件与失效信号。
8. **其他说明、附录与待补证内容（按需）**：关键来源、事实/计算/推断/情境、详细参数、资料缺口和补证问题。

模式整理表可用：

`模式｜客户与购买结果｜收费与交付方式｜主要成本/现金特征｜代表企业｜常见程度及依据`

代表企业是解释模式的案例，不能将检索案例占比写成行业模式份额。

### 企业商业模式分析报告

1. **核心摘要**：先回答目标企业怎样赚钱、关键优势和薄弱处、经营质量及最重要的观察点；每项给出关键数字、机制或证据。
2. **研究范围**：企业或经营主体、业务范围、地域、报告期、研究目的及必要的包含与排除。
3. **业务与模式组合**：主要业务、客户、采用的模式和收入线，说明主干、引流、留存及培育业务的关系。
4. **经营过程与经济性**：获客、合同、交付、四流与责任；收入构成、增长来源、单位经济、整体成本、共享费用、利润质量和现金转换。复杂部分附计算表。
5. **主要竞争企业的模式比较**：选择理由、相关业务和模式、与目标的差异、替代方式及影响。不要求为每个对手写完整企业报告。
6. **模式演变、增长与护城河**：业务协同或蚕食、扩张路径、投入与资金需求、优势的经营效果和复制压力测试。
7. **企业判断与观察点**：哪些机制已有验证、哪些条件尚未满足，风险、替代解释和可观察的变化。
8. **其他说明、附录与待补证内容（按需）**：来源、参数、事实/计算/推断/情境、详细计算和补证问题。

业务组合表可用：

`业务单元｜客户｜模式与收入线｜在公司中的作用｜共享资源或补贴关系｜已知占比/变化方向｜依据`

同一笔收入在多业务、多模式汇总时只计算一次；没有分部信息不猜分摊比例。

### 共用比较表与局部任务

行业可比较模式，企业可比较竞争企业的相关模式：

`模式/企业相关业务｜付款者与购买结果｜收费与收入口径｜收入组合｜成本驱动与共享费用｜单位经济｜现金周期与资本占用｜扩张路径｜关键依赖与阶段｜适用条件｜不可比项`

机制先比较，数值能对齐再计算差异；同名毛利率、贡献率或现金指标也要检查分母、成本范围、资本化、补贴及一次性项的处理。不同发展阶段可以比较，但应解释其影响。

只问某种模式、收费比较、单位经济或经营参数时，交付对应分析、计算与来源，不扩写其余章节。参数提取可用：

`字段｜值/方向/区间｜对象与业务单元｜时间地域｜单位/分母｜事实/计算/推断/情境｜证据状态｜成立条件｜后续用途｜是否可用于更新原结论`

参数包可供其他分析或综合研究复用，但后续推断不得回写成本 Skill 的事实。

结论直接说明哪里有效、在什么条件下有效、什么尚不清楚。没有足够利润或现金证据时，可以判断收费机制存在，但不能据此判断模式已经盈利或可持续。

## 三、其他交付物

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 单位经济、多业务收入或成本拆分、盈亏平衡、现金转换、情境或敏感性需要复算 | 带公式 `.xlsx` | 范围与口径、输入与来源、计算、情境与检查；参数、单位、公式和结果可追溯 |
| 用户要求可复算模型 | 带公式 `.xlsx` | 与本次问题直接相关的输入、计算和检查，不生成空模板 |
| 只需交换已整理的模式、业务或参数长表，且没有公式 | `.csv` | 字段定义、对象、时期、口径、来源和状态 |
| 计算简单且主报告表格能够完整展示 | 不生成附件 | 在 Markdown 中保留公式、输入、口径和结果 |

CSV 不能代替需要公式的模型。同行模式比较或业务列表本身不触发 Excel；只有出现复算、批量维护或明确交换需求时才生成。
同一数据表需要公式时使用 Excel；只交换无公式长表时使用 CSV，不同时生成两份重复附件。

## 四、保存与命名

- 保存位置按 [专项工作流程](专项工作流程.md)：有路由用任务卡指定位置；无路由默认当前任务工作文件夹。
- 文件命名：行业报告 `YYYYMMDD_研究主题_行业商业模式分析.md`；企业报告 `YYYYMMDD_企业名_企业商业模式分析.md`；合并报告 `YYYYMMDD_研究主题_行业与企业商业模式分析.md`。局部任务写具体内容，如 `YYYYMMDD_研究主题_订阅与按量收费比较.md`。
- 附件沿用主文件名称，再加具体用途，如 `_单位经济模型.xlsx`。版本号按需要添加，用户或项目另有命名规范时优先遵守。

## 五、信息缺口

关键收入线、成本池、合同/回款、模式迁移或比较口径存在缺口时，输出商业模式补证任务：

`待证主张｜对象/业务单元｜所需字段与口径｜建议时间范围｜可能渠道｜缺口会改变什么判断｜补充后更新哪一部分`

以下缺口会改变判断时，优先核对现有材料，允许补搜时再执行补证；用户要求只用现有材料时登记缺口：

- GMV、合同额、确认收入和回款无法区分；
- 核心成本、经营者劳动、账期或资本开支缺失到足以改变结论；
- 财务口径、业务分部或时间范围存在未解决冲突；
- 盈利、留存、复购、客户或现金流只有宣传表述，没有可用证据。

## 六、交付条件与交付前检查

本次问题已得到有依据的回答，主要经营机制、经济结果、判断条件和限制已说清，继续增加一般材料不会改变核心判断时即可交付。缺口只暂停受影响的判断，其余可确认内容继续完成。

交付前检查：

- 核心摘要先回答“怎样赚钱、是否有效、关键条件是什么”，研究范围单独成节；
- 客户价值、接单交付、收费、成本、现金和责任能够前后连接；
- 行业模式的常见程度有依据，代表企业没有被当成行业份额样本；
- 企业业务组合没有重复计算收入，共享费用和分部缺口已说明；
- 同行比较使用同口径，事实、计算、推断和情境分开；
- 附件只在第三节条件触发时生成，报告数字与模型结果一致；
- 文件位置、名称、相对链接和实际附件清单已核对。
