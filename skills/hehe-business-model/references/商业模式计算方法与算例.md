# 商业模式计算方法与算例

需要计算收入、单位经济、盈亏平衡、现金或每100元分配时使用。选择适合当前业务的公式，不要求全部计算。下列数值均为假设算例，不代表行业均值或真实企业。

## 1. 先分清计算的是什么

| 指标 | 含义及注意事项 |
|---|---|
| GMV、订单额、合同额 | 交易或签约规模；说明取消、退款、税费与统计范围，不自动等于收入 |
| 确认收入 | 按适用规则，在履约并满足确认条件时计入；说明主要责任人/代理人及总额/净额 |
| ARR、MRR | 某时点有效经常性收费的年化/月化金额；统一包含范围，剔除一次性服务，不当作实际年度/月度收入 |
| 客户付款、回款、净结算 | 现金收到多少；平台扣款、账期和预付会使其不同于收入 |
| 单位贡献、经营利润 | 按各自成本范围计算；单位贡献尚需覆盖固定、共享等成本 |
| 经营现金、资本开支后现金 | 处理收付款时间、非现金费用和资本投入；不等于利润或公司全部现金余额变化 |

计算表说明对象/业务、期间、单位、税费口径、参数来源和假设。缺失值留空或做明确情境；不同口径能转换则说明转换，不能则分别报告。

## 2. 按业务计算收入

| 业务 | 计算方法 | 使用条件 |
|---|---|---|
| 商品销售 | 当期满足收入确认条件的销量 × 不含代收税的净成交单价 | 多品类分别计算再加总；退货、折让计入净销量或净单价一次 |
| 订阅/席位 | 各服务期间有效付费席位 × 该期间分摊的单价，再加总 | 处理新增/退出日期、折扣、赠送期；一次性实施费单列 |
| 按量收费 | 各计费档实际可收费使用量 × 对应净单价，再加总 | 注意免费额度、阶梯价格、最低消费和封顶，不把所有用量乘标价 |
| 项目/服务 | 时段履约项目按交易价格 × 累计履约进度 − 以前期间已确认收入；时点履约项目按当期满足确认条件的履约义务计入 | 先判断适用时段还是时点；签约和收款不代表已履约 |
| 代理型平台 | 符合计佣条件的交易额 × 实际佣金率，其他已履约服务费单列 | 平台承担主要责任的买断自营业务，不能机械套抽佣法 |
| 广告 | 计费曝光量 ÷ 1000 × CPM，或有效点击量 × CPC，或有效转化数 × CPA | 按合同计费方式选用，多个漏斗指标不重复计费；访问量本身不是收入 |

订阅存量变化另算：

`期末ARR = 期初ARR − 流失ARR − 降配ARR + 扩容/涨价ARR + 新客户新增ARR`

MRR同理，所有加减项都是同一周期口径的金额；并购、汇率或范围调整另列。存量桥解释业务变化，实际收入仍按当期服务计算。

**例：** 年初ARR120万元且全年稳定，12月1日新增客户ARR120万元，假设服务均匀、无流失和其他收入。年末ARR为240万元；当年确认收入为 `120 + 120÷12 = 130万元`，不是240万元。

### 收入与到账的区别

- **主要责任人还是代理人：** 看转让商品或服务前是否控制它及合同责任，不按谁先收款或平台扣多少钱判断。
- **预收与赊销：** 尚未履约的预收对价不直接计收入；已履约并满足确认条件但未结算，也不等于没有收入。
- **折让、退款与坏账：** 成交价格调整、退款与后续信用减值分别处理。信用损失不能既冲减收入又作为费用扣一次。
- **多边付款：** 分别计算客户、广告主、商户等付款，核对是否购买不同服务；融资不是收入，补贴与政府采购按性质分开。

在不含增值税、无核销/汇兑/并购等其他变动的简单情形下，可用以下式子解释收款时间：

`客户现金收款 ≈ 确认收入 − Δ应收款（减值前）− Δ合同资产 + Δ合同负债`

Δ表示期末减期初。实际项目若有税费、退款、结算代扣或其他变动，分项调节；平台净到账不等于式中的客户付款总额。

## 3. 单位经济、成本与盈亏平衡

选择一个可重复单位，如订单、客户、门店或项目，且收入与成本覆盖同一单位和期间：

`单位贡献 = 单位净确认收入 − 随该单位新增的成本`

新增成本可分采购/生产、实施交付、云或按量投入、渠道交易、售后责任等，互不重叠。获客成本已计入就不再扣；退款已从收入扣除就不再记同额费用。毛利、单位贡献和经营利润的成本范围分别说明。

| 计算 | 方法与条件 |
|---|---|
| 获客成本CAC | 可归属获客支出 ÷ 同批新增付费客户；标明营销销售范围、归因时滞和自然新增是否计入 |
| 获客回收期 | 各期客户贡献累计覆盖获客及初始实施投入所需时间；贡献未重复扣同一投入。贡献稳定时才简化为投入÷每期贡献 |
| 盈亏平衡量 | 同期固定成本 ÷ 单位贡献；仅适用于单位贡献为正且价格、产品组合、产能和成本近似稳定的范围 |
| 多业务平衡 | 各业务数量 × 各自单位贡献的加总，覆盖固定及共享成本；组合不固定时做情境，不能套单一平均贡献 |
| 扩张情境 | 同时改变价格、数量、留存、成本、产能和资金占用中受影响的参数；超过产能台阶时补人员、场地或设备投入 |

成本架构同时列直接/间接、固定/变动/阶梯、现金/非现金、维护/扩张、可归属/共享。研发、制造采购、实施、渠道、售后、管理、合规等不可遗漏；无法可靠分摊的共享成本保留未知或有依据的范围，不填零。

付给经营者的工资按实际费用与现金处理；未支付劳动的机会成本可另算“计入经营者劳动后的经济结果”，不冒充会计费用或现金流出。营运资金是资金占用，资本开支是投入，均不能再直接当作当期经营费用重复扣除。

**例：** 单笔收入100元，采购40、交付10、渠道5、售后5，获客另计，则单位贡献40元。每月固定成本2万元，假设产能范围内成本稳定、无其他成本，盈亏平衡为 `20,000÷40=500单/月`。客户获客及初始实施投入120元，每月贡献40元且持续留存，简单回收期为3个月；客户不足3个月流失，就不能沿用此回收结论。

## 4. 从利润到现金

以经营利润为起点，可建立简化分析桥：

`经营利润 + 已扣折旧摊销等非现金费用 − 已计非现金收益 − 经营性营运资金增加 − 现金所得税 = 简化经营现金`

`简化经营现金 − 资本开支 = 简化资本开支后现金`

- 应收、合同资产、存货、预付等经营资产增加，通常占用现金；应付、应计费用、合同负债等经营负债增加，通常提供现金。排除现金、借款等融资项目。
- 非现金项目加回与营运资金变化应使用相配的口径，避免信用减值同时通过净应收和非现金费用调两次。核销、并购、汇率等另行调节，不能机械使用所有资产负债表差额。
- 从净利润开始时，应按模型目的调整已包含的利息等项目；本简化桥不自动等于审计现金流、自由现金流或现金余额增减。融资、分红、资产处置等单列。
- 维护性与扩张性资本开支尽量区分；固定资产采购时计资本开支，之后折旧计费用，利润转现金再加回已扣折旧。

**例：** 当期收入并收款100元，现金成本60元，折旧10元，资本开支20元，无其他营运资金变动、税和利息。

- 经营利润：`100−60−10=30元`。
- 简化经营现金：`30+10=40元`。
- 资本开支后现金：`40−20=20元`，与 `100−60−20` 相符。

现金变好还要解释原因：真实回款改善、压库存、延迟付供应商，还是借钱、卖资产。结合合同、增长、季节性及多期变化判断。

## 5. 每100元客户付款：三段分别核算

需要比较钱如何分配时使用。先说明100元是什么：终端付款、GMV、含税价、合同回款或确认收入；各模式可分别设情境，不共用一套比例。

| 段落 | 计算与说明 |
|---|---|
| A. 付款、收入与结算 | 分别列客户付款、已履约确认收入、尚未履约部分、代收税款、平台代扣和实际到账。不能用“100减去所有扣款”统一当收入 |
| B. 收入与经营结果 | 从确认收入扣采购/生产、外协交付、渠道获客、售后、经营费用、实际劳动费用及折旧等，每项只扣一次；估算劳动机会成本另列 |
| C. 经营结果与现金 | 按上一节加回已扣非现金项、处理收付款时差与资本开支，再与实际收支核对 |

表格可用：

`项目｜金额｜占付款或收入的分母｜现金/非现金｜固定/变动/阶梯｜来源或假设｜事实/计算/情境`

**主要责任人算例：** 假设卖家控制商品，向客户完成100元销售；平台扣20元服务费并结算80元，采购成本50元且已支付，无税、账期及其他费用。

- A：客户付款100；确认收入100；平台扣款20；卖家到账80。
- B：收入100−采购50−平台费20＝扣所列成本费用后的利润30。
- C：净到账80−采购付款50＝现金剩余30，平台费不能再扣一次。

若平台费列销售费用，毛利为50、扣平台费后为30；不可将30不加说明地叫毛利。另一个只为他人安排交易的代理人，即便经手100元，也可能只按佣金确认收入，须按其合同身份另算。

**预付算例：** 客户支付100元购买下一期间服务，当期尚未履约。忽略税费，则当期收入0、现金收款100、合同负债增加100。收款桥为 `0+100=100`，不能先计收入100再加预收100。

整张表标明 `[情境]` 与假设；不是行业平均利润率或对象真实利润。有实际数据时指出哪些值来自披露、哪些经过换算。

## 6. 核算用的小例子

| 问题 | 正确区分 |
|---|---|
| 曝光1万次，点击率1%，每点击2元 | 100次点击，CPC收入200元；曝光×点击率只得到次数，不是金额 |
| 收入100已确认，后续信用损失10，无价格让步 | 收入仍100，单列信用减值损失10；不是收入90再减损失10 |
| 时段履约合同100万，累计完成60%，以前已确认40万 | 本期收入20万；不能把累计60万再次全记本期 |
| 两项业务贡献30和20，共享固定成本15 | 合计经营贡献扣共享成本后35；两项各扣15后再汇总会重扣 |

## 7. 会计口径参考

- 收入确认的履约/控制权、主要责任人与代理人的总额/净额判断，及信用减值的处理，参考财政部等[关于企业2025年年报工作的通知](https://kjs.mof.gov.cn/gongzuotongzhi/202512/t20251224_3980024.htm)一（七）2–3、一（十一）1。该文不提供上文现金桥或ARR公式。
- 适用新收入准则的商品预收款使用合同负债科目，其中增值税不计入合同负债，参考财政部会计司[收入准则实施问答](https://kjs.mof.gov.cn/zt/kjzzss/sswd/srzzsswd/202012/t20201211_3634031.htm)。它不规定所有业务的税额或纳税时点。

以上作为中国企业会计口径参考；实际研究按对象适用制度和合同判断。经营公式与假设算例是分析工具，不替代企业会计政策。
