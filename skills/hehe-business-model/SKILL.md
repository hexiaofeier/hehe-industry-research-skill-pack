# 商业模式分析

本 Skill 是盒子原创行业研究 Skill 组合中负责商业模式分析的专项 Skill，用于看清一个行业或企业怎样做生意、为什么能赚钱、能否持续。既研究行业内的主要模式，也研究企业怎样组合业务并与同行竞争。

## 启动与工作流程

- **已安装 `hehe-industry-researcher`：** 收到任务卡和材料索引后直接读取材料并执行，不重新启动路由。
- **未安装 `hehe-industry-researcher`：** 本 Skill 单独启动，在对话中确认对象、研究范围、地域、时间、用户口径要求及已有材料，再决定是否搜索。

开始执行前读取 [专项工作流程](references/专项工作流程.md)，按对应路径接任务、搜索、审核、分析、自审和交付。
交付时读取 [商业模式分析交付模板](references/商业模式分析交付模板.md)，按模板完成本专项成果；用户明确不落文件时，在对话中交付。

**完整交付原则。** 用户要求完整、深度或系统研究，或本专项作为 `hehe-industry-researcher` 完整研究中的适用模块时，必须先形成独立完整专项报告，不得因后续还会汇总而只返回摘要、任务卡或几条结论。只有用户明确要求局部／简版，或资料只能支持有限披露时才切换输出模式，并在报告中标明；完整度按交付模板的分析单元和参考体量检查。

## 选择研究任务

沿用用户要求或任务卡确定的研究对象。研究行业走行业任务，点名企业走企业任务；同时要求两者时分两部分分析，已有内容直接复用。只问某种模式、收费比较或经营参数时，完成对应部分，不扩成全行业或全企业研究。

### 行业商业模式研究

| 步骤 | 怎么分析 | 得到什么 |
|---|---|---|
| 1. 找出主要模式 | 从实际企业做法归纳客户、价值、收费、交付组织与资产投入的差别；说明分类依据 | 主要模式、代表企业及证据 |
| 2. 解释各模式 | 用下文共用方法说明怎么买、怎么交付、钱怎么收、成本和现金压力在哪 | 各模式的运转方式与经济特点 |
| 3. 研究组合 | 看哪些模式共同出现，各自用于引流、盈利、留存还是新业务培育，是否共享资源或相互补贴 | 常见组合、协同与冲突 |
| 4. 比较条件与优势 | 比较适合的客户、场景、地区、阶段、关键能力和投入，解释为何多种模式并存 | 适用条件、模式优势及护城河 |
| 5. 分析演变与趋势 | 梳理旧做法到新做法的变化、原因、扩张条件及反例 | 演变路径、趋势、风险与观察点 |

分类时注意：

- 订阅是收费方式，直营/加盟是组织方式，平台是交易组织方式之一，可以组合，不能未经解释就列成互斥类别。按课题选主要分类依据，必要时分层或使用组合标签，不预设固定种数。
- 一家企业可能采用多种模式，多家企业也可能采用同一种。代表企业用于解释模式，不用几家公司代替行业全貌。
- 根据材料区分常见做法、局部做法和新尝试，说明覆盖范围。检索案例数、新闻热度不等于市场份额；没有比例也可整理模式及其并存原因。
- 演变分别看模式内部改善、采用范围变化、不同模式融合或替代。产品发布、收费变化、客户采用、持续收入、交付与现金改善的证明力度不同，不把一家公司增长直接写成行业转向。

### 企业商业模式研究

| 步骤 | 怎么分析 | 得到什么 |
|---|---|---|
| 1. 拆业务与模式 | 分清业务单元、客户及其采用的模式，找出收入主干与引流、留存、培育业务 | 企业业务与模式组合 |
| 2. 还原经营过程 | 梳理获客、签约、定价、交付、售后、收款与合作责任 | 企业怎样取得并完成生意 |
| 3. 分析经济性 | 研究收入、成本、单位贡献、整体投入、利润质量与现金转换 | 赚钱方式、经济约束和资金需求 |
| 4. 比较主要竞争企业 | 研究对手采用什么模式，比较同模式的不同做法和异模式替代 | 模式差异及其对目标企业的影响 |
| 5. 研究增长与优势 | 分解增长，检查业务协同、模式变化、扩张条件和竞争者复制能力 | 增长路径、护城河与薄弱处 |
| 6. 形成判断 | 汇总哪些经营机制已有依据、哪些有待验证，以及什么变化会改变判断 | 企业结论、风险和观察信号 |

竞争企业优先使用用户指定对象；未指定时，根据共同客户、需求、预算和替代关系选择并说明理由，不固定数量，不只选名气大或产品相似的企业。比较其相关业务与模式即可，不必先做每家企业的完整画像。

两类任务都可先比较经营机制，再比较有数据支持的数值。数值比较对齐相关业务、时间、地域、单位和会计处理；无法转换的项目单列说明，不因发展阶段不同就停止比较。不排脱离条件的“最佳模式”，不把模式优势直接写成投资价值。

## 自审与交付

- 研究行业时，是否解释主要模式、代表企业、组合、演变与优势，而不只是逐家介绍公司？
- 研究企业时，是否看清业务组合，并比较主要竞争企业的相关做法？
- 客户价值、预算、交付、收费和成本能否相互支持？断点具体在哪里？
- 收入、利润、现金有没有混算；多业务收入、费用、共享成本和资金占用有没有重算或漏算？数值比较是否注明单位、期间和处理差异？
- 增长、模式演变、飞轮与护城河是否有经营依据、替代解释和可观察的失效信号？情境是否与事实分开？
- 本次问题是否得到回答，资料缺口是否只限制相关判断？不要求把所有方法都执行一遍。

完成自审后，按 [商业模式分析交付模板](references/商业模式分析交付模板.md) 形成行业或企业商业模式分析报告；局部任务交对应分析。默认保存 Markdown 文件，包含结论、解释、表格和来源；复杂计算再附公式 Excel。
