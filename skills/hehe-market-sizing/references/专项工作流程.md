# 市场规模测算工作流程

## 1. 启动方式

- **由 `hehe-industry-researcher` 调用：** 收到任务卡和材料索引后直接执行，不重新启动路由或开题。
- **用户直接调用本 Skill：** 本 Skill 独立确认问题和范围并执行，不把 `hehe-industry-researcher` 或其他 Skill 作为启动条件。

组合模式下，下文提到的路由参考文件从调用方 `hehe-industry-researcher` 的安装目录读取；独立模式不读取这些文件。

## 2. 接任务或确认研究范围

**由 `hehe-industry-researcher` 调用时：** 它负责开题或专项问题确认、材料汇总，并派发任务卡和材料索引。本 Skill 先读任务卡中的共同研究范围、专项问题和预期交付，再按索引到材料库读取原文；也可查阅库内其他相关材料。任务卡已包含开题或对话确认的关键信息，不再从头读开题记录。缺少会影响测算的信息时，交由 `hehe-industry-researcher` 补充确认。材料使用规则见其 `references/分析准备流程.md`。

**单独启动时：** 先读取用户描述和已有材料，在对话中确认：

- 研究目的及对象：要测算什么行业或市场，用于什么判断；涉及特定企业时明确企业。
- 业务/产品/赛道范围：包含什么、不包含什么。
- 地域与时间范围。
- 用户提出的关键口径、单位或分母等要求。
- 已有材料及位置。

已说清楚的内容不重复询问；尚未明确的关键范围向用户确认，不能把 Agent 的推断当作用户确认。这里只做对话确认，不要求开题文件；确认后决定是否搜索。

## 3. 信息搜索

**组合模式：** 沿用它已确认的搜索安排和材料，按其 `references/信息搜索流程.md` 执行，不重做一轮全面搜索。分析发现缺口时可定向补搜；新材料保存到其指定的 `01_材料库/搜索材料/` 或已有项目对应位置，来源和文件位置交回路由更新材料索引。

**独立模式：** 没有可供分析的材料就搜索；有材料则询问是否需要新一轮搜索，需要则搜索，不需要则审核已有材料后分析。已明确的选择不重复询问；用户禁止联网时只使用已有材料，并说明缺口。搜索使用以下方式：

1. **设计关键词。** 围绕研究对象及销量、收入、价格、用户数等关键材料设计搜索词，不把分析维度逐项转成必搜词。
如果本机安装了 `sou-cha-ling`（搜查令 Skill）就调用对应专项的行业或企业关键词组件；
如果本机没安装 `sou-cha-ling`（搜查令 Skill），则自行设计关键词，组合对象名称、业务/指标、地域和时间，并扩展中英文名、简称、旧称、同义词及上下位概念。

2. **选择搜索能力。** 检查当前实际可调用的能力，按下表选择；示例包括但不限于所列工具，不要求全部使用。

| 能力 | 示例 | 用法 |
|---|---|---|
| 网页搜索与浏览 | Web Search、WebFetch、内置或已连接浏览器 | 广泛发现来源，再打开具体页面读原文 |
| 信息采集 Skill | `tanzi`、`last30days`、`agent-reach` 等 | 跨平台、批量或社区采集；读取已安装 Skill 的用法后调用 |
| 搜索与数据 MCP/API | Exa、Tavily、Serper 或其他已连接服务 | 补充垂直搜索与结构化数据；付费、登录按用户授权使用 |
| 原始网站与专业数据库 | 政府统计、监管/交易所、公司官网、招投标、行业数据库 | 直接取得数据、披露、政策、交易与执行记录 |
| 学术论文与预印本 | arXiv 网站或 API | 涉及学术概念、算法、AI 模型或前沿技术时必查；保留标题、作者、摘要、日期和链接，核读关键论文 |
| 网页与文件提取 | URL 正文提取、PDF/Office 解析、OCR | 已知网址或文件时直接读取正文、表格和附件 |

3. **找回原文。** 优先官方、监管、财报、统计、标准或论文等一手材料；社区与用户观点保留原帖和语境，搜索摘要只作线索。
4. **补齐缺口并留来源。** 一个渠道覆盖不足或调用失败时换其他可用能力，不让所有工具重复同一查询。保留标题、来源、日期、链接或文件位置、关键摘录及未取得的材料；按本专项原有交付规则整理进材料表或分析底稿。

## 4. 材料审核

已有材料与新搜材料都需审核；路由已提供审核记录时沿用，不重复整批审核，新增材料或发现的问题再核对。有 `hehe-baojie`（保洁 Skill）时调用它；没有时自行核对原文、主体、时间、地域、定义口径、单位分母、重复和冲突。

路由任务的审核结果交回 `hehe-industry-researcher`，记入材料索引或指定的 `01_材料库/审核结果/`；独立任务在测算底稿中记录来源、审核状态和未解决问题。

## 5. 分析与自审

按 [主 Skill 的核心测算能力](../SKILL.md) 及其指向的方法文件完成任务，再自行核对是否回答了约定问题、公式和结果能否复算，以及来源、材料时效、结论限制、明显断层和反例。发现问题先修正，再提交交付物。

## 6. 交付与返修

按 [市场规模测算交付模板](市场规模测算交付模板.md) 生成完整、可编辑的 Markdown 测算说明和带公式的 `.xlsx` 可复算模型；结果状态按参数链中最弱的一档标注。在对话中提供结果摘要和文件链接。用户明确不要 Excel 时仍交付 Markdown；明确不落文件时在对话中完整交付 Markdown，不生成文件。任务要求 Excel、但当前环境不能创建并重算 `.xlsx` 时，交付完整参数与公式并把工作簿标为待生成，不把部分交付称为完整模型。

- **组合模式：** 底稿、报告、模型和附件平铺保存到任务卡指定的 `02_专项分析/` 或已有项目对应位置；目录依据其 `references/研究项目目录模板.md`。提交实际文件清单、使用及新增的材料、未解决问题，由路由按 `references/专项分析与交付流程.md` 组织二次审核。收到退回问题后，补证、修正或重算受影响部分，自审后交回路由复查。
- **独立模式：** 自审后直接交付，文件默认保存在本次任务的当前工作文件夹，不放在 Skill 安装目录；用户指定了位置则按指定位置保存，不再等待路由审核。

单独专项研究只交付市场规模成果，不自行扩展成完整行业报告。用户明确要求不落文件时，按其要求在对话中完整交付。
