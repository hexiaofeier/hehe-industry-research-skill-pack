# 市场规模测算

本 Skill 是盒子原创行业研究 Skill 组合中负责市场规模测算的专项 Skill，回答“测算什么、怎么算、哪些参数决定结果、结果能用到哪里”。

市场规模测算的精度取决于材料与实际交易、经营或需求的接近程度，也取决于材料覆盖和模型假设。优先使用厂商实际出货与价格、渠道实际动销、客户采购台账、样本调研，以及官方统计、监管披露、财报、招投标和合同等公开原始资料；第三方估计和分析假设可以使用，但要降低结论强度并说明限制。
本 Skill 不执行访谈、问卷等一线调研，但可以接收用户已有的一手材料；一手材料不是启动前提。没有内部或调研数据时，仍可依据公开原始资料和经核对的二手资料完成测算，按证据条件交付确定值、区间、数量级或情景结果。

## 一、启动与工作流程

- **已安装 `hehe-industry-researcher`：** 默认先由它组织任务；收到任务卡和材料索引后，直接读取材料并执行测算，不重新启动路由。
- **未安装 `hehe-industry-researcher`：** 本 Skill 单独启动，在对话中确认目的、对象、业务范围、地域、时间、用户口径要求及已有材料，再决定是否搜索。

开始执行前读取 [专项工作流程](references/专项工作流程.md)，按对应路径接任务、搜索、审核、分析、自审和交付。
交付时读取 [市场规模测算交付模板](references/市场规模测算交付模板.md)，默认同时交付完整 Markdown 主报告和带公式的 `.xlsx` 可复算模型；用户明确不要 Excel 时仍交付 Markdown，明确不落文件时在对话中完整交付 Markdown。当前环境没有可创建并重算 `.xlsx` 的能力时，仍完成 Markdown、参数和公式，但把工作簿标为待生成；不得把未生成、未重算的文件称为已完成模型。

## 二、核心测算能力

### 1. 选择测算角度

先根据用户目的和材料条件，确定本次要回答什么，再选可用的测算角度。以下八个角度是常见且可组合的切入点，如果一个行业适配多个切入点，建议多角度测算并相互验证，但不要求全部计算。

| 切入点 | 主要问题 | 常用办法 |
|---|---|---|
| 市场机会 | 总机会多大、能服务多少、某家企业能获得多少 | 客户与用量估算、服务范围筛选、可获得客户或份额推算 |
| 交易与经营规模 | 某年卖了多少、交易了多少、实现多少收入 | 企业收入加总、销量乘均价、表观消费量、产品/渠道/地区加总 |
| 采购与预算 | 客户计划采购多少、已招标或签约多少 | 预算、招标、中标、合同分别汇总，结合执行情况估计 |
| 财政与经费 | 某领域投入多少，其中多少用于目标用途 | 经费分项加总、用途拆分、对外采购部分估计 |
| 已有规模续算 | 已知前期规模，当期或未来可能是多少 | 基期乘增长率、分业务续算、数量和价格分别更新 |
| 宏观与行业统计拆分 | 能否从相关大盘子估计目标市场 | 总量按相关占比拆分、统计数量乘单位支出、投入产出系数推算 |
| 保有量与更替 | 存量每年要换多少、还能新增多少 | 保有量 × 更换率 ＋ 新增购买量 |
| 类比与代理指标 | 数据极少时能否借相邻市场或相关可观测量估计 | 成熟市场人均值折算、代理指标反推；结论强度低 |

选定角度后读取对应细则：

- **市场机会（TAM/SAM/SOM）：** 三层口径、四层客户数、存量与流量两个轴的区分，以及全套名词对齐表，见 [市场机会与口径术语](references/市场机会与口径术语.md)。
- **其余七个角度：** 公式、参数、按业务调整的算法和使用检查，见 [测算方法详解](references/测算方法详解.md)，该文件同时收录通用换算规则（跨期、跨币种、含税、名义/实际值）。
- 需要比较历史、预测未来，或把需求换算成经营收入与可支撑主体数时，见同一文件的第八、九节。
- 各角度的完整算例、常见错算方式及多角度交叉验证，见 [测算参考示例](references/测算参考示例.md)。

### 2. 整理参数与计算

从用户提供已有材料、公开材料或现成历史分析中提取参数，不要求用户或搜索工具预先填齐全部分析字段。每个输入量单独登记一行，减项与系数同样是输入量；数值、范围、单位、时期、定义、来源及转换过程统一记录在 [交付模板的参数表](references/市场规模测算交付模板.md)，判断类型与参数性质按该模板的对照表标注，保留材料状态和版本。

代入公式时保留“来源原值 → 必要换算 → 模型参数 → 结果”的计算过程，不能只列机构名称；本轮计算结果不得反过来充当本轮输入证据。

**结果精度。** 结果的有效位数不超过链条上最弱的那个参数。关键比例是估计值时，结果按两位有效数字或区间表达，不制造伪精度；中间计算仍用未取整值，展示值与计算值分开。

**缺少参数时。** 未说明或不适用的字段如实标注，不为填表强求补搜。只有缺项影响当前计算或判断时，再选择针对性补搜、可解释代理或显式假设，按交付模板的补证任务表列出缺什么、目标证据、可接受与不可接受的替代、影响位置和停止条件。仍无法确认时，可交付公式、模型骨架、区间或情景试算，并说明限制；弱证据和未解决冲突不能写成确定事实。

### 3. 情景与敏感性

当关键假设足以改变结果时，至少提供基准情景及上下边界；通常可用保守/基准/乐观三档。调整有依据的数量、价格、执行比例等参数；续算模型也可直接调整增长率参数，但要解释取值依据，不手改最终结果。

选出 1–3 个最影响结果且最不确定的参数，说明：参数变化范围；结果变化范围；哪个阈值会改变结论；是否存在供给、政策、预算或替代方案形成的非线性上限。

除参数变化外，登记结果不确定性来自哪里：覆盖缺口、代理参数、口径断点、模型结构还是外部约束。说明结果区间、关键翻转点和失效条件，不另建与材料审核重复的评级体系。

### 4. 检查与解释结果

存在独立且有意义的第二条路径时再做交叉检查；没有合适路径时，在交付中明确标记“单路径”，不为形式完整强行拼一个数字。按课题选择检查项：

- 需求侧漏斗与供给约束的结果是否相容；
- 互斥细分加总与已覆盖企业收入之和是否相容；
- 人均、企均、席位均、设备均或单次支出是否具有业务合理性；
- 成熟市场或相邻市场是否真正可比。成熟市场和相邻市场只用于比较机制、数量级或合理性，不能直接替代本地市场规模证据。

不同方法或第三方结果有差异时，依次检查：

`市场定义｜地域｜年份｜价格基础｜税口径｜汇率｜客户范围｜产品范围｜分母｜是否重复计算｜预测假设`

先解释差异来自哪里，再决定哪些结果可以比较。多个角度收敛也不等于正确，它们可能共用同一批错误前提，核对时确认输入是否真正独立。不得直接平均不同口径结果；无法解决的冲突转为区间、情境或待补证状态。

满足以下条件即可结束本次测算：

- 目标数字及其范围已经确认；
- 核心参数可追溯，公式可复算；
- 关键假设已有情景或敏感性边界；
- 独立检查没有发现会改变结论的新口径；
- 新增材料只会增加细节，不会改变结果区间。
