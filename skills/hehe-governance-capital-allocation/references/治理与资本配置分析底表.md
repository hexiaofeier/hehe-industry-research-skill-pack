# 治理与资本配置分析底表

本文件提供字段、计算提示和检查方法。只有需要建立控制权图、治理事件台账或资本配置工作底表时读取；它不是统一评分表，也不替代法律、财务或估值专项。

## 一、工作簿建议结构

| 表 | 用途 | 最小字段 |
|---|---|---|
| `00_范围与输入` | 冻结主体、时点、制度版本和证据状态 | 范围卡、输入地图、缺口、判断上限 |
| `01_所有权与控制权` | 区分经济利益、表决、任免和事实影响 | 主体、关系、直接/间接比例、权利、协议、起止日、来源 |
| `02_董事会与激励` | 登记监督和激励机制 | 人员/机构、角色、提名方、独立性、任期、薪酬、KPI、股权工具、稀释 |
| `03_关联与治理事件` | 跟踪冲突、担保、审计和纠偏 | 事件、关联方、金额、审批/回避、影响、状态、整改、证据 |
| `04_资本来源用途` | 勾稽资金从哪里来、到哪里去 | 期间、主体、来源、用途、宣布/实际金额、现金/会计口径、财务定位 |
| `05_重大决策复盘` | 检验管理层历史决策 | 背景、目标、审批、投入、里程碑、结果、回报/损失、处置、归因 |
| `06_结论与交接` | 形成分项判断和下游输入 | 主张、状态、证据、机制、反例、限制、观察指标、下游用途 |

每个金额保留：`币种｜单位｜主体｜期间｜发生日/公告日/支付日｜累计或当期｜现金或会计口径｜原始定位`。

## 二、所有权与控制权底表

建议字段：

`节点 ID｜主体/个人｜司法辖区｜载体类型｜上层节点｜下层节点｜直接经济权益｜穿透经济权益｜表决权｜董事提名/任免｜否决/保护性权利｜一致行动/委托表决｜质押/冻结/代持｜起止日期｜证据｜状态｜备注`

### 1. 穿透计算提示

简单链条可用：

`穿透经济权益 = 各层经济权益比例连乘`

多路径持有时，对相互独立且不重复的路径求和。出现交叉持股、循环持股、可转工具、期权、VIE 或合伙安排时，不强行用一条乘法代替法律和合同权利，应列示各路径及不确定性。

表决权和经济权益必须分列。差异表决权示例：

`某类股份表决权占比 = 该类股份数量 × 每股票数 ÷ 全部票数`

这只是计算字段，不自动决定实际控制。还要检查出席率、董事任免、协议、否决权和事实影响力。

### 2. 控制权事件时间轴

`日期｜事件｜变动前权利｜变动后权利｜触发原因｜审批/条件｜是否完成｜影响｜证据`

至少区分宣布、签约、批准、生效、交割和终止。使用判断截止日前已经生效的状态；尚未完成事项单列情境。

## 三、董事会、委员会与管理层

### 1. 人员/机构表

`姓名/机构｜角色｜执行/非执行｜提名或关联方｜任期｜持股/工具｜其他任职｜专业背景｜委员会席位｜关键表决/回避｜离任或变更｜证据`

不要只统计“独立董事比例”。需要观察：

- 是否有获取信息、聘请顾问和提出异议的能力；
- 任期、交叉任职、商业关系或家族关系是否影响独立性；
- 审计、薪酬、提名、风险等委员会是否覆盖关键事项；
- 重大失败后是否更换责任人、调整机制或追回奖励；
- 关键人依赖、继任和授权是否清楚。

### 2. 决策责任矩阵

`事项｜提出者｜审查者｜批准者｜执行者｜监督/复盘者｜回避方｜金额/权限阈值｜实际案例｜缺口`

适用于并购、资本开支、融资、担保、关联交易、股权激励、分红回购和资产处置。制度条文与实际案例分开登记。

## 四、激励、稀释与保护

### 1. 激励计划表

`计划/对象｜授予日｜工具｜数量｜授予/行权价｜归属期｜绩效指标｜指标口径｜门槛/上限｜服务条件｜出售限制｜追索/追回｜修改/重授｜费用｜潜在稀释｜证据`

重点检查：

- 指标是否同时包含规模、利润/现金、资本效率、风险和长期结果；
- 是否可由会计调整、并购或回购机械改善；
- 考核周期是否短于业务兑现周期；
- 失败后是否仍能重设目标、加速归属或获得新授予；
- 回购是否主要抵消员工股权稀释。

稀释提示：

`潜在稀释率 = 潜在新增普通股 ÷（期末普通股 + 潜在新增普通股）`

若工具的行权、转换或回购条件复杂，沿用财报摊薄股数及附注口径，不自创精确值。

### 2. 权益与保护条款表

`资本提供者｜工具｜经济权利｜表决/否决｜优先/清算｜反稀释｜共同出售/拖售｜赎回/回购｜担保/契约｜信息权｜执行条件｜证据｜缺口`

“保护性权利”不必然形成控制；“拥有控制”也不意味着所有经济利益都归控制方。具体法律效果需要专业复核。

## 五、关联交易、担保与治理事件

### 1. 关联交易表

`期间｜交易双方｜关系｜类型｜金额/余额｜占相关分母｜定价依据｜审批/回避｜持续性｜结算/资金流｜商业理由｜替代方案｜财务影响｜疑点｜状态｜证据`

分母按问题选择，例如收入、采购、资产、净资产、现金、应收或担保余额；不能混用。

判断框架：

`必要性｜定价公允性｜对关联方依赖｜审批与回避｜披露透明度｜回款/担保风险｜少数股东影响｜长期经济结果`

### 2. 治理事件表

`日期｜事件｜责任主体｜触发机制｜涉及权利/金额｜审计/监管状态｜经营财务影响｜纠偏措施｜是否闭环｜复发指标｜证据`

事件可包括财务重述、内控缺陷、非标审计意见、审计师/财务负责人更换、董事辞任、处罚、诉讼、举报、资金占用、违规担保和承诺未履行。

## 六、资本来源—用途勾稽

### 1. 资本来源表

`期间｜经营现金｜债务融资口径（新增借款/净借款二选一）｜股权融资｜可转/优先工具｜资产处置｜补贴/一次性来源｜其他新增来源｜证据`

### 2. 资本用途表

`期间｜维持性资本开支｜增长性资本开支｜研发/能力建设｜并购/投资｜偿债｜分红｜实际回购｜租赁/其他融资支付｜重组/关停｜现金增加｜其他｜证据`

### 3. 简化勾稽

在口径统一且数据足够时检查：

`期初可用资金 + 本期新增来源 - 本期资本用途 ± 口径桥接项 ≈ 期末可用资金`

期初与期末可用资金不计入本期新增来源。差异可能来自汇率、合并范围、受限资金、分类口径、非现金交易或时间差，统一列为桥接项。

为避免重复计算：

- 经营现金流若已包含营运资本和税费，不再次作为独立来源叠加；
- 并购现金支付与取得现金净额按同一口径；
- 使用新增借款时，将偿债列入用途；使用净借款时，不再重复扣减偿债；
- 回购授权、承诺金额与实际支付分列；
- 经营现金流作为资本来源时，费用化研发、获客和组织投入只作经营现金内部拆分，不再进入资本用途合计；资本化研发按现金流口径列入投资支出，若已包含在资本开支中不得再次扣减。

## 七、资本配置指标与使用边界

指标只支持问题，不替代决策复盘。

### 1. 再投资与股东回报

可按材料口径计算：

`经济再投资 = 净资本开支 + 营运资本增加 + 经调整的长期能力投入 + 并购及长期投资净额`

经济再投资不参与上文现金桥。经调整的长期能力投入只包括未被净资本开支、营运资本或并购覆盖的增量；费用化研发、获客、内容、数据和组织投入只有在明确采用经济资本化口径时，才按当期资本化金额扣除相关经济摊销后计入，并与经营现金和其他用途去重。跨企业比较时说明调整口径。

`现金股东回报 = 现金分红 + 实际股份回购 - 同期股权发行所得`

若回购主要抵消员工发行，同时展示毛回购、净回购和股份数变化。

### 2. 配置结果

从财报、附注、交易披露或现成分析核对以下指标，保留定义与计算依据；可用同口径原值复算，缺失时不编造：

- ROIC 与增量 ROIC；
- 自由现金流和现金转换；
- 净债务、利息负担和流动性；
- 商誉、无形资产、减值和处置损益；
- 总股数、摊薄股数及每股结果。

本 Skill 可建立事件级桥：

`投入资本 → 对应收入/利润/现金或战略里程碑 → 实现时间 → 归因范围 → 当前回收/减值/退出状态`

无法把结果可靠归因到单项决策时，标记“组合结果”或“无法隔离”，不硬算项目回报率。

每项重大配置记录适用的债务成本、股权/目标回报、监管或公司门槛及当时可行的备选用途，并按主 Skill 的判断规则比较。

## 八、重大决策复盘卡

每项重大决策一行或一卡：

`决策 ID｜背景与约束｜宣布目标｜备选方案｜提出/批准/回避｜资金来源｜宣布金额｜实际投入｜执行时间轴｜经营里程碑｜财务结果｜回报/损失｜适用资金成本/目标回报｜可行备选用途｜超额回报或差额｜外部因素｜管理层可控因素｜纠偏/退出｜当前状态｜观察指标｜证据`

当前状态可用：

- `按计划推进`：投入与里程碑在既定范围内；
- `偏离但可解释`：发生偏差，有证据支持原因和纠偏；
- `结果不佳/待处置`：结果明显弱于目标，纠偏或退出仍未完成；
- `已纠偏/已退出`：管理层识别问题并完成实质处置；
- `暂不判断`：时间不足、数据不足或归因无法隔离。

这些状态不是跨公司的统一评分，也不能汇总成未经设计的总分。

## 九、结论卡与可复用结果

每条结论记录：

`问题｜结论状态｜事实/计算｜机制｜成立条件｜反例/替代解释｜观察指标｜未解决缺口｜下游用途｜能否回写`

先把“问题”改写为方向明确的判断命题，再使用 `成立｜条件成立｜不成立｜暂不判断`。例如“资本来源与用途可追溯｜不成立”与“管理层激励存在重大短期错位｜成立”；不能只填状态。

资金与权利事实：

`净债务/受限资金提示｜潜在稀释与工具｜少数股东/非经营资产｜关联交易调整疑点｜控制权/交易权利｜治理风险与情景提示`

这些是事实或复核提示，不是直接折价率。

风险与观察条件：

`实际控制与关键人｜激励对齐/错位｜重大冲突｜资本配置能力与反例｜融资/分红/回购约束｜下行情景触发｜逻辑失效指标`

治理与配置摘要：

`治理结构摘要｜资本来源用途｜重大决策复盘｜分项结论｜未解决矛盾｜判断上限`

复用时不得把推断改写为所有权、金额或财务事实；新增事实先核对来源，再更新分析。
