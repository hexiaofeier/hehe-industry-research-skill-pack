# 治理与资本配置分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告。完整模式交付完整专项报告；专项事件或快速核对交付范围相称的专项报告。用户明确不落文件时，在对话中按第二节结构交付。

Excel 和控制图只在第三节所列条件触发时生成；简单治理核对不附空白工作簿或装饰性组织图。

## 二、Markdown 主报告

### 完整度与展开要求

先确定输出模式：

- **完整专项报告：** 用户要求完整、深度或系统研究，或者本专项被纳入 `hehe-industry-researcher` 的完整研究时使用。必须覆盖本模板列出的适用主体章节。
- **局部专项答复：** 只在用户明确询问一个局部问题或明确要求简版时使用，只展开与该问题直接相关的章节。
- **有限披露报告：** 只在关键资料确实不足时使用；仍需充分分析现有证据能够支持的内容，不能只交缺口清单。

完整报告的核心主体章节不能只有标题、事实清单、新闻罗列或一张没有解释的表。每项主要结论至少完成“结论 → 关键证据或计算 → 机制、比较或变化原因 → 对本题的含义 → 成立条件或翻转点”的闭环；表格之后解释最重要的差异和意义。

**完整模式正文目标体量：** 完整治理与资本配置分析一般为 7,000—13,000 汉字；专项事件或快速核对一般为 2,500—5,000 汉字。 这是完整度检查线，不是写作配额；交付前必须实际统计正文字符数并记录结果。统计只包括推进本题结论的分析；来源清单、原文摘录、附录长表、方法或交付说明、验收记录、通用边界和更新流程不计入，也不得跨专项复制或批量套用同一句式后只替换变量。低于下限时先逐项复查并补足被压缩的核心能力；实质分析已经完整且差距不超过下限 10% 时，可记录偏差后交付，不得为贴线补字。差距超过 10% 且不属于局部或有限披露模式时，不得作为完整专项报告交付。超过上限也不代表更好，应删除重复结论、同义改写和只为防止质疑的说明。


完整模式按以下顺序平铺。专项事件或快速核对可只保留适用章节，但首个正文章节仍为核心摘要，第二节仍为研究范围，省略空章后其余章节连续编号。

1. **核心摘要**：先给治理质量和资本配置质量两项总体判断，再列三至六项主要发现；每项写明结论、关键权利/事件/金额证据及影响。摘要只放结果，不放研究过程。
2. **研究范围**：说明法律主体、重要子公司或载体、司法辖区、所有权和制度时点、财务期间、判断截止日、分析模式、决策用途及本轮可判断程度。
3. **所有权、控制权与治理机制**：展示经济利益、表决权、任免/否决权和事实影响力，给出控制链及变化时间轴；分析重大事项的提出、审批、执行和复盘关系，以及董事会、委员会、管理层、审计、内部控制、关键人和继任安排的实际表现。
4. **激励、资本提供者保护与治理风险**：分析管理层薪酬和股权工具、指标与周期、潜在稀释，以及少数股东和债权人的关键权利及利益错位；按事件说明关联交易、担保、利益冲突和重大治理事件的双方关系、金额和分母、定价、审批/回避、资金或资产流向、实际影响、纠偏状态及未解决疑点。
5. **资本来源、用途及勾稽**：按同一主体、期间、币种和现金/会计口径连接经营现金、融资和资产处置等来源，与内生投入、并购、偿债、分红、回购等用途；标明宣布、执行、支付和结果状态，解释勾稽差额。
6. **重大资本配置决策复盘**：逐项呈现背景与备选方案、审批和利益关系、资金来源、实际投入、里程碑、经营/财务结果、适用资金成本或目标回报、可行备选用途、处置和当前状态。
7. **治理质量与资本配置质量结论**：两类结论分开。先写方向明确的命题，再使用`成立｜条件成立｜不成立｜暂不判断`；给出关键证据、机制、反例或替代解释、适用范围、观察指标和翻转条件。
8. **其他说明**：只放无法归入前述章节且会影响理解的口径、制度差异或材料限制；没有实质内容时省略。
9. **附录**：按需放资料与依据表、完整控制权表、治理事件台账、资本配置底表、公式、来源和可复用字段，不让长底表淹没正文结论。
10. **待补证内容**：集中列出会改变核心判断的缺口、补证任务、受影响章节、何时结束或暂停，以及取得新材料后如何更新。

可供后续任务使用的字段：

`主体/期间｜控制权与关键权利｜决策机制｜激励/冲突｜资本来源｜资本用途｜历史结果｜判断状态｜财务接口｜估值调整提示｜投资逻辑影响｜限制与不可回写项`

## 三、其他交付物

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 任务包含资本来源—用途勾稽、多期重大配置复盘、回报/损失计算或其他公式计算 | 带公式 `.xlsx` | 使用[治理与资本配置分析底表](治理与资本配置分析底表.md)的七表结构，保留范围、输入、来源、公式、差额、结果和结论交接 |
| 多主体控制链、关联交易或治理事件需要筛选、穿透和持续更新 | `.xlsx` | 七表中与任务有关的工作表；主体、权利、时间、关系、金额、状态和证据可追溯 |
| 控制关系存在多层、多路径、VIE、交叉持股或权利分离，表格无法清楚呈现 | 报告内 Mermaid 控制图；用户要求独立图时再另存图源和展示图 | 经济利益、表决权、任免/否决权、起止日和不确定性分开 |
| 单一事件或简单控制核对，且无复算或大表维护需要 | 不生成附件 | Markdown 保留适用表格、证据和判断 |

影响结论的字段区分未披露、权利无法确认、结果尚未兑现和不适用。任何计算保留公式、单位、期间、数据来源和计算过程，不生成与七表结构并行的另一套工作簿。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由时使用任务卡指定位置；单独启动时默认保存到当前任务工作文件夹；用户指定位置时按其要求保存。
- 主报告：`YYYYMMDD_研究主题_治理与资本配置分析.md`。
- 附件：`YYYYMMDD_研究主题_治理与资本配置分析_附件名称.扩展名`，附件名称写具体用途，如`控制权链表`、`资本配置工作底表`。
- 研究主题写清企业、集团、项目或交易主体；版本号按需添加。用户或项目另有命名规范时优先遵守。

## 五、信息缺口

只对会改变控制权、治理有效性、利益冲突、资本勾稽或配置质量结论的缺口生成补证任务：

`待证权利/事件/金额｜主体与关系｜制度或财务期间｜所需原始材料｜当前状态｜影响章节｜缺失时如何降级｜补充后如何更新`

未解决缺口只暂停受影响的权利、事件或配置判断，其余可确认内容继续完成。

## 六、交付条件与交付前检查

主体、时点和权利口径已经确认，重大治理与资本配置事项可追溯，资本来源用途完成适用勾稽，两类质量结论及其条件已形成，新增一般材料不会改变核心判断时即可交付。交付前检查：

- 核心摘要分别给出治理质量和资本配置质量判断，研究范围单独成节；
- 经济利益、表决权、任免/否决权和事实影响力没有混称；
- 批准、授权、签约、交割、支付和结果状态分开；
- 资本来源与用途使用同一主体、期间、币种和现金/会计口径，勾稽差额已解释；
- 经营现金桥与经济再投资分开，费用化研发等项目没有重复扣减；
- 重大配置同时检查资金成本或目标回报、可行备选用途和历史结果；
- 治理质量与资本配置质量使用方向明确的命题和四种状态；
- 报告、七表工作簿和控制图的主体、金额、状态、结论及链接一致，实际文件可打开。

## 七、其他注意事项与专项要求

正式控制图、Excel 视觉美化、PPT 和品牌化版式只在用户明确要求时制作，不属于默认交付。呈现加工不得改变权利关系、资金口径、公式或结论。
