# 竞争格局分析

本 Skill 是盒子原创行业研究 Skill 组合中负责竞争格局分析的专项 Skill，回答“谁在竞争、谁在哪些方面领先、行业格局为什么形成并如何变化”。既可研究行业参与者、份额和核心企业横向比较，也可围绕目标企业分析其竞争位置、优劣势、问题、机会与策略。

## 启动与工作流程

- **由 `hehe-industry-researcher` 调用：** 收到任务卡和材料索引后直接读取材料并执行，不重新启动路由。
- **用户直接调用本 Skill：** 本 Skill 单独启动，在对话中确认对象、研究范围、地域、时间、用户口径要求及已有材料，再决定是否搜索。

开始执行前读取 [专项工作流程](references/专项工作流程.md)，按对应路径接任务、搜索、审核、分析、自审和交付。
交付时读取 [竞争格局分析交付模板](references/竞争格局分析交付模板.md)，按模板完成本专项成果；用户明确不落文件时，在对话中交付。

**完整交付原则。** 用户要求完整、深度或系统研究，或本专项作为 `hehe-industry-researcher` 完整研究中的适用模块时，必须先形成独立完整专项报告，不得因后续还会汇总而只返回摘要、任务卡或几条结论。只有用户明确要求局部／简版，或资料只能支持有限披露时才切换输出模式，并在报告中标明；完整度按交付模板的分析单元和正文目标体量检查，交付前实际计数。

## 核心分析方法

### 1. 行业与参与企业

明确研究什么行业或细分市场、包含哪些产品与客户，以及地域、时间和相关渠道。不同细分市场的客户与竞争方式差异较大时，分开分析。

分清竞争主要是争取新增客户，还是替换已有品牌或供应商；采购、渠道准入、续费等环节不同，实际对手也可能不同。

列出主要企业，包括头部企业、主要挑战者和有实际影响的新进入者。说明各自的相关业务、代表产品、客户与区域，以及市场角色或特点。企业研究围绕目标企业的相关业务选择主要对手。

影响格局的进入、退出、并购或业务转向，注明时间和当前状态。有实质准备动作的潜在进入者可列入观察，与已经经营的企业分开。

- 公司、品牌与具体业务分清；不能用集团整体收入代表某项业务。
- 是否竞争，看是否争夺相同客户的需求或预算；产品相似、产业链相邻、合作关系不等于竞争。
- 客户确实会选择其他技术、自建、人工或暂不购买时，说明这些替代做法的影响，不硬列成企业。

### 2. 市场集中度、份额与变化

#### 选择指标并计算

优先选择能说明本行业格局的核心指标，不要求每种都算：

| 指标 | 如何使用 |
|---|---|
| 收入／销售额 | 比较相关业务取得的收入或销售额；企业确认收入、终端零售额与平台交易额分别使用，不混算 |
| 销量 | 比较同类产品的销售数量；产品差异大时分品类看 |
| 用户 | 比较同一时间范围的付费、活跃或其他明确类型的用户；多家重叠使用时，分别报告用户覆盖率，不直接加总成集中度 |
| 出货量、订单 | 前者反映供货，后者反映签约或需求；作为补充口径，说明出货不等于终端销量、订单不等于已实现收入 |

计算时列出企业原数值、市场总量及来源；产品、地域、时间、渠道和单位保持可比，集团与旗下品牌不重复计数。

- **市场份额＝企业指标值÷同口径市场总量。**
- **CRn＝同一市场实际前 n 家企业的份额之和。** 按问题选择 CR3、CR5 等，不用固定阈值直接判定行业性质。
- **HHI＝同一市场各企业份额平方之和。** 份额使用百分数时结果范围为 0—10,000，使用小数时结果范围为 0—1，计算表必须注明单位。只有市场总量和参与者覆盖能够支持同一市场份额时才计算市场 HHI；覆盖不完整但已知份额可核对时，只称“已知企业 HHI 下限”，并注明未覆盖份额。阈值解释服从本题法域、行业和用途，不用固定阈值代替格局判断。
- **份额变化＝本期份额－基期份额，单位为百分点。** 对照同口径历史数据，区分份额上升与企业自身收入或销量增长。

市场总量未知时比较企业已有数值，不把已知企业归一到 100%；无法确认实际前 n 家时，写“已知企业份额合计”，不称 CRn。数据误差可能改变名次时说明排序不确定。并购、品牌归属或统计覆盖变化造成的增减，单独解释。

#### 解释格局及其变化

把客户看重的因素、企业能力差异与实际购买或经营结果联系起来，解释格局形成与变化：

- 当前由谁主导，是少数企业集中竞争，还是多个细分市场各有强者？
- 领先主要靠产品、价格、渠道、客户关系、交付能力还是其他优势？是长期积累，还是阶段性供需、补贴或资金投入带来的领先？高份额是否也带来了较好的利润或现金表现？
- 格局正在集中、分散还是重新分配？哪些企业上升、退出或转向，价格、技术、渠道、并购或新进入者起了什么作用？
- 接下来什么变化可能影响领先位置？说明发生条件、受影响企业及可观察信号。

已发生的变化用前后事实支持；解释原因时考虑其他可能因素。融资、新品发布或合作公告本身不等于竞争力提升；未来影响可以讨论，但与已发生结果分开。

判断对手扩张、新进入者或替代方案的影响时，看已具备哪些产品、客户、渠道和资金能力，可能切入哪些客户或区域，仍需跨过什么成本、认证或客户切换门槛，以及现有企业可能如何应对。客户能否同时采购多家、转向替代方案，也影响领先者能否守住位置。

说明重要变化改变了哪些需求、供给、成本或渠道条件，哪些企业因此受益或受损。分清发布、实际落地和经营效果出现的时间，考虑效果滞后。再问：没有这件事，结果是否仍可能这样变化？哪些反例或后续信号会推翻当前解释？

### 3. 核心企业比较

以企业在本行业的相关业务为比较对象，按同一组有效维度横向比较。行业研究不设标的企业，各家平行呈现；企业研究把目标企业与主要对手放在一起比较。

从下表选择影响本行业竞争的维度，也可补充行业特有维度，不要求全部使用。既看企业资源、能力与经营表现，也看客户购买、续购或更换供应商时看重什么。

| 常用方向 | 可比较的内容 |
|---|---|
| 企业背景与资本 | 创始人、发展背景、股东与投资者、融资及可用资源 |
| 团队与组织 | 核心团队经验、人员结构、组织与管理能力 |
| 业务与商业模式 | 业务组合及收入贡献、目标客户、收入来源、收费方式与业务协同；对单一产品或业务的依赖 |
| 产品与技术 | 已形成的产品线、定位、技术路线、核心技术、任务完成效果、质量与可靠性 |
| 经营表现 | 相关业务营收、增长、利润、盈利能力与现金表现；增长来自新增客户、老客户增购还是涨价 |
| 市场与用户 | 市场地位、用户或客户体量、客户结构、主要客户依赖、细分市场覆盖、留存与复购 |
| 品牌与用户评价 | 品牌认知、口碑、满意度、投诉及用户认可或不满之处 |
| 地域与渠道 | 优势区域、市场覆盖、渠道结构、控制力与客户关系；对单一区域或渠道的依赖 |
| 研发与创新 | 持续开发新能力的团队、投入与机制，技术成果、迭代速度及商业转化 |
| 销售与获客 | 销售组织、营销方式、获客成本与销售效率 |
| 价格、成本与供应链 | 可比产品售价、总使用成本、付款条件、采购制造、规模效率与供货稳定性 |
| 运营、交付与服务 | 运营效率、交付速度、实施、运维、售后与服务范围 |
| 合作生态与外部依赖 | 关键伙伴与合作内容、自有与外部能力；客户关系、技术、数据或渠道由谁掌握，能否替代，合作中断的影响 |
| 竞争策略与资源配置 | 定价、差异化、扩张方向；资金和人员投向、投入持续性、落地速度与效果，是否支持主要竞争方向 |

用“维度｜企业 A｜企业 B｜企业 C｜差异与优劣势”的比较表填写实际数值、做法或特征；企业或维度较多时可分表，但同一维度应覆盖各家。每项差异说明谁相对更强或更弱、适用于什么市场或客户，再归纳各家最突出的特点、优势与短板。不能只列待查字段、逐家简介，或每家挑一款产品就代表整家企业。

比较各家在客户、价位、应用场景或地域中的强弱分布，分清已经布局与确有优势。用可查到的赢单、失单、客户迁移、渠道进入或退出等检验竞争判断，说明实际得失与原因；个别案例不代表整体胜率。

背景、投资者和投入规模不直接等于优势，要说明资源怎样转化为产品、获客、效率或经营结果，以及能否持续。用户评价注明平台、时间和样本范围，不把可见评论当成全体用户意见。

企业较多、竞争方式有明显差异时，可按产品定位、直销／渠道、单点产品／一体化方案等关键差异归类。写明各类企业及归类依据，再解释这种方式如何影响获客、成本、交付或客户切换。同一企业不同业务可以分属不同类型；不为凑矩阵强画象限。

价格与性能比较注明对应产品和条件，宣传主张与实测、承诺与履约分开；缺失值写明未知，不算零分，也不以披露多寡判断强弱。

比较后归纳各家的竞争特点，再判断哪些优势可持续：成本效率、规模、技术积累、关键资源、认证、切换成本、生态或网络效应为何难以复制，依赖什么条件；复用前面的事实，不另抄一遍各维度。

### 4. 标的企业分析（企业研究时）

在企业横向比较的基础上，单拉一章分析目标企业，不以突出表中一行代替：

| 内容 | 要回答的问题 |
|---|---|
| 地位 | 在行业及主要细分市场处于什么位置？相对哪些对手领先、落后或正在变化？谁正威胁它的哪块业务，通过什么方式，有哪些实际动作？ |
| 优势与劣势 | 相对主要对手，强项与短板是什么？各有什么依据，在哪些客户、区域或业务上成立，能否持续？ |
| 问题与痛点 | 当前出了什么问题、原因是什么？哪些持续约束造成成本、效率、客户流失或增长损失？区分企业自身问题、行业共性压力与尚未发生的风险 |
| 关键风险与承压能力 | 什么变化会使当前优势或策略失效，影响哪些业务？面对价格战、关键客户流失、渠道变化或技术替代等压力，有哪些资金、客户、供应和组织上的应对余地？列关键触发条件与观察信号 |
| 机会 | 哪些需求、技术、渠道或竞争变化有利于它？为什么它可能拿得到，现有基础与缺少的能力是什么，还有谁在争夺？说明进入代价、必要条件与风险 |
| 策略 | 企业正在采取或已宣布什么行动，针对什么问题或机会，效果如何？研究建议另行标明；对有实际意义的选择比较收益、代价、资源取舍和适用条件，说明优先方向及需验证的结果，不硬给唯一答案 |

只做行业研究时不设本章；行业与企业一起研究时，保留行业的平行比较，再独立分析标的企业，共用前文事实，不重复抄表。局部比较或单一问题只展开相关内容。
