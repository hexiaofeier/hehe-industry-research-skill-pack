# 竞争格局分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告。用户明确不落文件时，在对话中按第二节结构完整交付。

Excel、CSV 或图形只在第三节所列条件触发时生成；简单比较不附空白底表或装饰性图形。

## 二、Markdown 主报告

### 完整度与展开要求

先确定输出模式：

- **完整专项报告：** 用户要求完整、深度或系统研究，或者本专项被纳入 `hehe-industry-researcher` 的完整研究时使用。必须覆盖本模板列出的适用主体章节。
- **局部专项答复：** 只在用户明确询问一个局部问题或明确要求简版时使用，只展开与该问题直接相关的章节。
- **有限披露报告：** 只在关键资料确实不足时使用；仍需充分分析现有证据能够支持的内容，不能只交缺口清单。

完整报告的核心主体章节不能只有标题、事实清单、新闻罗列或一张没有解释的表。每项主要结论应有相称的证据或计算，并解释关键机制、差异及其含义；成立条件或翻转点按其对判断的实际影响展开。表格之后解释最重要的差异和意义。

**读者导向的写作与删减**

- 正文围绕结论、证据、推理及其含义展开。删掉后不影响读者理解和判断的解释，直接删除。
- 会改变结论的口径、假设、条件和风险融入相应判断；同一事项集中说明一次，保留原有判断强度。
- 内部审核、资料取舍和研究执行过程留在底稿；正文只呈现其对结论的实质影响。
- 摘要、标题、正文、表格、图注及图内脚注统一执行；任何篇幅下均适用，不为字数目标补回无效解释。

**完整模式正文目标体量：** 完整行业或企业单线分析一般为 5,000—8,000 汉字；同时覆盖行业格局与标的企业时一般为 7,000—13,000 汉字。 这是完整度检查线，不是写作配额；交付前必须实际统计正文字符数并记录结果。统计只包括推进本题结论的分析；来源清单、原文摘录、附录长表、方法或交付说明、验收记录、通用边界和更新流程不计入，也不得跨专项复制或批量套用同一句式后只替换变量。低于下限时先逐项复查并补足被压缩的核心能力；实质分析已经完整且差距不超过下限 10% 时，可记录偏差后交付，不得为贴线补字。差距超过 10% 且不属于局部或有限披露模式时，不得作为完整专项报告交付。超过上限时检查重复结论和同义改写。


完整任务先给结论，再按以下顺序展开；局部比较只保留回答当前问题所需的章节，保留章节连续编号：

| 顺序 | 报告部分 | 主要内容 |
|---:|---|---|
| 1 | 核心摘要 | 一句话回答当前格局，再列三至六项关于领先者、集中度、竞争变化、标的相对位置或关键风险的主要结论及证据 |
| 2 | 研究范围 | 行业或细分市场、产品与业务口径、地域、时间、客户范围、份额指标、研究对象及必要的包含与排除 |
| 3 | 行业与参与企业 | 列出主要企业、相关业务或代表产品、客户与区域、市场角色或特点；影响判断的进入、退出或转向一并说明 |
| 4 | 集中度、份额与格局变化 | 列所用指标的企业数值、市场总量、份额、集中度及可比历史变化；解释领先原因与持续性、重要变化及后续观察点；涉及进入或替代压力时，说明门槛、现有企业的应对和影响条件 |
| 5 | 核心企业比较 | 按主 Skill 第三节选择共同维度，列“维度／各家企业／差异与优劣势”的横向比较表；按课题呈现客户与收入依赖、合作生态、资源配置、细分市场强弱及实际竞争得失。采用竞争方式归类时，注明成员、依据及其经营差异；末尾归纳各家特点与优势持续性 |
| 6 | 标的企业分析（企业研究时） | 分别说明目标企业的地位与主要威胁、优劣势、问题痛点、关键风险与承压能力、机会及策略。机会写清可获得条件，策略写清选择与取舍，区分企业实际行动与研究建议；最后归纳靠什么立足、最受什么制约、值得争取什么、需要防范什么 |
| 7 | 综合判断与观察点 | 形成方向明确的格局、企业优势持续性或标的机会命题，说明成立条件、反例、替代解释、翻转信号及后续观察指标 |
| 8 | 其他说明、附录与待补证内容（按需） | 放长表、详细计算、来源明细、不可比较项、未验证推断和会改变结论的补证任务 |

- **行业研究：** 各核心企业平行比较，不围绕某一家解释整个行业，不设标的企业章。
- **企业研究：** 行业背景简述，比较目标企业与主要对手，再单列标的企业分析章。
- **行业与企业一起研究：** 先完成行业格局和核心企业的平行比较，再单列标的企业分析章；复用事实，不省掉任一层分析。
- **局部比较：** 只展开回答当前问题所需的内容。

核心企业比较的小结可用表格：`企业｜主要竞争方式｜突出优势｜主要短板｜优势所在的细分市场`。这是对前文的归纳，不重复列营收、产品和人员数据。具体维度与风险按课题选择，可合并在原有表格或段落中，不逐项另开章节或附件。

报告应有企业名单、可支持的格局判断和实际比较结果，不用方法清单或空表替代分析。资料不足的部分说明缺口及影响，搜索与补证按[专项工作流程](专项工作流程.md)执行；不影响其他已有依据的比较。

## 三、其他交付物

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 需要计算多期份额、CRn/HHI、增长贡献、口径调整或敏感性 | 带公式 `.xlsx` | 范围口径、企业与市场总量输入、来源、公式、结果、历史期和检查项 |
| 多企业、多指标比较表需要后续交换或程序处理，但没有公式 | `.csv` | 企业、业务、地域、期间、指标定义、数值、来源、证据状态和不可比项 |
| 格局演变或战略群组用文字和表格难以说明，且用户要求图形 | 可编辑图源及展示图 | 图中对象、维度、时间和数据与报告一致；不以图代替比较依据 |
| 计算和比较均能在主报告中完整呈现 | 不生成附件 | 在 Markdown 中保留必要公式、企业表和来源 |

Mermaid、HTML 和展示图不是默认交付物。同行名单多本身不触发 Excel；只有复算、长期维护或数据交换需要时才生成。
同一数据表需要公式时使用 Excel；只交换无公式长表时使用 CSV，不同时生成两份重复附件。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由时使用任务卡指定位置；单独启动时默认保存到当前任务工作文件夹；用户指定位置时按其要求保存。
- 主报告：`YYYYMMDD_研究主题_竞争格局分析.md`。
- 附件：`YYYYMMDD_研究主题_竞争格局分析_附件名称.扩展名`，附件名称写具体用途，如`市场份额模型`、`企业比较表`。
- 研究主题写清行业或细分对象，企业研究加企业名；版本号按需添加。用户或项目另有命名规则时优先遵守。

## 五、信息缺口

只有缺口会改变企业范围、份额分母、集中度、竞争优劣势或标的判断时，才建立补证任务：

`待证主张｜企业/业务｜指标与分母｜地域/期间｜所需原始材料｜可接受替代｜不可比较项｜影响章节｜补充后如何更新`

未解决缺口只限制相应份额、企业或结论，其余已有依据的比较继续完成。

## 六、交付条件与交付前检查

行业边界、参与企业、比较口径和核心格局判断已经闭合，新增一般企业或低影响资料不会改变主要结论时即可交付。交付前检查：

- 核心摘要先回答当前格局及主要企业差异，研究范围单独成节；
- 企业名单覆盖研究问题所需的主要参与者，进入、退出和业务转向已按时点处理；
- 份额分子与分母、地域、时期和指标一致，集中度计算可复核；
- 核心企业使用共同维度比较，不用一家企业的长画像代替横向分析；
- 企业事实、格局推断和研究建议分开，优势结论包含持续条件和反例；
- 报告与附件的企业、指标、公式和数值一致，实际文件清单和链接可打开。
