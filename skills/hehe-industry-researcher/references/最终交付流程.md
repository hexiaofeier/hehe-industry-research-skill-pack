# 最终交付流程

## 最终汇总与成文

完成专项交付审核后，所有已定稿的专项交付物交由 `hehe-industry-researcher` 汇总成文，并形成交付用户的最终 Markdown 主报告。综合研究默认交付 Markdown 定稿、HTML 阅读版及约定附件；HTML 的制作方式按下文“HTML与其他视觉报告”选择。最终文件按[研究项目目录模板](研究项目目录模板.md)保存到 `03_最终交付/` 或已有项目的对应位置。汇总可以去重和提炼，但不得删除、覆盖或以总报告短章节替代已经验收的独立专项报告。

提纲、写作底表、草稿和交付质检单如需落文件，放在 `03_最终交付/过程稿/`；通过检查的报告定稿放在 `03_最终交付/` 本层。报告命名用 `YYYYMMDD_研究主题_文本研究报告.md`；用户或项目规范优先。

由 `hehe-industry-researcher` 按本流程整合为完整、连贯、可编辑的 Markdown 报告，要求结构清晰、核心结论有依据、证据丰富、推理完整，避免逻辑漏洞和前后矛盾。已成型研究报告不调用 `hehe-report-writing` 的“文本报告独立撰写”模块。

**文字润色与定稿。** 整合稿形成后，保留一份润色前稿于 `03_最终交付/过程稿/`，原稿已存在时直接沿用；若 `hehe-report-writing` 已安装且可用，默认调用润色模式，重点处理综合稿的组织、改写与新增论述，已润色的专项原文不重复处理；未安装、无法读取或用户明确跳过润色时，沿用原有成文与自审规则。随后由 `hehe-industry-researcher` 复核事实、数字、引用、有效条件、分析深度及跨专项衔接后定稿。分析或计算问题返回对应专项修正；返修只处理受影响部分。

**读者导向的写作与删减**

- 正文围绕结论、证据、推理及其含义展开。删掉后不影响读者理解和判断的解释，直接删除。
- 会改变结论的口径、假设、条件和风险融入相应判断；同一事项集中说明一次，保留原有判断强度。
- 内部审核、资料取舍和研究执行过程留在底稿；正文只呈现其对结论的实质影响。
- 摘要、标题、正文、表格、图注及图内脚注统一执行；任何篇幅下均适用，不为字数目标补回无效解释。

交付前有 `baojie` 则执行成稿核对，核对事实、计算、引用、推理及报告与附件的一致性；未安装时由 `hehe-industry-researcher` 自行完成这些检查。Markdown 可先核对，随后形成或修改的 HTML、PDF、PPT 及附件补查新增文件和受影响内容，沿用其他已完成的检查。发现问题时，只返回受影响的分析、审核或制作环节处理，修正后复查实际交付文件。

## HTML与其他视觉报告

综合研究默认交付 HTML，按实际安装情况执行：

| 安装情况 | 综合报告制作方式 |
|---|---|
| 未安装 `hehe-report-presentation` | 使用随包[HTML报告交付规范](HTML报告交付规范.md)、模板及生成器制作基础侧栏 HTML，不受 `hehe-report-writing` 是否安装影响 |
| 已安装 `hehe-report-presentation`，未安装 `hehe-report-writing` | 直接用 Markdown 定稿制作带侧栏目录的下拉 HTML，无需分页脚本 |
| 两者均已安装 | 主动提供下拉 HTML、16:9／9:16／A4 翻页 HTML和可编辑 PPT 的形式选择，说明默认下拉 HTML；选择 PPT 时同时保留 HTML 阅读版，PDF 随所选形态交付 |

选择由 `hehe-industry-researcher` 集中确认，专项不分别追问；已有明确要求直接沿用，不重复询问。下拉 HTML 直接使用定稿；翻页 HTML 或 PPT 在需要编排时使用已安装的 `hehe-report-writing` 分页模块，已有合格逐页稿直接使用。两者均已安装时，主动介绍上述形式并说明默认交付带侧栏目录的下拉 HTML；用户没有选择其他形式时完成默认版，不等待回复而留下缺失的 HTML。用户明确取消 HTML 时遵从其要求。

单独专项研究仍按原交付规则：未安装 `hehe-report-presentation` 时不增加整份视觉报告；已安装但无 `hehe-report-writing` 时，主动询问是否增加下拉 HTML；两者都有时，主动询问是否制作视觉报告并提供上述形式选择。用户选择制作后执行，拒绝则不增加；已有明确要求直接沿用。

交接定稿、图表与数据、来源、附件入口及用户要求，保留全部实质内容。按实际使用的呈现规范分别检查内容、视觉及技术：HTML 核对离线阅读、目录导航（下拉版含侧栏）、图表、来源、窄屏和打印；PDF 核对尺寸、颜色及页眉页脚；PPT 核对可编辑性。未完成的已约定文件继续制作，交付清单注明实际状态。产业链图形预览、竞争图、公式 Excel 等原定分析附件不受整份视觉报告选择影响。

### 已安装但运行条件不足

先按呈现 Skill 的依赖清单检查实际执行环境，复用可用环境或补齐本次所需依赖。Markdown 解析包缺失且暂不能补齐时，把定稿按原标题、完整段落、表格和引用转成 HTML 正文，放入 `canvas: scroll` 的 JSON 页面源，使用 `hehe-report-presentation` 现有标准库生成器制作带侧栏的下拉报告；逐项与原稿核对。呈现 Skill 本身无法读取或执行时，回到随包基础 HTML 模板；原生成器也缺解析包时，直接将已核对的正文和目录填入模板，不重复调用同样缺依赖的转换器。缺 Python 时可直接填充 HTML 模板。

缺浏览器只影响自动渲染检查、PDF 或 PPT 转换，不妨碍生成 HTML。已约定的 PDF／PPT 继续用可用工具完成；确实无法制作时，交付已完成文件并写明缺项及所需环境，不将未生成文件记为完成。HTML 内仅提供实际存在的 PDF 下载入口。研究与 Markdown 定稿照常推进。

## 交付内容清单

默认对外交付包括：

1. 一份整合后的可编辑 Markdown 主报告；
2. 综合报告默认的 HTML 阅读版，以及用户另选的视觉报告、相应可修改源文件和 PDF；
3. 各专项实际触发的 Excel、图源、结构数据表或其他必要附件；
4. 一份与实际文件一致的交付清单，包含本次 Skill 调用情况。

开题记录、材料索引、专项任务卡、各专项完整底稿、证据台账、审核记录、矛盾处理表和写作过程稿保存在项目目录中，供复核和续作使用；只有用户要求，或它们对理解结论确有必要时才随最终成果交付。主报告只保留会改变结论的口径、限制和待补证事项。

完整报告按平行章节展开：`核心摘要 → 研究范围与口径 → 按研究问题组织的报告主体 → 其他说明、附录与待补证内容（按需）`。核心摘要必须是首个正文章节，直接给出主要结论、关键证据及其决策含义。

总报告只能有一个一级标题。独立专项报告留在 `02_专项分析/` 并由调用表或交付清单链接；总报告正文不得再出现“某某专项报告”标题，不得把各专项原文依次改级拼接。正文按研究问题综合事实、计算和跨专项判断，同一证据只在最能推进结论的位置展开。

Skill 调用情况表放在交付清单中。字段为：`类别｜Skill｜状态｜本次职责或产物｜未调用或降级原因｜对完整性的影响`。主 Skill、`hehe-report-writing`、`hehe-report-presentation`、实际调用的辅助 Skill 和 13 个专项 Skill 均一行对应一个 Skill，13 个专项不得合并成一行；不罗列与本题无关的工具。专项状态与专项验收矩阵一致；`hehe-report-writing` 注明实际润色的报告或“未安装，沿用原流程”，`hehe-report-presentation` 注明实际制作的文件、用户未选择或未安装时使用的基础 HTML 方案；两者未安装不记为研究缺失。公开版使用实际加载的 `hehe-*` 名称。

完整综合报告的正文目标体量为：完整行业研究 25,000—40,000 汉字；完整企业研究 20,000—30,000 汉字；行业+企业研究 40,000—60,000 汉字。交付前实际统计正文字符数并写入交付检查；低于目标下限时先补足缺失的分析、证据和推理，实质分析完整且差距不超过下限 10% 时可记录偏差后交付，超过 10% 则不能称完整报告。正文中的实质分析和表格计入，来源清单、原文摘录、附录长表、验收记录、字数说明、交付状态和通用更新流程不计入。报告不得设置只为补体量的“深化复核、验收补充、字数补充、结尾复核”等章节，不得机械拼接专项全文、复用通用段落、批量套用同一句式后只替换变量，或追加零散补句；此类内容应删除后重新计数。不得在写作过程中按“还差多少字”追加内容；高于上限时检查重复，不以字数替代核心能力、证据和论证。

本题适用且影响完整性的专项均已完成时，可称完整行业研究或完整企业研究。应调用的专项因未安装或不可用而缺失时，标题和摘要标明“有限范围”，列出未评估部分及其对结论的影响；因本题不适用而不调用的专项不算缺口。

按研究问题和实际完成的分析组织章节；未完成的部分说明缺口，不为凑章节补写结论。

行业研究内容可参考：
`核心摘要｜研究范围与口径｜市场规模与预测｜产业链结构｜主要商业模式｜市场竞争格局｜宏观与政策传导｜趋势阶段｜发展驱动力｜行业痛点｜投资逻辑与机会（如适用）｜其他说明、附录与待补证内容（按需）`

企业研究内容可参考：
`核心摘要｜研究范围与口径｜主体与披露边界｜业务和经营验证｜市场/产业位置｜商业模式｜竞争位置｜增长与财务质量｜治理和资本配置｜外部暴露与趋势｜风险与反例｜估值/投资（如适用）｜其他说明、附录与待补证内容（按需）`

## 单独专项研究简化

单独专项研究按所选各专项 Skill 自己的交付规则交付结果，不另行生成完整行业或企业报告。分析中发现的缺口或矛盾会实质影响结论时，需在交付中明确标注，不得隐去不表。
