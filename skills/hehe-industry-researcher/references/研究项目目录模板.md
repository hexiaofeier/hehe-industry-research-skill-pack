# 研究项目目录模板

`hehe-industry-researcher` 在开题时确认研究文件夹位置，并建立本次需要的目录；单独专项研究在对话确认问题后完成这一步。已有项目沿用原目录，将下列用途对应到实际位置。

```text
研究主题/
├─ 00_开题与任务/          # 开题记录、专项任务卡
├─ 01_材料库/              # 材料索引放在本层
│  ├─ 已有材料/            # 用户已有材料放在本层
│  ├─ 搜索材料/            # 搜索方案、报告、原文、摘录和原始记录，含专项补搜材料
│  └─ 审核结果/            # 资料及专项审核、证据台账、矛盾与补证记录
├─ 02_专项分析/            # 各专项的底稿、报告、模型和附件，文件平铺，不分行业研究/企业研究
└─ 03_最终交付/            # 完整 Markdown 主报告、同内容 HTML 阅读版及约定附件
   └─ 过程稿/             # 报告提纲、写作底表、草稿和交付质检单
```

- `01_材料库/已有材料/` 始终保留，其他分支按实际需要创建。单独专项研究的成果放在 `02_专项分析/`，完成后直接交付。
- `hehe-industry-researcher` 将保存位置交给搜索、审核和写作能力；专项的交付目录写在任务卡“预期交付”中。
- 文件统一用 `YYYYMMDD_研究主题_成果名称.扩展名`；企业研究在研究主题中加企业名，专项成果名称按各专项规定，附件写清具体用途。完整研究的 Markdown 与 HTML 使用同一文件名主体。草稿或多版本在成果名称后加 `_草稿`、`_v2` 等；用户或项目另有命名规范时优先遵守。
- 用户提供的本地材料复制到 `01_材料库/已有材料/`，保留原件；已在该目录中的材料不重复复制。
- 继续研究时，读取开题、索引、任务卡和实际交付文件确认进展。
