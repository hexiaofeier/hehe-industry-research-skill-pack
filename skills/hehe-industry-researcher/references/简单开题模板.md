# 简单开题模板

行业研究、企业研究和行业+企业研究共用一份开题模板。
单独专项研究用相关字段做对话确认，需要保存时也用本模板。
开题记录要简洁精悍，先预填，再让用户确认真正影响研究的边界。不适用的字段可省略，未确定的内容注明待确认或待补。
开题环节尽量简捷，开题记录中除了必填维度的确认外，不得因任何非关键维度缺失而阻塞开题推进。

```markdown
# [研究主题]：研究开题

## 开题记录

- 【必填】研究类型：行业研究、企业研究、行业+企业研究、单独专项研究
- 研究目的：重点了解什么、结果用于什么、其他
- 【必填】研究对象：本次研究关注的行业、企业、业务、产品、技术、模式、其他
- 业务/产品/赛道范围：包括什么、不包括什么
- 地域范围：全球、中国、省市地区、其他
- 时间范围：
- 关键口径、单位或分母（已有明确要求时填）：记录用户约定；尚需搜索或分析才能确定的内容留到后续。
- 【涉及企业研究必填】标的企业：填写企业名单；尚未选定时，说明由用户指定还是 Agent 推荐
- 标的研究范围：公司整体或某项业务/产品；重点关注历程、团队、业务、产品、技术、模式、用户、营收、利润、战略、估值、投资视角等
- 已有材料及位置：
- 【必填】是否开展新一轮信息搜索：
- 其他要求（如有）：

```

## 填写示例

主题：研究中国个人用户使用通用 AI 工具的市场与需求，并研究相关企业业务。

| 开题项目 | 示例填写 |
|---|---|
| 研究类型 | 行业+企业研究 |
| 研究目的 | 重点了解个人用户 AI 工具主要使用场景、用户需求、竞争选择和付费情况，为C端产品定位与市场进入判断提供参考。 |
| 研究对象 | 面向个人用户提供问答、写作、总结、搜索、研究、代码或多模态协助的通用 AI 助手。 |
| 业务/产品/赛道范围 | 包含 ChatGPT、Claude、Gemini、DeepSeek、豆包、Kimi、Workbuddy 等通用 AI 助手及其个人订阅，包含对话机器人和 Agent工具；不包括to B的AI工具与系统、单功能的垂直 AI 工具（如写作、绘图、视频、教学工具）、以及不含 AI 能力的普通软件。 |
| 地域范围 | 中国大陆用户；国产与海外产品分别记录，不把全球数据直接当作中国数据。 |
| 时间范围 | 观察近一年，材料截至本次搜索日；如需预测，另行确认预测年限。 |
| 关键口径、单位或分母 | 用户规模区分注册用户、月活用户和付费用户，下载量单列；个人订阅费与 API 费用分列，订阅费按人民币/月比较，API 费用保留实际计费单位，需要换算时注明使用量假设；产品数据与公司数据不混用。 |
| 标的企业 | 候选为腾讯（元宝、Workbuddy）、字节跳动(豆包、豆包办公)、阿里巴巴（千问、千问办公）；名单有可能在研究过程中增加。 |
| 标的研究范围 | 各公司的个人通用 AI 助手业务，关注产品、技术、收费方式、用户获取及竞争；不把集团整体数据当作该业务数据。 |
| 已有材料及位置 | 暂无；需要从头搜索信息。 |
| 是否开展新一轮信息搜索 | 需要；先搜行业资料，再补选定企业的相关业务资料。 |
| 其他要求 | 暂无。 |

**开题文件命名规则**：`YYYYMMDD_研究主题_开题记录.md`。保存位置见[研究项目目录模板](研究项目目录模板.md)。
