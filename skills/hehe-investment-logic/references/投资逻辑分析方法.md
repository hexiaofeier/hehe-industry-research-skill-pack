# 投资逻辑分析方法

本文件保存 `hehe-investment-logic` 共用的五步分析方法。先按主 Skill 确定研究对象并读取对应模式，再执行以下步骤。

## 第一步：明确研究对象和工作论点

把任务改写成带研究对象、进入方式和期限的判断问题；用户明确研究角色时再加入角色。例如：

- 对某类长期资本而言，这个产业环节是否进入值得继续研究的布局窗口；
- 某公司未来三年的经营兑现与当前估值之间是否存在需要验证的预期差；
- 当前增长是结构性机会、周期恢复还是短期情绪，哪种证据能区分它们。

写一句待验证的工作论点：

`研究对象｜如何进入｜资金付给谁并取得什么｜价值来自哪里｜为什么是现在｜靠什么兑现｜什么会证伪｜研究角色（如有）`

工作论点是待验证假说，不是先写好的结论。

## 第二步：比较投资方向并建立价值与回报实现链

从任务相关维度中选择，不固定数量：

- 市场空间与结构变化；
- 产业链稀缺、瓶颈与价值转移；
- 商业模式与单位经济；
- 技术拐点与商业化条件；
- 用户需求与采购行为；
- 竞争格局与进入/替代压力；
- 宏观、政策和资本约束；
- 公司经营、财务、治理和资本配置；
- 战略协同、控制权或交易条款。

行业机会模式先把可投资方向列全，再比较：

`方向｜价值来源｜需求与经营验证｜竞争与壁垒｜资本需求｜为什么是现在｜主要风险｜判断`

按证据把方向分为 `优先考虑｜有条件考虑｜继续观察｜暂不考虑`，并写明排序理由。排序不是固定打分；只有能够解释价值如何产生、谁能捕获、何时兑现及为何优于其他方向，才可列为优先。

企业、项目、上市证券或具体交易不必重做完整行业地图，但要说明对象依赖的行业机会、价值环节和兑现路径。

核心投资论点使用下列论证链；辅助发现按其对判断的实际影响展开，共用条件集中说明：

`[事实/计算] 起点 → [推断] 因果机制 → 经营或价值结果 → 成立条件 → 领先/同步/滞后指标 → 反方解释 → 失效条件`

不得只写“政策支持、市场很大、技术领先、需求旺盛”。必须说明这些因素如何传到可获得收入、利润、现金流、资本效率、协同价值或退出可能性。

再判断回报可能来自哪些来源：

- 行业或公司经营增长；
- 份额、价格、产品/客户结构或留存改善；
- 毛利、费用、营运资本、资本开支或现金转换改善；
- 估值变化或价值发现；
- 分红、回购、利息或其他现金回报；
- 战略协同、控制权、资源获取或交易条款；
- 私募股权的里程碑兑现与退出价值。

写成：

`价值来源 → 现实兑现机制 → 所需时间 → 所需投入/稀释 → 可观察结果 → 主要泄漏项`

经营、财务、治理和估值依据可从原文核对，也可复用现有分析。缺参数先定向补证；合理假设注明依据和范围，再测算其对判断的影响。

**解释决定回报的经营假设。** 选出一至三个关键驱动，写清“当前实际表现 → 变化原因及证据 → 未来取值 → 所需投入”。例如，销量增长对应客户、渠道或产能兑现，利润率改善对应价格、产品结构或成本变化。管理层目标与研究判断分别保留；用历史兑现和可比对象检验幅度与时间，再判断投资论点是否站得住。

**把资金缺口接到投资条件。** 检查增长、还债、分红与回购所需现金能否由经营和现有资金支持；融资缺口对应融资时点、条件和新增股数。判断融资完成、延期或无法完成分别如何改变里程碑、持股比例和回报；投资人需要跟投时计入追加现金流。复用模型中的现金与股数路径，避免只提高盈利、同时假设分红回购和持股比例都不受影响。

**把经营结果接到投资人回报。** 已有价格或交易条件、且输入支持时，列出初始投入、期间回款、追加投入、稀释、退出所得及发生时间，按实际路径计算：

- 上市股权：单次买入且不追加、分红不再投资时，持有期回报＝（退出价格＋累计每股分红－买入价格）÷买入价格。按适用方法解释每股盈利/现金和估值变化的贡献；回购已通过股数或每股指标反映时，不再当作该持有人的额外现金回报。
- 非上市股权与并购：企业价值先经净债务等调整得到股权价值，再按稀释后持股和实际分配条款确定投资人所得；输入已是股权价值时不重复扣债。后续融资同时检查新增资金用途和稀释；参与追加投资时同步计入现金流出及新增权利。
- 项目、债权与混合工具：按实际时点列投入、分配、本息、转换或处置所得，区分项目整体和投资人现金流。
- 已全部退出时，MOIC（投资回收倍数）＝累计回收÷累计投入；尚有持仓时单列剩余价值，说明所报倍数含未实现部分。多期收支按实际日期用公式或脚本计算年化 IRR；异常现金流导致多解或无解时，列现金流并以明确折现率的 NPV 辅助判断。税费、币种和时间口径前后一致。

按输入支持程度给出点值或情景区间，说明回报主要依赖经营改善、重估还是条款。没有进入价格的行业筛选仍先比较方向与兑现条件。

## 第三步：按对象完成比较或结构核查

行业机会模式建立候选企业池：

`候选企业｜对应优先方向｜相关业务暴露｜经营验证｜可进入方式/交易状态｜核心优势｜主要短板｜估值/交易条件｜入选理由｜待核查问题`

- 企业与方向的关联必须落到产品、客户、订单、收入、利润、现金、产能、资质或其他经营事实；不能只凭概念标签入选。
- 比较谁更能捕获价值、谁需要更多资本、谁的兑现证据更强，以及当前价格或交易条件是否已经反映预期。
- 材料不足时保留候选并标注待核查，不把知名度当作优先级。

企业模式把目标企业与主要可比企业或替代标的放在同一组有效维度下比较：

`企业｜行业位置与业务暴露｜增长｜盈利与现金｜资本效率｜竞争优势｜治理与风险｜估值/交易条件｜催化剂｜投资吸引力判断`

比较后直接说明目标企业相对位置、优先于谁、弱于谁，以及差异来自经营质量、价格预期还是交易条件。若用户只问一家公司，也不能只写公司自身优点；没有可比材料时先补搜或明确比较缺口。

- **项目：** 列清项目边界、参与方、权责、投入、里程碑、收入成本现金、资金缺口、投资载体和退出条件；必要时比较替代项目或不投资方案。
- **上市证券：** 比较当前证券与主要可比证券，核对价格、估值、资本结构、稀释、流动性和证券层风险，不用公司优秀代替价格判断。
- **具体交易：** 还原交易结构、定价、资金去向、所得权利、交割条件、审批和退出；必要时比较不交易或替代交易方案。

## 第四步：判断为什么是现在、投资人适配和三种情景

至少区分四类时机：

1. **行业阶段**：技术、供给、需求、经营验证和结构变化到了哪里；
2. **公司里程碑**：产品、客户、订单、收入、利润、现金或组织能力何时可能跨越关键节点；
3. **估值/交易条件**：当前估值或条款反映了什么假设，数据日期和方法是否适用；
4. **催化剂**：事件如何影响指标、何时可观察、靠什么兑现、哪里可能失败。

催化剂写成：

`事件 → 传导路径 → 可观察指标 → 预计时间窗 → 兑现条件 → 失败风险`

“近期有政策/发布会/融资/新品”本身不构成投资时机。

同时核对市场共识与预期差：

- 市场或交易参与者普遍在相信什么；
- 当前价格、估值、交易条款或资本行为可能隐含什么；
- 本研究在哪个关键变量、时间、机制或结果上不同；
- 如果共识其实正确，研究论点会怎样失效；
- 预期差何时、通过什么指标被市场或交易对手看见。

没有可追溯的共识材料或估值输入时，只能写“可能的分歧假设”，不得宣称存在确定预期差。

将影响最大的分歧落到具体变量：`变量与期间｜市场/交易对手预期及依据｜本研究判断及依据｜差值对经营与回报的影响｜验证信号与时点`。管理层指引、分析师一致预期和价格反推值分别标明；反推需固定其他假设，所得组合不自动等于市场共识。表后解释分歧为何存在、是否足以改变选择。

**用历史参照校准关键假设。** 针对增长持续期、利润率爬坡、资本需求或退出时间等决定性假设，选择同阶段、相近规模与商业模式的历史对象，比较实际路径及成功、平庸或失败结果。写清目标为何可能更好或更差；参照不足时用案例和区间判断。百分位或成功率须有可核对的样本、分母和期间。多个乐观假设同时成立时检查相互依赖，例如降价扩张与利润率提升是否相容，不直接把相关事件的概率相乘。

再按 [投资方式与交易路径](投资方式与交易路径.md) 核对所选路径的交易事实、资金去向、所得权利、价格或条款、进入条件和退出限制。战略投资项目还要比较自建、采购、合作、合资与投资等替代方案，并分开说明财务回报和战略回报。只分析当前任务实际相关的路径，输出适配条件与不适配原因。

每个情景至少写：

`关键变量｜触发条件｜传导路径｜经营/价值结果｜时间窗｜可观察指标｜退出或暂停判断条件`

- **基准情景**：当前证据最能支持的路径；
- **上行情景**：哪些额外条件同时成立才会出现；
- **下行情景**：需求、竞争、成本、治理、融资、政策或估值冲击如何传导。

各情景使用一致的进入条件、计量口径和明确的时间安排，把经营变化接到回报结果。识别一至三个最可能翻转结论的变量，输入支持时测算盈亏平衡或达到本题回报要求所需的临界值，说明哪项先失守。回报要求注明来源；概率加权仅在本题需要时使用，概率说明依据或假设、检查合计为100%，并检验结论对概率的敏感性。

区分两种反推：估值反推回答“当前价格需要怎样的经营表现支撑”；回报反推回答“在给定经营与退出情景下，什么进入价格、条款或退出条件能满足投资人的回报要求”。后者得到的是投资条件边界。解释它与模型价值区间的差异，不能直接把目标收益率当成企业资本成本。

同一项目已有估值计算时，核对并沿用其对象、时点、币种、情景、经营预测、融资与股数版本，以及各时点价值结果和公式位置。需要改变假设时，在共享模型中增列情景并同步两份报告；投资逻辑正文解释取舍、回报和行动条件，详细估值推导留在估值模型及报告。

## 第五步：用反方检验后给出投资选择

风险必须连接到逻辑本体：

`风险事件 → 暴露对象 → 传导环节 → 收入/利润/现金/估值/协同/退出影响 → 领先指标 → 缓冲因素 → 证伪或退出条件`

至少提出一个最强反方论点，并回答：

- 哪些现有证据支持反方；
- 主论点与反方分歧在哪个可观察变量；
- 什么证据会推翻反方，现有反证是否足以改变主论点；
- 多久以后仍未兑现，应当降级或退出逻辑；
- 什么新事实出现时必须暂停当前判断，并重新核对相关基础分析。

最后区分两种退出：

- **投资逻辑退出**：定义假说不再成立的条件、观察频率、容忍时滞和复核责任。不能用不断延长时间窗来逃避证伪。
- **经济退出**：按投资工具说明潜在退出方式或流动性来源、所需里程碑和市场条件，以及锁定期、交易深度、买方集中、审批、控制权或契约约束。

同时说明退出失败、折价、稀释和时间延长风险。若没有足够资料，只列“待验证退出条件”，不得承诺可退出或实现收益。

结论分三层表达：

- **投资选择**：`优先考虑｜有条件考虑｜继续观察｜暂不考虑｜资料不足`；
- **投资逻辑状态**：`成立｜条件成立｜不成立｜暂不判断`；
- **交易可执行性**：`可进入｜有条件可进入｜暂不可进入｜未发现交易机会｜待核实`。

第一句话先回答是否值得投以及当前如何进入；再说明本研究对象最重要的选择、比较结果和原因。结论要写清研究对象、期限、价格或交易条件；用户已说明研究角色时，再写清为谁判断。如果只能做历史或初步筛选，应直接标明。

**有旧报告或要求复核时：** 保留原报告与预测，按 `原论点/预期及日期｜新事实与来源｜变化原因｜对回报及三层结论的影响｜下一验证点` 更新。对已到期预测记录兑现情况，区分经营兑现、时间推迟、假设错误和价格预期变化。公司经营改善但价格上涨更快时，投资吸引力可能下降；股价上涨本身也不证明论点兑现。首次研究不生成空更新表，局部更新只展开受影响判断。
