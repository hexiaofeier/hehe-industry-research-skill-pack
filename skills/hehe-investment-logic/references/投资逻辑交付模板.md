# 投资逻辑交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告，并在对话中反馈核心结论和文件位置。用户明确不落文件时，在对话中按第二节结构完整交付。

Excel 或 CSV 只在第三节所列条件触发时生成。投资逻辑卡和完整分析都是 Markdown 主报告的深度选择。

## 二、Markdown 主报告

### 完整度与展开要求

先确定输出模式：

- **完整专项报告：** 用户要求完整、深度或系统研究，或者本专项被纳入 `hehe-industry-researcher` 的完整研究时使用。必须覆盖本模板列出的适用主体章节。
- **局部专项答复：** 只在用户明确询问一个局部问题或明确要求简版时使用，只展开与该问题直接相关的章节。
- **有限披露报告：** 只在关键资料确实不足时使用；仍需充分分析现有证据能够支持的内容，不能只交缺口清单。

完整报告的核心主体章节不能只有标题、事实清单、新闻罗列或一张没有解释的表。每项主要结论至少完成“结论 → 关键证据或计算 → 机制、比较或变化原因 → 对本题的含义 → 成立条件或翻转点”的闭环；表格之后解释最重要的差异和意义。

**完整模式正文目标体量：** 完整投资逻辑分析一般为 7,000—13,000 汉字；范围明确的投资逻辑卡一般为 2,500—4,000 汉字。 这是完整度检查线，不是写作配额；交付前必须实际统计正文字符数并记录结果。统计只包括推进本题结论的分析；来源清单、原文摘录、附录长表、方法或交付说明、验收记录、通用边界和更新流程不计入，也不得跨专项复制或批量套用同一句式后只替换变量。低于下限时先逐项复查并补足被压缩的核心能力；实质分析已经完整且差距不超过下限 10% 时，可记录偏差后交付，不得为贴线补字。差距超过 10% 且不属于局部或有限披露模式时，不得作为完整专项报告交付。超过上限也不代表更好，应删除重复结论、同义改写和只为防止质疑的说明。


先确定研究对象，再根据任务深度交付投资逻辑卡或完整分析。投资逻辑卡保留核心摘要、研究范围、进入方式、回报来源、主要风险、退出与观察条件；完整任务使用下列结构。

先给投资路径结论：

`投资方式｜当前是否可进入｜资金去向｜取得的权利或资产｜回报来源｜关键价格/条款｜最大风险｜退出路径`

用户指定一种投资方式时只列该路径；用户泛问行业“怎么投”时，可比较多种可行路径，但不为凑表强行加入没有现实机会的方式。

用户没有说明研究角色时，报告直接围绕研究对象展开，不标注“中立视角”。用户要求分别服务多个角色时，每个角色单独形成一份报告；不同角色之间不做比较，也不另做跨角色总览。同一研究对象、同一角色下可以比较多种投资路径。

先按研究对象调整报告重点，不另建五套模板：

| 研究对象 | 机会与价值结构重点 | 进入方式、对象比较或交易结构重点 | 必须回答 |
|---|---|---|---|
| 行业机会 | 方向和价值池 | 进入路径与候选企业 | 投什么方向、投哪些企业、如何进入 |
| 企业 | 企业所处机会与兑现条件 | 目标企业、可比企业与交易窗口 | 企业是否值得投、相对位置、当前能否进入 |
| 项目 | 项目价值、边界和里程碑 | 参与方、权责、项目经济与投资载体 | 项目是否成立、如何投入、如何回款和退出 |
| 上市证券 | 发行人经营与证券价值来源 | 价格、估值、可比证券、流动性和稀释 | 当前证券是否有吸引力、价格隐含什么、如何退出 |
| 具体交易 | 交易目的与价值来源 | 结构、资金去向、所得权利、定价和交割 | 交易是否真实且合理、是否已交割、外部能否复制 |

正文使用以下八部分：

1. **投资选择与可进入性摘要**：第一屏直接回答是否值得投、当前如何进入、本对象最重要的选择与比较结果、为什么、为什么是现在、所需价格或交易条件、最大风险及本轮可判断范围。
2. **研究范围与判断条件**：说明研究对象、研究角色（如有）、业务或交易边界、地域、判断截止日、期限、价格或交易条件、资金进入方式、投资目的和本轮可判断程度。
3. **对象所处机会与价值结构**：说明价值来自哪里、需要哪些条件兑现。行业机会要形成方向排序；其他对象只分析与当前对象有关的行业和价值结构。
4. **进入方式、对象比较或交易结构**：按上表完成候选企业、企业比较、项目结构、上市证券比较或具体交易核查，并说明交易可执行性。
5. **投资论点、回报来源与为什么是现在**：关键依据、事实—机制—结果链、收益来源桥、催化剂、市场共识、隐含预期及本研究的差异。
6. **投资人适配、战略目的、三种情景、反方与风险**：适配和不适配条件；战略投资适用时，说明协同和替代方案；再给出基准、上行、下行情景，最强反方、风险传导及可能翻转结论的变量。
7. **证伪、退出与后续观察**：证伪信号、投资逻辑退出、经济退出、未解决矛盾、观察指标及何时结束或暂停。
8. **其他说明、附录与待补证内容（按需）**：放资料与依据表、详细情景参数、观察指标、来源、口径、限制和补证任务。

结论分三层：

- **投资选择**：`优先考虑｜有条件考虑｜继续观察｜暂不考虑｜资料不足`；
- **投资逻辑状态**：`成立｜条件成立｜不成立｜暂不判断`；
- **交易可执行性**：`可进入｜有条件可进入｜暂不可进入｜未发现交易机会｜待核实`。

必须说明研究对象、期限和价格或交易条件；用户指定研究角色时，还要说明报告为谁服务。分清投资吸引力与交易可执行性，不将研究判断写成个性化交易指令。只有历史材料或用户禁止补搜时，标题或摘要应明确标注“历史判断”或“初步筛选”，不得冒充当前投资结论。

资料与依据表、情景参数表和观察指标表根据任务复杂度放在正文或附件，不要求每次机械拆成独立章节；无法支持的内容应说明原因，不静默省略。

## 三、其他交付物

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 三种情景、收益来源桥、多标的比较或观察指标需要公式复算 | 带公式 `.xlsx` | 范围与条件、输入与来源、情景参数、计算、结果、翻转变量和检查项 |
| 只需交换一张候选对象、交易路径或观察指标长表，且没有公式 | `.csv` | 对象、路径、期间、口径、状态、来源、适用条件和限制 |
| 实际价值区间、敏感性或反向估值是核心问题，且已有确认结果或当前可用 `hehe-valuation-analysis` | 引用已确认结果；需要新算时由 `hehe-valuation-analysis` 生成估值模型 | 投资逻辑附件不另建一套估值模型，不把情景参数表改名为目标价模型 |
| 定性投资论点和少量情景可在主报告中完整呈现 | 不生成附件 | Markdown 保留参数、依据、回报链和翻转条件 |

没有已确认估值结果且当前不可用 `hehe-valuation-analysis` 时，保留估值缺口，降低受影响的价格、回报和投资判断强度，其余投资逻辑继续完成。

资料与依据表、情景参数表和观察指标表根据复杂度放在主报告或一个对应附件中，不为同一批字段机械拆成多个文件。
同一数据表需要公式时使用 Excel；只交换无公式长表时使用 CSV，不同时生成两份重复附件。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由时使用任务卡指定位置；单独启动时默认保存到当前任务工作文件夹；用户指定位置时按其要求保存。
- 主报告：`YYYYMMDD_研究主题_投资逻辑分析.md`。
- 同一任务按多个角色分别交付时，在研究主题后加角色，如`YYYYMMDD_研究主题_基金研究员_投资逻辑分析.md`。
- 附件：`YYYYMMDD_研究主题_投资逻辑分析_附件名称.扩展名`，附件名称写具体用途，如`情景与收益来源模型`、`观察指标表`。
- 研究主题写清行业机会、企业、项目、上市证券或具体交易；版本号按需添加。用户或项目另有命名规范时优先遵守。

## 五、信息缺口

只有缺口可能改变核心投资判断、进入方式、回报来源、价格条件或退出路径时才发起补证：

`待证主张｜缺失字段｜对象/地域/时间/口径｜优先原文类型｜建议检索方向｜用途｜若缺失如何降级｜付费或授权边界`

缺口未解决时，只降低或暂停受影响的投资论点、交易可执行性或情景；其余有依据的部分继续完成。

## 六、交付条件与交付前检查

研究对象、投资路径、价值和回报链、关键价格或条件、主要反方、风险与退出已经形成有依据的回答，新增一般材料不会改变投资选择时即可交付。交付前检查：

- 核心摘要第一屏直接回答是否值得投、如何进入和主要原因，研究范围单独成节；
- 行业机会、企业、项目、上市证券或具体交易使用了对应重点，没有混写对象；
- 投资吸引力与交易可执行性分开，资金去向、所得权利和退出路径可核对；
- 回报来源、为什么是现在、预期差、三种情景、最强反方和证伪条件互相衔接；
- 投资选择、投资逻辑状态和交易可执行性三层结论均明确；
- 财务、治理和估值缺口没有被自行补造，附件没有重复建设估值模型；
- 报告与附件的参数、口径、结论和链接一致，实际文件可打开。

## 七、其他注意事项与专项要求

本 Skill 负责一份可直接阅读的投资逻辑 Markdown 专项报告，以及其中的条件化投资论点、风险和跟踪条件。PPT、品牌化视觉版和个性化交易指令不属于默认交付。
