# 投资方式与交易路径

本文件帮助投资逻辑分析先确定研究对象，再认清“钱如何进入、投资人取得什么”，并使用对应角度分析。只选择与任务有关的路径，不机械全跑。

## 一、五个维度不要混淆

| 维度 | 要回答的问题 | 常见取值 |
|---|---|---|
| 研究对象 | 正在判断什么 | 行业机会、企业、项目、上市证券、具体交易 |
| 研究立场或角色 | 谁在使用分析、准备做什么决策 | 行业投资研究人员、二级市场分析师、普通投资者、基金研究员、产业投资人员、项目投资负责人、企业并购负责人、战略投资负责人 |
| 资金进入方式 | 钱通过什么交易进入 | 二级市场、一级融资、老股转让、控股并购、债权、可转债或其他混合工具 |
| 投资目的 | 为什么投 | 财务回报、战略协同，或两者兼有 |
| 决策阶段 | 当前要做到多深 | 机会筛选、初步判断、深入尽调、投资决策 |

研究对象必须明确，是分析的出发点。研究立场影响关注重点，不改变事实标准，也不是启动门槛：

| 研究立场或角色 | 常见关注点 |
|---|---|
| 行业投资研究人员或一般投资从业者 | 行业价值池、优先方向、候选企业、可进入工具、兑现阶段和主要风险 |
| 二级市场分析师 | 公开证券、盈利预期、估值、催化剂、流动性和市场预期差 |
| 普通投资者 | 实际可购买的工具、信息可得性、价格、风险、流动性和退出便利性 |
| 基金研究员 | 基金策略、资金期限、投资阶段、规模、权利、回报要求和组合约束 |
| 产业投资人员 | 产业协同、资源投入、业务控制、财务回报、投资期限和不投资的替代方案 |
| 项目投资负责人 | 项目边界、建设与审批、资本金、现金流、里程碑、项目载体和退出安排 |
| 企业并购负责人 | 控制权、交易范围、对价、融资、审批、整合难度和协同兑现 |
| 战略投资负责人 | 战略目标、资源交换、治理权利、利益冲突、财务与战略回报及替代方案 |

用户没有说明角色时，围绕已经确定的研究对象继续分析，不另设“中立研究视角”。用户要求分别服务多个角色时，每个角色单独分析和交付，不比较角色，也不制作跨角色总览。

“战略投资”是投资目的，不是唯一的交易方式。战略投资者可能参与新股融资、受让老股、收购控制权、成立合资公司或使用可转债等工具。

## 二、先核对交易是否存在

至少查清与本题有关的内容：

`投资标的｜交易或证券｜当前是否可进入｜资金接收方｜投资人取得的资产或权利｜价格/估值/利率｜主要条款｜投资资格与审批｜期限｜退出方式`

- 二级市场买入通常是与市场卖方交易，资金通常不进入上市公司；增发、配股或新股融资才可能把新增资金交给公司。
- 一级融资需要核对融资轮次、是否仍在进行、新股或老股、投前投后估值、金额、投资方及资金用途。
- 老股转让需要核对出售方、转让原因、比例、价格、权利和转让限制，不能把它写成公司新增融资。
- 并购或战略投资没有实际公告、出售意愿、融资安排或接触证据时，只能作为情境方案。

## 三、按进入方式选择分析重点

### 1. 上市证券与二级市场

适用于公开交易的股票、基金、债券或其他证券。

重点核对：

`证券与交易场所｜当前价格和流动性｜盈利与现金预期｜估值及隐含假设｜分红/回购/利息｜催化剂｜市场预期差｜下行与退出条件`

结论回答当前证券是否具有吸引力，不把“公司值得长期关注”直接写成“当前价格值得买入”。

### 2. 一级股权融资

适用于初创、成长、Pre-IPO、定增或其他公司发行新股的交易。

重点核对：

`融资阶段｜新股/老股｜投前/投后估值｜融资金额｜稀释｜资金用途｜现金消耗｜关键里程碑｜投资者权利｜后续融资｜退出路径`

早期项目更关注产品、客户、团队和下一里程碑；成长期项目还要关注扩张效率、盈利与现金质量、后续融资需求及退出可达性。

### 3. 老股转让

适用于从创始人、员工、早期投资人或其他股东处受让现有股权。

重点核对：

`出售方与原因｜资金去向｜转让比例｜折价/溢价｜股东权利｜董事席位或信息权｜优先权｜转让限制｜共同出售/强制出售安排｜流动性与退出`

公司经营质量良好，也不代表老股价格、股东权利和退出安排合理。

### 4. 控股收购与并购

适用于取得控制权、收购业务或合并交易。

重点核对：

`控制权与交易范围｜交易对价｜收益与现金质量｜收购融资｜改善与协同来源｜整合难点｜治理安排｜监管审批｜交割条件｜潜在退出买方`

协同只能写成待兑现机制；必须说明由谁执行、投入什么、何时观察、失败后损失什么。

### 5. 债权、可转债与混合工具

适用于贷款、债券、可转债、优先股或兼有股债性质的安排。

重点核对：

`偿付来源｜利率/回报结构｜期限｜优先级｜担保或抵押｜财务契约｜再融资风险｜转换条件｜稀释｜下行保护｜违约处置`

债权判断先看偿付能力和保护条款；转换或股权上行不能替代对本息安全的核查。

## 四、战略投资叠加层

投资目的包含战略协同时，在所选交易方式上增加：

`战略目标｜双方投入资源｜客户/渠道/技术/供应链/数据/产能协同｜独家或排他｜控制与治理｜知识产权和数据权利｜利益冲突｜财务回报｜战略回报｜协同失败后的退出或降级方案`

同时比较不投资是否也能实现目标，例如自建、采购、商业合作、授权或合资。只有投资比替代方案更有效时，战略理由才成立。

## 五、如何选用

- 用户已经指定投资方式：只使用对应路径，并核对其是否真实存在。
- 用户泛问某行业“怎么投”：简要扫描可行路径，再深入现实可执行、信息足够的路径。
- 用户泛问某家公司“值不值得投”：先核对公司法律形态、上市地点、融资或交易状态；上市公司默认先看公开证券，非上市公司先看是否存在融资或股权交易。
- 用户同时关心财务与战略目的：使用同一交易事实，分别判断财务回报和战略回报，不合并成一个模糊结论。
- 无法确认实际交易：可以给出条件化方案，但交易可执行性标为“未发现交易机会”或“待核实”。

## 六、统一输出

先给投资路径结论：

`投资方式｜当前是否可进入｜资金去向｜取得的权利或资产｜回报来源｜关键价格/条款｜最大风险｜退出路径`

再把各路径放回统一投资逻辑：

`投资吸引力 → 交易可执行性 → 价值与回报机制 → 为什么现在 → 成立条件 → 最强反方 → 证伪信号 → 经济退出`

不要因为某种方式理论上存在，就假设当前投资人一定有资格、额度、卖方、融资窗口或谈判机会。
