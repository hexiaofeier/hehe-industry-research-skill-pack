# 财务分析

本 Skill 是盒子原创研究 Skill 体系中负责企业财务分析的大专项，把企业财报、附注和经营数据重建成一套可追溯、可解释、可复算的财务分析，回答“结果怎样形成、质量如何、能否持续、风险藏在哪里、哪些变量会改变判断”。

所有报告均以独立的“核心摘要”开篇，随后按[交付模板](references/财务分析交付模板.md)依次写研究范围、财务口径与适用的主体分析章节。完整企业财务分析覆盖六项财务分析能力、连续年度、最近期间及报告—Excel对应要求。正文围绕主要变化、驱动、财务质量和持续性展开。

需要计算指标、检查三表或建立工作底表时，读取 [财务口径、公式与工作底表](references/财务口径、公式与工作底表.md)。

按任务读取以下方法：

- 完整公司财务诊断或深入分析报表科目时，读取[企业财务诊断方法](references/企业财务诊断方法.md)；
- 重构三表、制作预测或压力测试模型时，读取[三表重构与预测模型](references/三表重构与预测模型.md)；
- 检查盈利质量、审计事项和异常科目时，读取[会计质量与异常核查](references/会计质量与异常核查.md)；
- 分析软件、平台、项目制、重资产、房地产、银行、保险或早期企业时，读取[行业财务口径适配](references/行业财务口径适配.md)；
- 企业没有连续完整财报、只有部分经营指标或几乎没有公开财务数字时，读取[无完整财报企业的财务分析](references/无完整财报企业的财务分析.md)。

## 启动与工作流程

- **由 `hehe-industry-researcher` 调用：** 收到任务卡和材料索引后直接读取材料并执行，不重新启动路由。
- **用户直接调用本 Skill：** 本 Skill 单独启动，在对话中确认对象、研究范围、地域、时间、用户口径要求及已有材料，再决定是否搜索。

开始执行前读取 [专项工作流程](references/专项工作流程.md)，按对应路径接任务、搜索、审核、分析、自审和交付。
交付时读取 [财务分析交付模板](references/财务分析交付模板.md)，按模板完成本专项成果；用户明确不落文件时，在对话中交付。

**完整交付原则。** 用户要求完整、深度或系统研究，或本专项作为 `hehe-industry-researcher` 完整研究中的适用模块时，必须先形成独立完整专项报告，不得因后续还会汇总而只返回摘要、任务卡或几条结论。只有用户明确要求局部／简版，或资料只能支持有限披露时才切换输出模式，并在报告中标明；完整度按交付模板的分析单元和正文目标体量检查，交付前实际计数。

## 一、职责范围

负责财务口径、三表与分部重构、经营和资本诊断、财务预测、公式工作底表及正式财务分析报告。单位贡献、固定费用覆盖、关联及表外事项按其财务影响分析。

完整商业模式研究、治理与资本配置决策评价、估值、投资建议、法定审计及跨专项综合报告/PPT不属于本专项任务。

## 二、确定材料条件与任务范围

材料条件决定结论能做到多深，研究问题决定需要分析哪些内容。财报完整度决定交付名称和结论强度，不决定本 Skill 能否启动。

### 材料层级

连续财报、附注及必要分部数据较完整时，重建三表；资料不完整时，按[无完整财报企业的财务分析](references/无完整财报企业的财务分析.md)选择部分财务披露、经营与融资数据或几乎无数字路径。交付名称和体量统一见交付模板。

### 任务范围

按研究问题确定分析范围，按材料覆盖确定展开深度。完整任务覆盖六项财务分析能力，报告章节按交付模板组织；业绩更新、单项问题和预测任务深入相关模块。

同一材料条件下，可以执行四类任务：

| 任务 | 需要完成的分析 |
|---|---|
| 完整企业财务分析 | 财务事实重建、经营结果、现金与资产、资本回报、融资风险和会计质量；涉及未来时增加预测或压力测试 |
| 业绩更新与偏差分析 | 解释本期相对上期、预算、公司指引或既有预测的差异及原因 |
| 专项财务问题 | 只深入相关科目和三表影响，不机械生成完整公司报告 |
| 财务预测与模型 | 以经营驱动联动三表和必要附表，输出情景、敏感性及财务承压点 |

金融机构、保险、房地产、基金、平台型或重度项目制业务必须先读取[行业财务口径适配](references/行业财务口径适配.md)，识别普通工商企业指标的失效点；缺少对应方法时记录待补方法及其影响。

## 三、分析流程

### 1. 确认范围，整理原值和版本

建立财务分析范围表：

`公司/经营主体｜法人/证券标识｜合并或单体｜分部范围｜地域｜报告期与频率｜财年截止日｜币种与单位｜会计准则｜持续/终止经营｜重述/会计政策变化｜审计状态｜分析截止日｜分析模式｜决策用途`

另建期间和版本表：

`期间｜原披露日｜版本/重述日｜原币种与单位｜是否审计｜可比状态｜差异原因｜本次采用值`

主体、分部、期间或重述关系不清，且足以改变结论时，停止强结论并列补证任务。

正式依赖财报数字前，检查审计意见、关键审计事项、内部控制重大缺陷、重大重述及会计政策变化；发现异常时核对受影响的科目及判断。

接收已审核材料时保留其限制；用户提供但尚未核验的数据可进入原始表，但只能标为 `[用户提供待核]`，不得直接支撑强财务结论。

原始数据表至少保留：

`字段ID｜报表/附注｜主体/分部｜期间｜原字段名｜原值｜币种/单位｜正负号｜来源定位｜审核状态｜重述/调整关系｜备注`

不得覆盖原始值。任何标准化、重分类、汇率换算、年化、一次性调整或推算都新建字段，并记录：

`原值 → 调整原因 → 公式/方法 → 调整值 → 判断类型 → 对结论影响`

### 2. 标准化三表、分部并完成勾稽

建立“业务/客户/地区 → 收入与成本 → 营运资本与资产 → 现金与融资”的财务结构。统一字段、单位、符号和期间，处理重述、并购处置、汇率与分类变化，形成历史三表、分部—合并桥和必要附表。

按[三表重构与预测模型](references/三表重构与预测模型.md)完成重构与联动，用[财务口径、公式与工作底表](references/财务口径、公式与工作底表.md)核对计算。分部无法可靠分摊时单列未分配及抵销；勾稽差额先定位原因，再记录金额和受影响判断。

### 3. 解释增长、利润、现金和营运资本

按[企业财务诊断方法](references/企业财务诊断方法.md)建立收入、利润及现金变化桥，结合业务、客户、产品、地区、交付和回款解释贡献。分别分析增长金额与质量、毛利及费用驱动、净利润到经营现金、自由现金流和营运资本占用。

先确认各因素贡献多少，再用经营证据筛选主要原因；尚不能区分的解释只在会改变结论时继续核查。业绩更新另与预算、指引或上一版预测作偏差比较。

### 4. 判断资产、资本回报与财务韧性

继续使用诊断方法检查重大资产的形成、回收及减值，追踪资本开支到产能、利润和现金兑现的时滞。以适用的ROE、ROIC及增量回报拆解盈利、周转和杠杆贡献。

将可用现金、债务期限、融资成本、担保契约及其他现金义务按期间匹配；需要判断承压能力时，将经营或融资冲击传导到最低现金、融资缺口和契约节点。

### 5. 核查会计质量与异常

按[会计质量与异常核查](references/会计质量与异常核查.md)核对正式披露、收入确认、应计与非经常项目、资产减值、准备、资本化及关联和表外事项。完整任务覆盖会计质量；专项任务检查可能改变当前结论的相关科目。

结合异常的财务影响决定补证顺序，并记录已有解释、待核事项及受影响结论；可选预警模型按该参考的适用条件使用。

### 6. 联结历史驱动并形成结论

将增长、利润、现金、投入和融资联系起来，判断企业所处阶段、主要变化及持续性，选出下一期值得观察的指标。

任务涉及未来时，按[三表重构与预测模型](references/三表重构与预测模型.md)建立经营驱动、附表和三表联动的预测或压力情景，记录假设依据、现金传导及翻转条件。无完整三表时按低披露参考建立相应的条件模型。

## 四、交付与自审

按[财务分析交付模板](references/财务分析交付模板.md)生成Markdown主报告，并按计算任务附公式Excel。工作簿结构、公式纪律及重算、输入联动、保存重开检查统一见[财务口径、公式与工作底表](references/财务口径、公式与工作底表.md)；三表模型另做联动与经营合理性检查。

提交前先按交付模板检查开篇摘要：位置、内容或独立可读性不合格，先修正再交付。再核对：任务覆盖符合交付合同；关键数字可追溯且勾稽差额已处理；解释与证据相称；报告和底表相互对应。主体、期间、口径、重大差额或缺失数据足以翻转结论时，补证或暂停受影响的判断，其余分析继续。成文按交付模板检查主线、重复和限制说明。
