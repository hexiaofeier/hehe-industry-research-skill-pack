# 企业财务诊断方法

本参考用于完整企业财务分析、业绩变化分析或深入检查主要报表科目。它提供问题和判断方法，不要求每次机械生成全部表格。

## 一、财务分析的基本单位

从重要变化出发，先计算金额、幅度与贡献，再解释经营原因及其现金和持续性影响。

- 观察和计算给出来源、口径及计算结果；
- 原因解释用经营证据连接变化，区分算术贡献与经营机制；多个解释仍有竞争时，寻找能区分它们的观测，只对影响主要判断的分歧补证；
- 预测给出假设依据、传导关系和会改变结果的条件。

按金额、对结论的影响及事项性质分配篇幅。共用口径和缺口集中登记；不影响主结论的细小差额留在底表，正文只展开会改变本段判断或下一动作的限制。性质严重的事项即使金额小也需核查。

按问题组合四种比较：

1. **时间比较：** 本期、上期、同期、三至五年趋势和滚动十二个月；
2. **结构比较：** 占收入、资产、负债、现金流或分部合计的比例；
3. **贡献比较：** 某业务、地区、产品、客户或科目对总变化贡献多少；
4. **基准比较：** 与公司预算/指引、历史正常水平或可比企业比较。可比对象必须说明为什么可比，不用不明来源的“行业平均”。

比率与绝对金额并列，时点余额结合期间变化解释。

## 二、先建立企业财务结构

在解释财务数字前，先回答企业怎样把经营活动变成三张报表：

| 经营问题 | 需要识别的内容 |
|---|---|
| 收入从哪里来 | 业务、产品、客户、地区、渠道、合同形式、结算单位和确认时点 |
| 成本怎样形成 | 材料、采购、制造、履约、渠道、人员、研发、获客和售后 |
| 哪些资产支撑经营 | 存货、应收、固定资产、在建工程、无形资产、商誉、租赁资产和长期投资 |
| 经营怎样占用或释放现金 | 回款、备货、预付、账期、合同资产/负债、税费和季节性 |
| 资金从哪里来 | 经营现金、债务、股权、供应链融资、租赁和资产处置 |
| 资金用到哪里 | 营运资本、资本开支、研发、并购、偿债、分红和回购 |

可建立财务结构表：

`业务/经营环节｜收入与结算方式｜主要成本｜关键资产｜关键负债｜现金时点｜融资需求｜对应报表和附注`


## 三、三表的横向和结构分析

### 1. 横向趋势

对重要科目至少检查：

- 绝对金额、同比变化和三至五年趋势；
- 增长速度是否持续加快、放缓、反转或周期波动；
- 变化是否集中在某个季度、半年、并购或政策时点；
- 利润、现金、资产和债务是否同步；
- 基数、重述、会计分类和期间长度是否使同比失真。

### 2. 结构分析

- 利润表：各项收入、成本和费用占收入比重；
- 资产负债表：各类资产、负债和权益占总资产比重；
- 现金流量表：经营、投资和融资现金流的来源与用途，以及主要项目占收入、经营现金或总现金流入的比例；
- 分部：各业务或地区占收入、利润、资产和资本开支的比例。

结构变化要解释原因。例如存货占资产上升，可能来自增长备货、需求放缓、成本上涨、并购、季节性或跌价不足，不能只写“存货压力增加”。

### 3. 变化贡献

当总指标变化由多个部分组成时，计算各部分的增减额和对总变化的贡献。收入增长、毛利改善或现金流恶化都应尽量落到具体业务、地区或科目。

## 四、利润表诊断

### 1. 收入质量

建立收入变化桥，按资料可得性拆分：

先区分并购/处置、汇率和会计口径影响，再拆可比业务的价格、数量与结构。各项采用一致基准并核对总变化，未解释金额单列；具体分解公式见[财务口径、公式与工作底表](财务口径、公式与工作底表.md)。

重点检查：

- 收入是否由主营业务、核心产品和持续客户贡献；
- 订单、合同额、出货量、GMV、用户数与收入确认是否匹配；
- 客户集中、一次性大单、渠道压货、退货、返点和延长账期是否抬高收入；
- 分部增长能否与行业、产能、渠道、客户或终端需求相互验证；
- 有机增长与并购增长、报告增长与可比增长是否分开。

### 2. 毛利和成本

建立毛利变化桥：

先将毛利变化拆成收入规模影响与毛利率影响，再向下解释售价、销量、产品/客户/地区结构、材料与采购、制造/履约效率、产能利用、汇率及会计分类；父项与子项不重复相加，未解释差额单列。闭合公式见[财务口径、公式与工作底表](财务口径、公式与工作底表.md)。

检查毛利改善是否来自真实价格和效率，还是低毛利业务退出、成本分类变化、库存跌价转回、补贴或短期原材料变化。

### 3. 费用和经营杠杆

分别分析销售、管理、研发及其他主要费用：

- 金额、费用率和人均/单位业务指标是否同向；
- 属于固定支出、随收入变化的支出，还是为未来增长提前投入；
- 研发费用化与资本化、股权激励、折旧摊销、重组和减值怎样影响可比性；
- 收入增长时费用增幅更低是否形成经营杠杆；收入下降时费用能否调整；
- 按财务问题分析单位贡献、固定费用覆盖，以及扩张投入与维持投入。

### 4. 营业利润到净利润

建立利润桥：

`毛利 → 营业利润 → 税前利润 → 公司整体净利润 → 归母净利润 → 每股收益`

逐项解释补助、公允价值、投资收益、资产处置、减值、利息、汇兑、税率、少数股东损益、终止经营和股本变化。归母净利润不能替代公司整体净利润；每股收益变化还要检查股份数量、回购、增发和潜在稀释。

### 5. 调整后利润

管理层口径和研究口径分开：

`项目｜公司是否调整｜研究是否调整｜税前/税后金额｜现金/非现金｜是否可能重复发生｜调整理由｜调整后结果`

经常发生的“非经常”费用、持续股权激励或反复重组，不能每年全部排除后再声称是正常利润。

## 五、现金流和营运资本诊断

### 1. 利润到经营现金流

建立桥表：

`净利润 + 非现金项目 ± 营运资本变化 ± 税息及分类差异 ± 其他 = 经营现金流`

重点解释折旧摊销、减值、股权激励、递延税、应收、合同资产、存货、预付、应付、合同负债和其他经营项目。经营现金转差可能是增长投入，也可能是回款恶化、库存积压或供应商账期收紧。

### 2. 经营现金流到自由现金流

至少区分：

- 简化自由现金流：经营现金流减购建长期资产支出；
- 对企业更适用的自由现金流口径：是否还需考虑租赁本金、资本化开发、处置、维护性资本开支、并购或利息分类；
- 维护性资本开支与增长性资本开支暂时无法拆分时，提供区间或两种口径。

### 3. 营运资本

对应业务选择应收、合同资产、存货、预付、应付、票据和合同负债，检查：

- 余额、增速、收入或成本占比；
- 账龄、周转、逾期、核销和减值准备；
- 客户、供应商、项目、地区和季节性集中；
- 经营改善还是通过延迟付款、保理、票据或供应链融资换来现金；
- 半年或季末余额是否代表全年正常状态。

负营运资本结合预收、需求和付款行为区分经营优势与付款延迟。DSO、DIO、DPO 和现金转换周期按[公式参考](财务口径、公式与工作底表.md)的分母、期间和业务条件使用。项目制、平台或预付模式应改用合同里程碑、递延收入、预收和结算周期等更合适指标。

## 六、资产质量诊断

按重要性分析下列科目，不要求每家公司逐项机械展开：

| 科目 | 需要回答的问题 |
|---|---|
| 现金与短期投资 | 是否受限、存放何处、能否自由调度、是否承担信用/估值/币种风险 |
| 应收与合同资产 | 与收入是否匹配；账龄、逾期、信用损失和客户集中是否恶化 |
| 存货 | 原材料、在制品、产成品和渠道库存怎样变化；库龄、跌价、退货及更新换代风险如何 |
| 预付和其他应收 | 交易对手、用途、回收方式及关联方占用风险是否清楚 |
| 固定资产与在建工程 | 产能、利用率、转固、折旧、停建和减值是否匹配经营结果 |
| 无形资产与资本化研发 | 资本化条件、摊销期限、项目成功率和费用递延影响是否合理 |
| 商誉及并购资产 | 形成对象、现金产生单元、业绩兑现、减值假设和敏感性是否可信 |
| 长期投资 | 是否服务主业，收益和现金回收怎样，是否存在估值和减值风险 |
| 递延税资产 | 未来是否有足够应税利润实现，亏损和抵扣期限是否接近失效 |

用余额滚动桥解释重大资产的新增、处置、折旧摊销、减值及其他变化，再结合经营用途、现金回收和会计估计判断质量；涉及承压能力时增加压力情景。

## 七、资本开支和资本回报

### 1. 资本开支

区分维护性、替换性和增长性投入；无法拆分时保留区间或未知。核对现金流量表支出、固定资产/在建工程变化、折旧、处置和非现金取得。分析投入后的产能、收入、毛利和现金是否按合理时滞兑现，同时计入影响资本需求的租赁、平台补贴、合作方投入及表外承诺。

### 2. ROE 与杜邦拆解

用三因素杜邦拆分盈利、周转和杠杆贡献，必要时进一步分离税负与利息负担。定义和公式见[财务口径、公式与工作底表](财务口径、公式与工作底表.md)。

### 3. ROIC 与增量回报

公开 NOPAT、投入资本、平均余额、税率及调整项，同时使用经营视角和融资视角检查投入资本。并购、租赁、商誉、资本化研发、大额闲置现金和少数股东可能显著改变结果。

新增资本投入较大时，检查增量 NOPAT、增量现金和建设爬坡时滞；分母过小、为负或期间错配时不计算虚假精确的增量 ROIC。

## 八、流动性、债务和韧性

建立债务与流动性表：

`工具/债权人｜期初余额｜新增｜偿还｜非现金变化｜期末余额｜到期日｜利率｜固定/浮动｜币种｜抵押/担保｜契约｜可用授信`

分析：

- 可自由使用现金、受限现金、子公司或地域隔离资金和维持经营所需最低现金；
- 未来各期到期本金、利息和租赁支出，加权融资成本与固定/浮动利率结构；
- 利息覆盖、净债务/EBITDA、经营现金偿债和授信余量；
- 债务币种与经营现金币种是否错配；
- 再融资依赖、供应链融资、保理、票据、回购义务和或有负债；
- 压力情景下最低现金、契约触发点和融资缺口出现在哪个期间。

偿债判断结合资产变现能力、现金流时点和债务期限。

## 九、业绩偏差与更新分析

有预算、指引、市场一致预期或上一版模型时，建立偏差表：

`指标｜实际｜比较基准｜金额差｜比例差｜价格/数量/结构等直接原因｜经营解释｜是否一次性｜对以后期间的影响`

收入高于预期但现金、利润或订单质量变差，不能只写“超预期”；利润低于预期但来自主动投入时，也要判断投入是否具备可验证的后续回报。

## 十、形成财务判断

报告结论应形成一条完整主线：

1. 企业目前处于增长、收缩、转型、投入、收获还是承压阶段；
2. 收入和利润变化的主要驱动是什么；
3. 利润的现金含量和会计质量怎样；
4. 哪些资产和营运资本正在占用或释放现金；
5. 资本回报来自经营效率还是杠杆及会计变化；
6. 债务、流动性和再融资是否可承受；
7. 哪些结论最可能被未来披露推翻；
8. 下一期应观察哪些数值、附注和经营事件。

综合判断提炼已得到支持的主要解释、持续性及监测项；尚未解决且会改变结论的分歧集中列明。
