# 财务分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告；Excel 是否生成按下表所列计算任务决定。
其他交付物，需按实际计算任务决定。具体参见下表。

| 任务情况 | 默认交付 |
|---|---|
| 完整企业财务分析且披露充分 | Markdown 主报告＋带公式 Excel 工作底表 |
| 有限披露或专项问题，包含多期计算、桥表、压力情景 | Markdown 主报告＋与任务规模相称的带公式 Excel |
| 仅解释少量已给结果，没有实质性计算 | Markdown 主报告，不强制 Excel |
| 用户明确不要 Excel | Markdown 主报告，在正文保留关键公式与计算过程 |

Excel 可使用当前环境中任何能够写入公式、保存并重算 `.xlsx` 的库、应用或 Skill，不限定具体产品。任务已经触发 Excel、但当前环境没有这类能力时，仍完成 Markdown、输入、公式和计算过程，并在交付清单中把工作簿标为“待生成”；这属于部分交付，不能把未生成、未重算的文件称为已完成底表。

财报完整度决定交付名称和展开深度：

| 资料条件 | 交付名称 | 体量与载体 |
|---|---|---|
| 连续财报、附注及必要分部数据较完整 | 完整企业财务分析 | 一般约一万至一万五千汉字；完整覆盖六项财务分析能力，至少三年连续年度（通常三至五年）及最近季度或半年；配带公式 Excel。年度与中期分开比较，标明重述及缺失期间 |
| 只有部分报表或可核对的财务指标 | 有限披露财务分析 | 通常约六千至一万二千汉字，围绕有证据的财务变化及原因形成正式分析；内部检查六项财务分析能力覆盖，缺口集中说明；有实质计算时带 Excel |
| 无完整报表，但有可核对的经营、合同、融资或现金数据 | 财务经营分析；含情景时加“与情景测算” | 围绕可核对事实、经营财务关系和情景公式展开；通常约五千至一万汉字，有实质测算时带 Excel |
| 几乎没有可核对的财务数字 | 财务可分析性评估与补数方案 | 交代现有事实、待回答问题、所需数据和可复用模型骨架 |

上述体量适用于相应的完整任务；材料不足或单项问题按证据和所需分析深度展开。篇幅用于数据解释和推理。

## 二、Markdown 主报告

完整企业财务分析使用第1—8项，第9—11项按需设置。

1. **核心摘要**：先给一句总体判断，再列三至六项主要发现；每项写明结论、最关键的数字或证据及其含义。有可比数据时附核心趋势或指标表。摘要必须是首个正文章节，只读本节即可掌握报告结论，不放研究过程和一般性说明。
2. **研究范围**：说明研究对象或经营主体、业务范围、地域、报告期、分析截止日、研究目的及必要的包含与排除。只交代本报告分析什么，不展开材料清单、方法过程或资料缺口。
3. **财务口径与数据版本**：说明合并或单体、分部范围、币种与单位、会计准则、审计状态、重述与重分类、数据版本及可比性。直接改变某项结论的口径同时在相关章节说明，不把整段口径重复到各章。
4. **连续年度财务趋势与三表结构**：完整分析覆盖三至五年连续年度及最近季度或半年，分别呈现利润表、资产负债表、现金流量表、分部贡献、主要变化桥和勾稽结果。年度与中期分开比较，缺失期间和不可比变化明确标出。
5. **收入、盈利、现金流与营运资本**：解释收入增长来源、毛利和费用变化、利润质量、净利润到经营现金的转换、自由现金流及应收、存货、应付等周转。先说明变化和贡献，再判断原因及持续性。
6. **资产质量、资本开支、资本效率与流动性**：分析重大资产的形成、回收与减值，资本开支到产能、利润和现金的兑现，ROE、ROIC及增量回报，以及可用现金、债务期限、融资依赖和承压能力。普通工商企业指标不适用时改用行业适配口径。
7. **会计质量与异常事项**：检查审计意见、关键审计事项、收入确认、应计与非经常项目、减值、准备、资本化、关联交易及表外事项。只展开可能影响财务判断的重要异常，不罗列无关风险。
8. **历史驱动、情景边界与综合判断**：联结增长、利润、现金、资产和融资，判断企业所处阶段、财务质量、持续性和主要风险；存在相反信号时说明哪个更重要及原因。任务涉及未来时增加预测或压力情景；最后给出翻转条件及少量跟踪指标，不重复摘要和前文计算。
9. **其他说明（按需）**：集中说明材料充分性、来源边界、特殊分析方法和共用限制及其影响。只有确有必要时设置；只为防止质疑、没有新增证据或推理的说明删除。
10. **附录（按需）**：放来源明细、详细公式和计算过程、口径或版本对照、附件索引及可复用结果。支撑正文判断的关键证据、数字和必要公式仍留在相关章节。
11. **待补证内容（按需）**：只列可能改变财务判断的缺口，说明所需数据、用途、影响、建议来源及补充后更新哪一章；有明确披露时间时列复查时间。

有限披露、财务经营分析和专项问题按上述先后顺序使用适用标题；省略无实质内容的章节后，其余章节连续编号。重要缺口集中放在“待补证内容”。几乎无数字时，核心摘要仍先给当前可成立的判断，再交代研究范围、现有口径和补数方案。

## 三、其他交付物

### Excel 工作底表

按[财务口径、公式与工作底表](财务口径、公式与工作底表.md)建立任务需要的计算内容，并完成Excel验收；涉及三表重构和预测时执行[三表重构与预测模型](三表重构与预测模型.md)。报告所依赖的变化桥、周转、资本回报、债务和情景计算均对应到底表的输入与公式。

### 报告与 Excel 对应（实际生成 Excel 时）

两份文件按报告章节和关键指标对应。Markdown相关章节标出对应工作表和关键范围，首次提到配套底表时使用相对链接；Excel的“报告索引”按[工作底表规则](财务口径、公式与工作底表.md)反向登记报告位置。正文数值引用工作簿已计算结果。

### 其他附件

| 触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 只需交换一张已整理的原始数据或参数长表，且没有公式 | `.csv` | 字段 ID、主体/分部、期间、币种/单位、口径、来源、状态和限制 |
| 用户明确要求单独图形或展示版 | 对应可编辑图源与展示文件 | 图中数值、期间和口径与报告及 Excel 一致 |
| 没有独立交换或展示需要 | 不生成其他附件 | Markdown 与适用的 Excel 已构成完整交付 |

CSV 不替代带公式的工作底表。完整财务分析不因另做图形而省略 Markdown 或 Excel。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由用任务卡指定位置；无路由默认当前任务工作文件夹。
- 文件命名：主报告`YYYYMMDD_研究主题_财务分析.md`；工作底表`YYYYMMDD_研究主题_财务分析工作底表.xlsx`；其他附件使用 `YYYYMMDD_研究主题_财务分析_附件名称.扩展名`。
- 研究主题写清行业或细分对象，企研加企业名；需区分草稿或版本时加在成果名称后。用户或项目另有命名规范时优先遵守。

## 五、信息缺口

只对可能改变财务判断的缺口生成补证任务：

`待证字段/主张｜主体/分部｜期间｜币种/单位｜所需报表或附注｜建议检索方向｜用途｜若缺失如何降级｜授权/付费边界`

可复用结果字段：

`资料来源｜字段/指标｜定义与公式｜主体/分部｜期间｜币种/单位｜判断类型｜状态｜情景｜限制｜后续用途｜是否可用于更新原结论`

## 六、交付条件与交付前检查

按资料条件选定的交付路线已经完成其可成立的分析，核心数字可追溯、重要计算可复算、关键缺口和判断上限已说明，新增一般材料不会改变当前结论时即可交付。有限披露、财务经营分析和财务可分析性评估按各自路线验收，不等待不存在的完整三表。

以下规则用于全篇成文与交付自检，不作为报告章节。开篇摘要按第二节的验收要求检查；正文逐段核对：

- 一段围绕一个发现展开：结论、关键证据、解释及必要影响。
- 计算事实给来源、口径和结果；因果推断补机制及区分证据；预测补假设和翻转条件。按判断类型提供所需支持。
- 同一缺口、口径或风险在最相关位置解释一次；后文需要时简短引用。仅当它改变本段判断或下一动作时展开限制。
- 按事项金额、性质和对主结论的影响安排正文、附表或记录的位置。覆盖检查留在底稿，正文呈现实质发现。
- 逐段检查：删除只为防止质疑、没有新增证据或推理的声明；合并重复结论、同义提醒和空转过渡。
- 交付物检查：报告与 Excel 的章节索引、关键数值、公式和来源一致；适用的工作簿已完成重算、联动测试、保存后重开及回读；文件名称、相对链接和实际清单可核对。
