# 会计质量与异常核查

本参考用于判断利润、资产、负债和现金的会计质量，定位需要继续核读的科目和附注。核查结果落到受影响的财务判断及补证动作。

## 一、先检查正式披露

至少查看适用项：

- 审计意见及其变化；
- 关键审计事项、持续经营重大不确定性和强调事项；
- 内部控制重大缺陷、监管问询、处罚和财务重述；
- 会计政策、会计估计、列报和收入确认变化；
- 审计师更换、频繁延迟披露或主要财务负责人的异常变化。

标准无保留意见不等于所有数字没有风险；关键审计事项是审计关注重点，也不自动等于存在错报。

## 二、收入确认和回款

检查收入、经营量、合同、交付和现金是否能互相解释：

- 收入在发货、验收、上线、里程碑、使用或收款的哪个时点确认；
- 总额法还是净额法；平台、代理、经销和联合交付的责任主体是谁；
- 退货、返利、折扣、质保、可变对价和渠道库存怎样处理；
- 应收、合同资产、票据、保理和经营现金是否与收入增长匹配；
- 大额年末交易、一次性合同、延长账期、关联交易或应收快速增长是否集中；
- 合同负债、预收和未履约义务是否支持未来收入，还是来自特定项目时点。

收入增长、应收增长和现金下降同时出现时，核查客户结构、交付时点、账期、季节性、项目结算和减值准备，确定背后的经营或会计原因。

## 三、利润与现金质量

建立：

`净利润 → 非现金损益 → 营运资本变化 → 税息及分类差异 → 经营现金流 → 资本开支 → 自由现金流`

重点检查：

- 利润长期高于经营现金流的原因；
- 折旧摊销、减值、拨备、递延税和股权激励等非现金项目；
- 政府补助、公允价值、投资收益、处置收益和汇兑是否反复贡献利润；
- 公司调整后指标排除了什么，排除项目是否实际反复发生；
- 经营现金改善是否来自应付款延后、票据、保理、税费时点或一次性收款，而非经营改善。

## 四、资产质量

### 1. 应收和合同资产

检查账龄、逾期、客户集中、坏账准备、核销、保理和期后回款。减值率下降若与客户风险和账龄恶化同时发生，需要解释。

### 2. 存货

检查原材料、在制品、产成品、在途和渠道库存，结合销量、采购、产能、产品更新、价格变化、库龄、跌价准备和期后销售判断。备货可以是主动策略，也可能掩盖需求放缓。

### 3. 固定资产和在建工程

检查长期未转固、转固后利用率不足、折旧年限变化、处置损失、闲置和减值。资本开支现金与资产余额差异应由应付设备款、非现金取得、并购、租赁或处置解释。

### 4. 无形资产和资本化支出

检查资本化条件、项目阶段、资本化率、摊销年限、项目失败和减值。资本化可能符合准则，但仍会把当期费用推迟到未来。

### 5. 商誉和并购资产

检查被收购业务的收入、利润、现金和协同是否兑现；减值测试中的增长率、利润率、折现率和终值假设是否承受得住压力情景。

### 6. 其他资产

关注其他应收款、预付款、长期投资、递延税资产、受限资金和复杂金融资产的交易对手、变现方式、估值依据及关联关系。

## 五、负债、准备和表外事项

检查：

- 债务、租赁、票据、供应链融资、保理和回购义务是否完整；
- 应付增加来自采购增长、账期优势还是延迟付款；
- 质保、诉讼、退货、重组、环境和其他准备是否充分且连续；
- 担保、承诺、最低采购、长期合同、资本承诺和未决诉讼是否可能形成现金支出；
- 关联交易、资金占用、资产转移和非经营性往来是否影响报表质量。

## 六、税务与权益

- 比较法定税率、有效税率和现金税率，解释永久差异、递延税、税收优惠和地域组合；
- 检查递延税资产是否依赖难以实现的未来利润；
- 检查少数股东损益、永续工具、可赎回权益、股权激励和可转债对归母利润、权益和稀释的影响；
- 回购、分红、增发和股份支付造成的每股指标变化要与公司整体利润变化分开。

## 七、可选量化预警

数据、行业和期间可比，且已核实完整模型定义、版本和输入时才计算。底表列公式、采用值及必要适用条件；模型信号用于定位后续核查，舞弊、破产或信用判断需另有相应证据。

### 1. Sloan 应计指标

按[公式参考](财务口径、公式与工作底表.md#七会计质量辅助指标)计算现金流口径应计比率。较高正值提示利润对非现金项目依赖较高，进一步检查增长、项目结算、季节性、营运资本和会计估计。

### 2. 杜邦分析

按[公式参考](财务口径、公式与工作底表.md#五资本效率)拆分盈利、周转、杠杆及必要的税负与利息影响，定位回报变化的来源。

### 3. Piotroski F-score

适用于有连续两期报表的非金融企业，观察盈利、现金质量、杠杆/流动性和经营效率九类二元信号。用于历史财务改善筛选，逐项输出信号及其财务含义。

### 4. Altman Z 系列

原始 Z、私营企业 Z' 和非制造/新兴市场 Z'' 的系数与区间不同。使用前先确认企业类型、市场价值数据和模型版本；银行、保险及许多特殊行业不适用。结果仅用于偿债风险预警。

### 5. Beneish M-score

八变量模型通常观察：应收增长、毛利变化、资产质量、销售增长、折旧、销售管理费用、应计和杠杆。必须使用同一模型的完整定义、方向和系数；增长公司可能因销售和应计变化被误报。结果用于进一步核查收入、资产和费用确认。

## 八、异常判断的记录方式

每项异常用同一张表记录：

`事项｜涉及科目和期间｜观察到的变化｜来源定位｜可能解释｜反证/替代解释｜现金与三表影响｜严重程度｜需要补什么材料｜当前结论`

严重程度基于对当前财务判断的影响，而不是数字看起来是否夸张：

- **重大：** 可能翻转利润、现金、偿债、持续经营或主要结论；
- **重要：** 不一定翻转整体结论，但会改变增长质量、资产质量或风险判断；
- **观察：** 当前影响有限，未来期间需要跟踪。

## 九、结束判断

会计质量核查汇总回答：

1. 报告利润与经营现金是否相互支持；
2. 主要资产是否能形成未来收入或现金；
3. 负债、承诺和融资义务是否完整；
4. 哪些会计估计和一次性项目最影响结论；
5. 哪些异常已有合理解释，哪些仍需补证；
6. 如果最不利解释成立，会改变哪项财务判断。
