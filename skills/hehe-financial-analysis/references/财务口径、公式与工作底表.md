# 财务口径、公式与工作底表

本参考用于计算、勾稽或创建财务分析工作底表时读取。使用时结合会计准则、业务模式和披露口径调整公式。

## 一、口径卡和符号

每项计算同时保留：

`指标｜公式｜分子｜分母｜主体/分部｜期间｜币种/单位｜平均/期末口径｜调整项｜数据来源｜适用限制`

- 收入、利润和流入为正；费用、损失和流出在展示层说明符号约定。
- 资产负债表用期末余额，周转和回报指标优先用期初期末平均余额。
- 月、季、半年和年度数据不直接比较；年化仅作为显式情境。
- 币种换算保留原币、汇率日期/类型和换算值。
- 百分点变化与百分比变化分开。

## 二、最小勾稽

### 资产负债表

`资产总额 − 负债总额 − 权益总额 = 0`

少数股东权益、永续债、可赎回权益或其他夹层工具按披露和任务用途单列，不静默塞入普通权益。

### 现金桥

`期初现金 + CFO + CFI + CFF + 汇率影响 + 其他现金变动 = 期末现金`

现金及现金等价物、受限现金和报表列示口径不一致时，先建立口径桥。

### 债务桥

`期初有息债务 + 新增借款 − 偿还 + 汇率/公允价值/非现金变化 = 期末有息债务`

租赁负债、应付票据、供应链融资、可转债和少数股东回售义务是否计入，必须显式说明。

### 固定资产桥

`期初净固定资产 + 资本开支 − 折旧 − 处置/报废 − 减值 + 汇率及其他 = 期末净固定资产`

资本开支与现金流量表购建资产支出不一致时，检查应付设备款、并购取得、非现金租赁和分类变化。

### 权益与留存收益桥

`期初权益 + 综合收益 + 发行/回购 + 股权激励 + 少数股东变化 − 分红 + 其他 = 期末权益`

### 差额与舍入容差

先核对主体、期间、单位、版本、抵销与字段映射，再判断舍入影响。设加总差额 `d = 披露总数 − Σ(a_i × 分项_i)`；各原值按最近单位四舍五入，统一单位后的最小披露步长为 `u_总、u_i`，则最大舍入误差界为 `E = u_总/2 + Σ(|a_i| × u_i/2)`。简单合计的 `a_i = 1`；精确原值对应误差为0，派生小计不重复计入底层误差。

`|d| ≤ E`记为“与舍入相容”，保留实际差额；超过E则查原因。截位、上下界或精度未知时，按实际取值区间核对或标记容差待定，不套用半单位公式。比例与乘积使用输入区间传播，报告显示的小数位不改变原值检查。

数值容差与事项重要性分开判断。超过容差的差额即使占比很小也保留待核状态；是否进入正文及是否继续补证，按其能否改变财务判断和事项性质处理，见[专项工作流程](专项工作流程.md)。

## 三、增长和利润

- 同比增长：`本期 / 上期 − 1`
- CAGR：`(终值 / 初值)^(1/期间数) − 1`；初值或终值为零/负数时不使用。
- 毛利率：`毛利 / 收入`
- 营业利润率：`营业利润 / 收入`
- 净利率：`归属口径净利润 / 对应收入`
- 费用率：`对应费用 / 收入`

常用结构分析：

- 利润表共同比：`某利润表科目 / 收入`
- 资产负债表共同比：`某资产或负债科目 / 总资产`
- 现金流强度：`某现金流项目 / 收入`，或按问题除以经营现金流/总现金流入
- 分部贡献：`某分部指标 / 公司合计指标`
- 变化贡献：`某分部或科目增减额 / 公司合计增减额`；合计增减额接近零或分项正负抵销时，不使用百分比贡献，改列增减金额

预算、指引或预测偏差：

- 金额差：`实际值 − 比较基准`
- 比例差：`实际值 / 比较基准 − 1`

比较基准为零、负数或口径不同时，不使用失真的比例差。

增长桥优先区分报告增长、并购/处置、汇率、会计口径、价格、数量和结构。

有同口径价格和数量时，可采用：

- 数量影响：`(本期数量 − 上期数量) × 上期价格`
- 价格影响：`(本期价格 − 上期价格) × 上期数量`
- 量价交互项：`(本期价格 − 上期价格) × (本期数量 − 上期数量)`；产品组合变化需另按产品权重拆分。

多产品、多地区或渠道差异明显时逐项计算后汇总；无法取得同口径数据时，不把收入余额拆成虚假的精确量价贡献。

毛利变化可用闭合桥：`Δ毛利 = (本期收入 − 上期收入) × 上期毛利率 + 本期收入 × (本期毛利率 − 上期毛利率)`。费用变化可按同式替换为费用率；再向下拆业务结构、价格、成本和一次性事项，避免父项与子项重复计量。

EBITDA、调整后利润和非 GAAP 指标必须保留公司定义与本研究定义。股权激励、资本化研发、租赁和重组费用是否调整，按用途决定并双列影响。

经营杠杆可以观察：

- 增量营业利润率：`Δ营业利润 / Δ收入`
- 费用弹性：`费用同比变化率 / 收入同比变化率`

收入变化接近零、正负方向相反或存在并购重述时，改看金额桥。

## 四、现金和营运资本

- 简化自由现金流：`CFO − 资本开支`。必须标记是否包含并购、租赁本金、资本化开发、处置或利息分类差异。
- 经营现金转换：可比较 `CFO / 净利润`、`CFO / EBIT` 或 `CFO / EBITDA`，但分母接近零或为负时不计算比率，改看绝对差额和驱动。
- 经营性营运资本：`经营性流动资产 − 经营性流动负债`；排除现金、短期投资、有息债务等融资项目，具体分类需公开。
- 营运资本变动：`期末经营性营运资本 − 期初经营性营运资本`；与现金流量表符号可能相反，要做桥。
- 现金流应计项：`净利润 − 经营现金流`
- 资本开支强度：`资本开支 / 收入`
- 自由现金流率：`自由现金流 / 收入`

周转天数常用形式：

- DSO：`平均应收账款 / 信用销售收入 × 期间天数`
- DIO：`平均存货 / 销售成本 × 期间天数`
- DPO：`平均应付账款 / 采购额 × 期间天数`
- CCC：`DSO + DIO − DPO`

采购额不可得时，用销售成本替代必须标为代理。预收、合同资产/负债、项目里程碑和季节性显著时，应增加相应周转指标或滚动期间，不机械使用年末余额。

## 五、资本效率

### ROIC

`ROIC = NOPAT / 平均投入资本`

常用：`NOPAT = EBIT × (1 − 适用税率)`。说明采用规范化现金税率还是法定税率；亏损、税盾或地域差异大时，分别核算相关税项。

投入资本至少用两种视角勾稽：

1. 融资视角：`有息债务 + 权益 + 其他融资性资本 − 非经营现金/投资`
2. 经营视角：`经营资产 − 无息经营负债`

两种构造差额可能来自商誉、租赁、养老金、递延税、少数股东、资本化研发或分类错误。不能为得到理想 ROIC 随意选择口径。

### 增量 ROIC

`增量 ROIC = ΔNOPAT / Δ投入资本`

只在期间可比、投入与收益时滞合理且分母不接近零时使用。并购、重大处置或周期拐点需拆开。

### 其他回报指标

- ROE：`归母净利润 / 平均归母权益`
- ROA：`对应利润口径 / 平均资产`

负权益、巨额回购、金融杠杆、资产重估和一次性损益会显著扭曲比率，应同时解释绝对资本和现金结果。

### 杜邦拆解

三因素：

`ROE = 净利率 × 总资产周转率 × 权益乘数`

其中：

- 净利率：`归母净利润 / 收入`
- 总资产周转率：`收入 / 平均总资产`
- 权益乘数：`平均总资产 / 平均归母权益`

五因素可用：

`ROE = 税负 × 利息负担 × 营业利润率 × 资产周转率 × 财务杠杆`

EBIT、税前利润、归母利润和权益采用对应定义，各因子的平均余额口径保持一致。

### 再投资与增长

- 再投资额可按问题采用：`资本开支 − 折旧摊销 + 经营性营运资本增加 + 其他经营性长期投入`
- 再投资率：`再投资额 / NOPAT`
- 基于稳定关系的增长提示：`再投资率 × 增量或边际资本回报`

该关系是分析工具，不是自动预测公式。并购、重大处置、亏损、投入产出时滞和会计口径变化显著时必须调整。

## 六、流动性和杠杆

- 净债务：`有息债务 − 可自由使用现金及等价物`；受限现金和业务必需现金不能自动抵扣。
- 净债务/EBITDA：只在 EBITDA 为正、口径稳定且债务定义一致时使用。
- 利息覆盖：可用 `EBIT / 利息费用` 或 `CFO 前利息 / 现金利息`；必须说明口径。
- 流动比率、速动比率：受季节性、供应链融资和受限资产影响，不能单独证明偿债安全。
- 现金跑道：`可用现金 / 情境月度净现金消耗`；现金消耗必须基于明确期间和情境。
- 债务到期覆盖：`(可用现金 + 同期间可用于偿债的经营现金 + 满足提款条件的未用承诺授信) / (同期间到期本金 + 待付利息)`；可用金额先扣除维持经营与必要资本支出占款，已扣利息不重复计入。
- 契约余量：按契约定义计算 `实际指标与触发阈值之间的距离`，不得用普通财务指标替代合同口径

债务分析至少列到期日、利率、币种、固定/浮动、担保、契约、再融资依赖和可用授信。

## 七、会计质量辅助指标

预警模型的选择、适用条件与异常解释见[会计质量与异常核查](会计质量与异常核查.md)。

### Sloan 应计

优先使用现金流口径：

`应计比率 = (净利润 − 经营现金流) / 平均总资产`

Sloan结果结合营运资本和非现金项目解释；Piotroski、Altman和Beneish按会计质量参考核实版本及输入后选用。

## 八、历史—情景桥

经营驱动选择和情景传导见[三表重构与预测模型](三表重构与预测模型.md)。输入区区分事实基线、计算、推断与情景，关键假设记录依据、观察指标和失效条件。

常用预测关系示例：

- 收入：按业务使用`销量 × 单价`、`期间付费客户当量 × 同期间ARPU`、`符合确认口径的交易金额 × 佣金率`或`合同金额 × 当期收入确认比例`，明确期间与总额/净额口径；
- 毛利：`收入 − 销售成本`，销售成本由采购、材料、履约、产品结构或毛利率假设形成；
- 应收：`信用销售收入 × DSO / 期间天数`；
- 存货：`销售成本 × DIO / 期间天数`；
- 应付：`采购额 × DPO / 期间天数`；
- 固定资产：`期初净额 + 资本开支 − 折旧 − 处置/减值 ± 其他 = 期末净额`；
- 债务：`期初债务 + 新增 − 偿还 ± 非现金变化 = 期末债务`；
- 利息：按平均债务、利率、现金利息和资本化利息规则计算；
- 留存收益：`期初留存收益 + 净利润 − 分红 ± 调整 = 期末留存收益`；
- 现金：由三类现金流和汇率变化形成，不手工填入目标余额；如使用循环信贷补足最低现金，显式显示公式和开关。

## 九、工作簿结构与公式流向

以下是内容模块，不是每个任务都必须建立的固定 Sheet。完整企业分析或预测模型通常全部使用；专项问题可以合并，只要原值、计算、检查和结果仍能追溯。

### `报告索引`

按[交付模板](财务分析交付模板.md)，以报告章节和关键指标建立索引，记录：

`报告章节｜关键指标｜Markdown 文件名｜Excel 工作表｜关键范围｜主要结论｜来源材料/字段ID`

同一指标在一个计算区维护公式，其他工作表和报告引用该结果。索引只负责定位。

### `00_范围口径`

主体、分部、期间、币种、准则、版本、审计状态、符号、指标定义和情景名称。

### `01_原始数据`

只存来源原值和定位；禁止公式覆盖。每行保留字段 ID，供后表引用。

### `02_标准化三表与分部`

标准化字段、重分类、调整桥、分部合计、抵销和合并结果。调整列与原值列分开。

完整模型可以按利润表、资产负债表和现金流量表拆成多张 Sheet，也可以在同一 Sheet 分区；必须保持期间和字段一致。

完整任务按交付模板的时间覆盖建立年度追踪区，并与中期数据分区。

### `03_必要附表`

按题建立收入与经营驱动、营运资本、固定资产/折旧、无形资产/摊销、债务/利息、税、权益、租赁或其他附表。附表与三表双向勾稽，但公式流仍从输入和驱动流向报表。

### `04_勾稽检查`

资产负债表、现金、债务、固定资产、权益及分部桥；显示差额和状态，不用颜色代替数值。

### `05_驱动与财务质量`

增长桥、利润桥、现金转换、营运资本、资本开支、资本效率、流动性和异常项。

### `06_情景与敏感性`

输入区、基准/改善/压力情景、关键变量、结果和翻转条件。公式不得与输入混在同一单元格。

### `07_可复用结果`

保存已确认字段、定义、期间、来源、状态与限制，供当前任务交付或后续分析复用。

数据与公式保持单向流动：

`范围口径、原始数据和情景假设 → 标准化与分析计算 → 报告结果`

`04_勾稽检查` 只读取原始数据和计算结果并显示差额，不反向参与业务计算；`07_可复用结果` 只引用已完成的分析结果。

修改既有模板前识别输入区、公式区、跨表链接和命名范围；视觉格式调整保持分析结构与公式不变。

## 十、Excel 验收

- 原始数据使用可计算的数值，保留字段 ID、来源、期间、币种和单位；
- 历史原值和明确假设可以作为输入，派生值、预测值、桥表和检查项使用公式；
- 关键公式可以一致复制，历史值、调整值和情景值不相互覆盖；
- 缺失、零、不适用和公式错误分别处理；检查项显示通过、差额或不可检查，保留差额数值；
- 扫描预测期硬编码、同一行不一致公式、跨表断链、期间错位、单位混用和隐藏覆盖；
- 重新计算后检查意外公式错误和循环引用，勾稽表显示真实差额；
- 修改一个代表性输入，确认相关结果和检查项同步变化；
- 保存后重新打开 `.xlsx`，回读关键公式、结果和状态并检查关键 Sheet 的显示；
- 核对报告章节、关键指标、数值与 Excel“报告索引”及对应范围一致；随机抽查至少三项报告数值能追到公式和来源。

## 十一、特殊情况

以下只提示通用框架的调整方向。详细方法见[行业财务口径适配](行业财务口径适配.md)；缺少对应方法时，使用仍然适用的部分并列明未覆盖项。

- 银行、保险和其他金融机构：普通工业企业的营运资本、净债务/EBITDA 和 ROIC 往往不适用，应使用资本充足、资产质量、准备金、净息差、偿付能力等专门框架。
- 非上市或早期公司：优先分析现金跑道、融资依赖、毛利/贡献利润、回款、客户集中和有限披露边界；不补造完整报表。
- 并购活跃公司：拆有机/并购增长、购价分摊、商誉、少数股东、或有对价、重组和协同兑现。
- 高通胀或多币种：区分交易、折算、名义/实际增长和汇兑对现金/权益的影响。
- 季节性业务：优先使用滚动十二个月、同期比较和平均余额，避免只看单一季末。
