# 三表重构与预测模型

本参考用于重建历史三表、必要附表及其联动，建立预测、情景和压力测试。

## 一、先判断需要哪种模型

| 任务 | 模型要求 |
|---|---|
| 历史财务诊断 | 标准化历史三表、分部、主要附表和勾稽；不强制预测 |
| 业绩更新 | 新期间接入原历史模型，建立实际与上期/预算/指引/预测的偏差桥 |
| 专项问题 | 只建立能回答问题的科目表和三表影响，不生成无关空表 |
| 完整预测 | 历史三表、经营驱动、附表、预测三表、情景和模型检查联动 |
| 压力测试 | 在基准模型上改变关键经营或融资条件，观察利润、现金、债务和契约的传导 |

## 二、模型的基本结构

工作簿的内容分层、原值与公式流向见[财务口径、公式与工作底表](财务口径、公式与工作底表.md)。本参考规定各表如何构建和联动。

## 三、历史三表重构

### 1. 原始字段映射

为每个字段保留：

`字段ID｜报表/附注｜原字段名｜标准字段名｜主体/分部｜期间｜原值｜单位｜符号｜来源定位｜重述/调整｜采用值`

公司自定义科目、准则差异和期间分类变化不能静默合并。相同名称含义不同或不同名称含义相同时，记录映射理由。

### 2. 利润表

至少建立适用的：收入、销售成本、毛利、销售/管理/研发费用、其他经营损益、营业利润、利息与其他非经营损益、税前利润、所得税、公司整体净利润、少数股东损益、归母净利润和每股收益。

同时保留公司披露的 EBITDA、调整后利润或非 GAAP 指标及其对账，不自行把定义不同的指标并成一条历史序列。

### 3. 资产负债表

至少建立适用的：现金与受限资金、短期投资、应收与合同资产、存货、预付与其他经营资产、固定资产与在建工程、无形资产与商誉、长期投资、其他资产；应付与合同负债、短长期债务、租赁、准备与其他负债；股本、储备、留存收益、少数股东权益和其他权益工具。

### 4. 现金流量表

保留公司采用的直接法或间接法结构，并将：

- 净利润与经营现金流相连；
- 营运资本变化与资产负债表相连；
- 折旧摊销与长期资产附表相连；
- 资本开支与固定资产/在建工程相连；
- 借款、偿还、分红、回购和发行与债务、权益附表相连；
- 期末现金与资产负债表及现金口径桥相连。

### 5. 分部与合并

建立：

`分部合计 + 未分配项目 + 内部交易抵销 + 其他调整 = 合并结果`

只在披露支持时拆分分部资产、利润、资本开支和现金。不能可靠分配的总部费用、税、资金和抵销项单列，不按收入机械分摊。

## 四、必要附表

### 1. 收入与经营驱动表

按[公式参考的历史—情景桥](财务口径、公式与工作底表.md#八历史情景桥)选择销量与单价、付费客户与ARPU、交易金额与佣金率或合同确认驱动，统一期间、履约和总额/净额口径。

分部、产品、地区、客户或渠道至少选择一个能解释收入变化的层级。无法取得经营量时，保留收入和结构驱动，不虚构量价拆分。

### 2. 营运资本表

按业务建立应收、合同资产、存货、预付、应付、票据、合同负债及其他项目的余额、周转和现金影响。预测时使用周转天数、收入/成本比例、合同节点或其他可解释驱动，而不是简单复制上一年余额。

### 3. 固定资产、在建工程和折旧表

按[公式参考的固定资产桥](财务口径、公式与工作底表.md#二最小勾稽)跟踪余额，单列资本开支/取得、转入、处置、折旧、减值及汇率变化。

必要时按资产类别、项目、地区或产能拆分。折旧年限、残值率、建设期和转固时间应与附注及经营计划一致。

### 4. 无形资产、资本化研发和摊销表

区分外购、内部开发、并购取得和商誉；跟踪新增、摊销、减值、处置和汇率。不能把研发现金支出、资本化研发和利润表研发费用混为一项。

### 5. 债务和利息表

逐项列期初余额、新增、偿还、非现金变化、期末余额、利率、币种、到期和担保；利息由平均债务、利率及现金利息/资本化利息规则计算。循环借款或现金补足机制如形成循环引用，明确模型处理方式和关闭开关。

### 6. 税务表

连接税前利润、当期税、递延税、现金税、亏损结转和有效税率。多地区、税收优惠、亏损或递延税资产较大时，不能用单一税率机械预测。

### 7. 权益表

按[公式参考的权益桥](财务口径、公式与工作底表.md#二最小勾稽)连接综合收益、发行、股权激励、分红、回购及少数股东变化。

每股收益预测还需连接期初股份、发行、回购、期权、可转债和加权平均股份。

## 五、三表联动

预测三表至少满足：

- 净利润从利润表进入现金流量表和留存收益；
- 折旧摊销从资产附表进入利润表和现金流量表；
- 营运资本变化从资产负债表进入经营现金流；
- 资本开支从现金流量表进入固定资产/在建工程附表；
- 债务新增和偿还同时影响现金流量表、资产负债表和利息费用；
- 分红、回购和发行同时影响现金流量表、权益和股份数量；
- 现金流量表期末现金及等价物，与资产负债表及附注经口径桥调整后的对应金额一致；
- 每期资产等于负债加权益。

预测单元格不得独立硬填一套利润、现金和资产负债结果。

## 六、驱动式预测

### 1. 收入

优先按分部或业务建立数量、价格、客户、渗透率、续费、合同进度、费率、产品结构或地区驱动。历史增速只可作为参考，不能自动成为预测。

### 2. 毛利和费用

- 毛利：售价、采购、产品结构、产能利用、履约和汇率；
- 销售费用：获客、渠道、销售人员、推广或收入比例；
- 管理费用：组织规模、固定成本、一次性事项；
- 研发费用：人员、项目、费用化/资本化和开发阶段；
- 股权激励、折旧摊销和减值分别建模，不隐藏在统一费用率中。

### 3. 营运资本和资本开支

营运资本用业务适用的周转、合同或收入/成本比例驱动；资本开支连接维护、扩产、门店、研发、数字基础设施或项目建设计划，并通过折旧和产能影响未来期间。

### 4. 融资、税和现金

根据到期债务、最低现金、资本开支、分红回购和授信设置融资。税务考虑地域、优惠、亏损和递延税。现金是三表联动后的结果，不作为任意平衡数；如使用循环信贷补足，必须清楚显示。

## 七、情景、敏感性和压力测试

### 1. 情景

基准、改善和压力情景应改变能够解释业务的驱动，而不是直接改变净利润。可调整：销量、价格、产品结构、毛利、费用投入、回款、库存、资本开支、利率和融资可得性。

参数优先取企业自身可比历史、已生效合同、订单履约与产能约束；可比企业和行业数据经口径调整后作外部参照。记录关键参数的来源期间、采用区间、选择依据及更新触发。历史异常期单列，基准须能解释已有经营结果。

情景幅度对应实际事件或约束，如合同调价、客户流失、回款延迟、投产或融资推迟；联动相关变量，避免把互不相容的最好或最差端点拼成一组。用户指定值作为指定假设保留。资料只能支持区间时输出区间；无法校准结果时优先反求盈亏平衡、最低回款或资金门槛。任意数值只用于用户明确需要的计算演示。

低披露条件下的最低输入、四类计算及缺数处理见[无完整财报企业的财务分析](无完整财报企业的财务分析.md)。

### 2. 敏感性

选择真正可能翻转结论的少数变量，观察对收入、营业利润、经营现金、自由现金、最低现金、债务和契约余量的影响。不要为了展示而生成大量无决策用途的二维表。

### 3. 压力传导

输出：

`冲击条件 → 收入/毛利 → 营运资本 → 经营现金 → 债务/利息 → 最低现金与契约 → 缓冲措施 → 失效时间`

## 八、模型检查

依照第五节逐项检查三表及附表联动，核对分部抵销和未分配项能否追溯。通用勾稽公式及硬编码、断链、错误、输入扰动和保存重开检查统一执行[财务口径、公式与工作底表](财务口径、公式与工作底表.md)。

### 合理性检查

- 增长、毛利、周转、资本开支、债务和税率是否能由经营事实解释；
- 改善情景是否真的比基准改善，压力情景是否真正传导到现金和债务；
- 预测末期是否出现无原因的增长加速、利润率跳升、负债消失或现金无限积累；
- 历史异常年是否被错误当作正常基准。

结合勾稽结果与假设依据判断模型是否可用，关键假设的变化须传导到财务结果。
