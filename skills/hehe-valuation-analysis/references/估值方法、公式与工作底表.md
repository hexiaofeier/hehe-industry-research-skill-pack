# 估值方法、公式与工作底表

本文件用于估值方法选择、公式计算、工作表构建和计算审计。只在任务需要实际估值或检查模型时读取；公式是结构，不会自动产生可靠输入。

## 一、建议工作簿结构

| 表 | 用途 | 最小内容 |
|---|---|---|
| `00_设置与输入` | 冻结对象并登记输入血缘 | 设置卡、输入地图、假设类型、审核状态、单位/币种/日期 |
| `01_规范化与调整` | 从报告值桥接估值输入 | 报告值、调整项、理由、税务、规范化值、上游定位 |
| `02_可比与交易` | 建立对象池和倍数 | 可比理由、财务口径、价格日、EV/权益桥、倍数、不可比项 |
| `03_DCF` | 现金流与现值 | 驱动、FCFF/FCFE、折现率、终值、现值、检查项 |
| `04_SOTP_资产_里程碑` | 处理异质分部或特殊情境 | 分部/资产/里程碑、方法、价值、共享项、概率/折扣边界 |
| `05_价值桥与敏感性` | 汇总价值区间和翻转变量 | EV—权益桥、股数、情景、敏感性、反向估值 |
| `06_结论与交接` | 记录判断和限制 | 方法状态、区间、隐含条件、不可比项、缺口、下游字段 |

每个单元格或输入至少能追溯到：

`输入 ID｜变量｜数值｜单位｜币种｜主体｜期间/时点｜事实/调整/情境｜来源或上游定位｜审核状态｜公式依赖｜备注`

工作簿应区分输入、公式和输出，避免硬编码覆盖公式。格式化不得改变公式、数值精度或空缺状态。

## 二、价值口径与调整桥

### 1. 企业价值与普通股价值

常用概念桥：

`普通股股权价值 = 企业价值 - 债务及债务类项目 - 优先权 - 少数股东权益 + 可用现金 + 非经营资产 - 其他非经营负债`

该式是检查框架，不是统一会计公式。逐项判断：

- 债务是否已影响现金流或倍数分母；
- 租赁、养老金、保理、供应链融资和担保是否债务化；
- 现金是否受限、经营必需或不可汇回；
- 联营、投资性资产是否已经进入经营利润或分部价值；
- 少数股东的利润、现金流与价值是否同口径；
- 优先股、可转债、期权和认股权证按何种权利、稀释或负债口径处理。

### 2. 每股或每单位价值

`每股情境值 = 普通股股权价值 ÷ 完全摊薄股数`

完全摊薄股数应说明使用库藏股法、如果转换法、财报摊薄股数或情境转换。深度价内、价外工具和融资轮权利不同，不能只用一个静态股数。

### 3. 规范化桥

`报告指标 +/− 一次性/非持续/口径调整 = 规范化估值指标`

每项调整登记：

`报告值｜调整方向｜税前/税后金额｜是否现金｜是否经常发生｜是否可能再次发生｜估值方法影响｜依据`

“调整后”不能成为移除所有负面项目的借口。经常出现的重组、股权激励、诉讼、减值或获客支出可能具有持续经济意义。

## 三、可比公司估值

### 1. 对象池与可比矩阵

字段：

`公司｜业务/产品｜地域｜客户/收费｜规模｜增长｜毛利/利润率｜资本强度｜生命周期｜财务风险｜会计口径｜可比结论｜排除/保留理由`

先按经济机制判断可比，再看行业标签。对象不足时可以扩大参照，但必须标为“有限参考”。

### 2. 常用倍数匹配

| 价值分子 | 可匹配分母 | 常见限制 |
|---|---|---|
| 企业价值 EV | 收入、ARR、EBITDA、EBIT、NOPAT、FCFF | 资本结构中性，但需处理租赁、少数股东和负利润 |
| 普通股市值/价值 | 净利润、EPS、账面权益、FCFE、股利 | 受资本结构、优先权、回购/稀释影响 |
| 资产/项目价值 | 储量、产能、面积、用户等经营单位 | 必须证明单位经济、质量、利用率和权利可比 |

基本公式：

`EV/收入 = 企业价值 ÷ 同期收入`

`EV/EBITDA = 企业价值 ÷ 同期 EBITDA`

`P/E = 普通股市值 ÷ 归属普通股股东净利润`

`P/B = 普通股市值 ÷ 归属普通股股东账面权益`

同一期限写清是历史、LTM、NTM 或具体年度。价格日和预测版本日要登记；跨币种先按一致汇率折算。

### 3. 从倍数到价值

`隐含企业价值 = 目标经营指标 × 选定 EV 倍数`

`隐含股权价值 = 目标权益指标 × 选定权益倍数`

倍数选择可以参考中位数、区间、业务/增长/利润差异或有依据的回归，但必须公开逻辑。不要把最高倍数给“最好公司”、最低倍数给“最差公司”而没有变量映射。

### 4. 可比倍数交叉检查

- 收入倍数需与毛利、利润率、留存、资本强度和现金转换同时解释；
- EBITDA 倍数可能忽略资本开支、租赁和营运资本；
- P/E 受杠杆、税率、一次性项目和回购影响；
- P/B 更适用于资产与盈利能力相关的业务，需结合 ROE/资产质量；
- 负分母、接近零分母和极端值不宜机械纳入统计。

## 四、可比交易估值

交易表字段：

`交易日/宣布日｜买方｜标的｜权益范围｜企业/股权价值｜现金/股份/或有对价｜控制权｜协同｜标的财务期｜倍数｜完成状态｜市场环境｜可比性｜来源`

检查：

- 宣布、签约、批准、交割和最终支付是否混用；
- 对价是否包含债务承接、营运资本调整、earn-out、滚存股权或其他权利；
- 控制权溢价与买方协同是否适用于当前任务；
- 历史利率、行业周期、监管和融资环境是否可比；
- 失败交易不应与已完成交易无差别混合。

可比交易常用于边界和交叉检查，不自动优于交易可比性更高的其他方法。

## 五、DCF：FCFF 与 FCFE

### 1. FCFF

常见结构：

`FCFF = EBIT × (1 - 经营税率) + 折旧摊销 - 资本开支 - 营运资本增加 +/− 其他经营调整`

也可从经营现金流桥接，但要避免营运资本、税和资本开支重复计算。

`企业价值 = 显性期 FCFF 现值 + 终值现值`

`FCFF_t 现值 = FCFF_t ÷ (1 + WACC)^t`

### 2. FCFE

常见结构：

`FCFE = 归属普通股净利润 + 非现金费用 - 资本开支 - 营运资本增加 + 净借款 +/− 其他权益现金调整`

`普通股价值 = 显性期 FCFE 现值 + 权益终值现值`

`FCFE_t 现值 = FCFE_t ÷ (1 + 股权成本)^t`

FCFE 对融资政策更敏感。债务路径不稳定或资本结构显著变化时，先说明适用限制。

### 3. WACC 与资本成本

常见结构：

`WACC = E/(D+E) × Re + D/(D+E) × Rd × (1-T)`

若有优先资本或其他工具，应按价值权重和相应成本扩展。权重通常反映估值时点或目标资本结构，但必须说明选择。

CAPM 可作为股权成本的一种估计：

`Re = 无风险利率 + Beta × 股权风险溢价 + 经明确说明的其他风险项`

注意：

- 无风险利率、风险溢价、Beta、债务成本和税率都有币种、期限、时点和业务口径；
- 不能机械叠加流动性、小公司、国家、治理等多个风险溢价造成重复计数；
- 折现率不是用来修正不可信预测的万能旋钮；预测风险和资本成本风险要分开处理；
- 对私有/早期项目可用情景或目标回报作压力测试，但不得把用户期望收益写成客观资本成本。

### 4. 终值

永续增长法：

`终值_n = FCFF_(n+1) ÷ (WACC - g)`

需满足 `WACC > g`，并检查稳定期增长、利润率、再投资和资本回报是否互相一致。

退出倍数法：

`终值_n = 终值年度经营指标 × 退出倍数`

退出倍数必须匹配终值年度业务、增长、利润和市场环境；使用当前倍数会把市场定价假设带入“内在价值”。

终值占比过高不是自动失败，但提示显性期未覆盖关键稳定过程。应延长显性期、调整模型结构或扩大区间，而不是隐藏问题。

### 5. 中期现金流与时点

年度模型使用年末或年中折现必须一致。可使用年中惯例：

`现值 = 现金流_t ÷ (1 + 折现率)^(t-0.5)`

若估值日在财年中间，处理从基期到估值日的 stub period，避免把已发生现金流再次折现。

## 六、SOTP 与共享项目

分部表：

`分部｜经济机制｜经营指标｜估值方法｜情景参数｜企业/股权价值｜内部交易｜共享资产/负债｜少数股东｜价值区间｜限制`

基本桥：

`SOTP 股权价值 = 各分部价值合计 - 总部/共享净负债 - 其他未分配负债 + 未分配非经营资产 - 重复项目`

注意：

- 总部成本不能既从分部利润扣除又单独资本化扣除；
- 内部交易和共享资产应消除或分配，不能重复估值；
- 分部价值口径要统一到企业或权益层；
- 控股平台折价、税务泄漏和处置成本需有任务依据，不能套固定比例。

## 七、资产、股利与特殊主体

### 1. 调整后净资产或 NAV

`调整后净资产 = 资产可实现价值合计 - 负债及处置成本合计`

每项资产记录账面值、调整依据、变现时间、权利限制、税费和价值区间。资产价值与持续经营价值不可无说明地相加。

### 2. 股利折现

稳定增长的简化结构：

`权益价值 = 下一期可持续股利 ÷ (股权成本 - 长期股利增长率)`

只在分配政策、监管资本和盈利可持续性能够解释时使用。股利增长必须与留存、ROE 和资本要求一致。

### 3. 金融、保险、地产、资源与困境主体

这些主体可能需要监管资本、资产质量、嵌入价值、NAV、储量/产量、清算顺位或回收率等专门模型。通用 Skill 应：

1. 标记行业特殊性；
2. 读取专门口径或另行扩展；
3. 在缺少专门方法时缩小结论，不用普通 FCFF/EBITDA 模型伪装完成。

## 八、早期项目与里程碑情景

建立状态树：

`当前验证状态 → 下一里程碑 → 所需资本 → 稀释/权利 → 达成时间 → 达成后经营状态与价值 → 未达成/停滞价值`

情境期望值仅在概率作为显式参数时计算：

`情境期望值 = Σ（情境价值 × 情境概率）`

概率总和检查为 100%，但概率本身不因公式而变成事实。可同时输出不加权的情境区间，避免一个主观概率掩盖尾部风险。

融资后普通股价值还需处理：

`融资前价值 + 新资金 - 交易成本/即时用途调整 = 融资后整体价值（情境）`

不同证券的清算优先、参与权、反稀释、转换和回购条款可能使“融资后估值”与普通股经济价值不同，应读取治理与交易权利输入。

## 九、敏感性、翻转点和反向估值

### 1. 敏感性表

优先使用一维或二维表回答具体问题，例如：

- WACC × 永续增长率；
- 收入增长 × 经营利润率；
- 退出倍数 × 里程碑时间；
- 融资金额 × 稀释率；
- 可比倍数 × 规范化指标。

变量范围记录：`来源｜中心值｜上下界｜步长｜是否压力情境｜改变该范围的证据`。

### 2. 翻转点

翻转点回答“什么参数达到什么位置时，结论状态或相对关系改变”。可以用目标价值反求增长、利润率、折现率、终值倍数或里程碑。

不要只输出最乐观/最悲观单元格；说明哪些组合违反业务、财务或数学约束。

### 3. 反向 DCF

由当前企业价值反推经营假设时：

1. 从市场普通股价值建立 EV 桥；
2. 冻结折现率、终值和其他参数；
3. 只反求一个或少数可解释变量；
4. 将隐含值与历史、上游情景和行业边界比较；
5. 输出“价格要求什么成立”，不宣称市场真的相信该假设。

## 十、计算审计

至少检查：

1. 企业价值与股权价值桥是否闭合；
2. 估值分子与经营/权益分母是否匹配；
3. 价格日、汇率日、财务期和预测版本是否一致；
4. 历史、LTM、预测和情境是否被明确标记；
5. 债务、租赁、现金、少数股东、联营和优先工具是否重复或遗漏；
6. 股数与利润是否同为基本或摊薄口径；
7. DCF 现金流、折现率和终值是否同一价值层级；
8. 终值增长率、资本回报、再投资和稳定利润率是否相容；
9. SOTP 内部交易、总部成本和共享资产是否重复；
10. 情境概率、权重和区间是否有依据且合计正确；
11. 敏感性是否包含真正翻转结果的变量；
12. 空白、零、不可用、未披露和不适用是否被区分。

重要公式旁设置检查单元格，使用 `OK/待核/不适用`，不要让总值看似正常掩盖局部断链。

## 十一、结果表达

方法结果表：

`方法｜状态｜价值口径｜低/中/高情境｜关键参数｜适用理由｜主要限制｜是否纳入最终区间`

最终区间应说明形成方式：

- 一个主方法的多情景区间；
- 多个适用方法的共同范围；
- 主要方法加有限交叉检查；
- 信息不足下的条件边界；
- 暂不判断。

不要默认平均方法中点。若采用权重，记录权重的决策含义、来源和敏感性。

向下游保留：

`价值口径｜估值时点｜情景区间｜方法与适用性｜关键输入｜隐含要求｜翻转变量｜当前价格/交易条件｜限制｜不可回写项`

模型价值不是预计成交价，也不是投资建议；流动性、控制权、交易执行和投资者约束对结果的限制须单列，未核清时不推断实际交易回报。
