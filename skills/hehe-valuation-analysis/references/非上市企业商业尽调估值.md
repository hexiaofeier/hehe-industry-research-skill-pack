# 非上市企业商业尽调估值

本文件用于非上市企业只有两三年管理报表、科目汇总或较粗财务数据，但商业尽调仍需形成估值区间的任务。目标是同时回答两件事：企业按当前可核验经营状态值多少钱；达到明确经营和 IPO 里程碑后可能支持多大价值。

## 一、先确认估值和交易口径

记录：

`法律与经营主体｜纳入业务范围｜100%企业价值/股权价值/融资前估值/融资后估值｜控制权或少数权益｜估值时点｜财务基期｜币种｜交易阶段｜预计持有或上市时间｜证券权利`

- 控股并购先确定是否采用无现金无负债口径、正常营运资本基准和交割调整。
- 股权融资分清新股、老股、融资前与融资后估值，登记新增资金、稀释和优先权。
- IPO 准备项目分清当前股权价值、IPO 时点融资前价值、发行后市值和当前股东届时持股价值。

## 二、建立最低可用估值财务

不要求为了估值重建完整三表，但至少形成以下六组输入。优先整理最近两至三年、最近一期和 LTM；无法形成 LTM 时使用最近年度与可比期间，并标明日期。

| 输入组 | 最低内容 | 主要核对材料 |
|---|---|---|
| 收入 | 产品、客户、地区或渠道收入，确认时点，退款与内部交易 | 合同、订单、交付、发票、纳税和银行回款 |
| 毛利与单位经济 | 直接材料、采购、生产或履约成本，毛利和关键单位贡献 | 成本台账、采购、库存、生产或项目记录 |
| 规范化利润 | 营业利润、折旧摊销和可识别调整，形成 EBITDA、EBIT 或其他适用指标 | 管理报表、总账、工资、关联交易和费用明细 |
| 现金转换 | 应收、存货、预付、应付、合同负债及坏账或跌价 | 账龄、库存、流水、客户和供应商抽样 |
| 资本投入 | 维持与扩张资本开支、研发投入及未来资金需求 | 固定资产、项目预算、产能和研发记录 |
| 价值桥 | 现金、有息债务、股东借款、租赁、担保、或有负债、非经营资产、股权和优先权 | 银行、借款协议、章程、股东名册及重大合同 |

每项输入标明 `已交叉核对｜管理材料且内部一致｜计划或口述｜冲突/缺失`。基准估值优先使用已交叉核对的数据；管理材料能够勾稽但外部凭证不足时可以进入基准区间，同时扩大区间并保留状态；计划或口述只进入情景。

## 三、形成规范化指标

建立：

`原始管理口径 → 会计与范围统一 → 一次性或非经营调整 → 关联交易与市场化调整 → 规范化经营指标`

重点检查创始人或关联方薪酬、个人化费用、非公允关联采购或销售、政府补助、经常发生的“偶发”费用、股权激励、费用化与资本化研发、租赁、坏账、存货减值、一次性项目和停业业务。

调整必须有金额、方向、理由和材料。管理层希望剔除的支出如果会随业务持续发生，保留在规范化成本中。收入可靠但利润科目不够可靠时，不强行得到精确 EBITDA，可改用收入或毛利倍数并对可实现利润率做交叉检查。

## 四、按可核验指标选择主方法

| 经营与数据状态 | 优先方法 | 必须同时检查 |
|---|---|---|
| 已盈利且规范化 EBITDA 可核验 | 可比交易或可比公司 EV/EBITDA | 资本开支、营运资本、租赁和增长差异 |
| 收入可靠、成本费用仍粗 | EV/收入或 EV/毛利 | 毛利质量、成熟利润率、获客和履约投入 |
| 订阅或持续收费业务 | EV/ARR 或经常性收入倍数 | 留存、扩张、毛利、获客回收和现金消耗 |
| 项目制、订单制或产能爬坡 | 已实现收入或利润倍数加订单兑现情景 | 订单约束、取消、交付、验收、回款和新增资本 |
| 资产价值主导或经营承压 | 调整后净资产、重置或处置价值 | 资产权利、可实现性、时间和处置成本 |
| 尚未形成稳定收入或利润 | 单位经济与里程碑情景 | 下一里程碑、所需资本、失败价值和稀释 |

上市公司可比反映公开市场定价，可比交易更接近控制权交易条件。先按业务机制、规模、增长、利润率、客户质量和资本强度筛选，再把私营、规模、流动性、治理或控制权差异映射到具体变量和情景；不要机械叠加固定折价或溢价。

当前企业价值区间的基本形式为：

`当前企业价值区间 = 规范化经营指标区间 × 可解释的倍数区间`

经营指标和倍数分别做敏感性，避免用一个乐观指标同时配最高倍数而不说明成立条件。

## 五、DCF 的使用条件

只有以下输入能够形成可复核经营桥时，才把 DCF 作为主方法：

- 收入能由客户、产品、产能、价格、留存或订单等驱动解释；
- 毛利和经营费用与业务扩张机制相容；
- 营运资本、资本开支、税和融资需求没有被省略；
- 管理层预测能与历史兑现、合同、产能和市场边界比较。

只有两三年粗财务且上述条件不足时，DCF 用于情景或交叉检查，不用长预测和精确终值制造单点价值。
经营改善和 IPO 情景的经营输入来自用户、管理层预算、已有经营分析或明确设置的情境；本 Skill 检查一致性并完成价值转换，不在缺少依据时另行编造完整经营预测。

## 六、把当前价值与 IPO 上行情景分开

使用三层价值阶梯，不机械平均：

1. **当前独立经营价值**：只使用估值时点已经形成并可核验的经营能力、资产负债和规范化指标。
2. **经营改善上行情景**：加入能够由订单、产能、客户、产品、利润率或组织改造支持的增量，并写出兑现时间和资金需求。
3. **IPO 情景价值**：在达到收入、盈利、规范治理、审计和资本市场条件的假设下，计算未来时点可能支持的公开市场价值。

IPO 情景至少建立以下桥：

`当前经营状态 → 关键经营里程碑 → IPO 年度规范化指标 → 同阶段上市可比倍数 → IPO 时点企业或股权价值 → 上市前融资与稀释 → 当前股东届时权益 → 时间折现或目标回报检查`

可使用：

`IPO 时点企业价值 = IPO 年度规范化指标 × IPO 情景倍数`

`IPO 时点普通股价值 = IPO 时点企业价值 - IPO 时点净债务及债务类项目 - 优先权 + 可用现金及非经营资产`

`当前持股情景价值 = IPO 时点普通股价值 × 当前股东届时持股比例 ÷ (1 + 情景回报率)^年数`

情景回报率是投资者视角参数，不冒充客观资本成本。若加入上市成功概率，必须同时保留未加权情景和未上市或延迟情景，概率只作为显式假设。

所谓“IPO 故事”最终应落为可观察的价值驱动：收入规模与质量、可持续利润、现金转换、客户集中度、合规与审计、治理、资金用途、后续融资及可比公司位置。上行情景可以高于当前基准，但报告必须并列展示两者及价值差来自哪些里程碑。

## 七、从企业价值到股权价值和交易价格

建立：

`企业价值 - 有息债务及债务类项目 + 可用超额现金 + 非经营资产 - 非经营负债 - 优先权与少数权益 = 普通股股权价值`

并购采用交割调整时，再建立：

`交割权益对价 = 普通股股权价值 ± 实际营运资本相对正常基准的调整 ± 其他已确认交割调整`

- 并购交易另列交割现金、债务、正常营运资本、或有对价、滚存股权和协同，不把协同价值自动归给卖方。
- 股权融资另列融资前估值、新资金、融资后估值、证券权利及完全摊薄持股比例。
- 缺少净债务或优先权资料时，可以交企业价值区间，但不能直接给普通股价值。

## 八、情景、敏感性和结果表达

至少对以下变量中的真正翻转项做敏感性：

`规范化收入或 EBITDA｜倍数｜毛利或利润率｜订单兑现｜营运资本｜资本开支｜上市时间｜后续融资｜稀释｜退出倍数`

结论表建议使用：

`价值层级｜估值时点｜方法｜经营指标区间｜倍数/折现参数｜企业价值｜股权价值｜当前股东价值｜关键里程碑｜判断状态`

结论使用 `成立｜条件成立｜不成立｜暂不判断`。每项先写方向明确的命题。核心摘要并列展示当前独立经营价值、经营上行情景和 IPO 情景，说明价值差来自哪些经营与资本条件。
