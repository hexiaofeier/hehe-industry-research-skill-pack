# 估值分析交付模板

## 一、交付载体

除非用户明确要求不落文件，否则必须生成可编辑 Markdown 主报告。根据任务是否包含实际计算，交付组合如下：

| 任务情况 | 默认交付 |
|---|---|
| 方法适用性、口径或少量已给结果核对，不含实际估值计算 | Markdown 估值卡 |
| 完整公司、有限披露或专项估值，包含价值计算、情景区间、敏感性或反向估值 | Markdown 主报告＋带公式的 `.xlsx` 估值模型 |
| 非上市企业商业尽调估值 | Markdown 主报告＋带公式的 `.xlsx` 估值模型；并列呈现当前独立经营价值、经营改善上行情景和条件化 IPO 情景 |
| 复核用户已有模型 | Markdown 复核报告；需要修正且用户要求时，另交独立修正版模型，保留原文件 |

用户明确不要 Excel 时，仍交付 Markdown，并在正文保留可复核的输入、公式、计算过程和结果；工作簿专属检查记为不适用。用户明确不落文件时，在对话中按第二节结构交付。

Excel 可使用当前环境中任何能够写入公式、保存并重算 `.xlsx` 的库、应用或 Skill，不限定具体产品。任务已经触发估值模型、但当前环境没有这类能力时，仍完成 Markdown、输入、公式、情景和计算结果，并在交付清单中把工作簿标为“待生成”；这属于部分交付，不能把未生成、未重算的文件称为已完成估值模型。

## 二、Markdown 主报告

### 完整度与展开要求

先确定输出模式：

- **完整专项报告：** 用户要求完整、深度或系统研究，或者本专项被纳入 `hehe-industry-researcher` 的完整研究时使用。必须覆盖本模板列出的适用主体章节。
- **局部专项答复：** 只在用户明确询问一个局部问题或明确要求简版时使用，只展开与该问题直接相关的章节。
- **有限披露报告：** 只在关键资料确实不足时使用；仍需充分分析现有证据能够支持的内容，不能只交缺口清单。

完整报告的核心主体章节不能只有标题、事实清单、新闻罗列或一张没有解释的表。每项主要结论应有相称的证据或计算，并解释关键机制、差异及其含义；成立条件或翻转点按其对判断的实际影响展开。表格之后解释最重要的差异和意义。

**读者导向的写作与删减**

- 正文围绕结论、证据、推理及其含义展开。删掉后不影响读者理解和判断的解释，直接删除。
- 会改变结论的口径、假设、条件和风险融入相应判断；同一事项集中说明一次，保留原有判断强度。
- 内部审核、资料取舍和研究执行过程留在底稿；正文只呈现其对结论的实质影响。
- 摘要、标题、正文、表格、图注及图内脚注统一执行；任何篇幅下均适用，不为字数目标补回无效解释。

**完整模式正文目标体量：** 完整、有限披露或非上市商业尽调估值一般为 7,000—13,000 汉字；只核对方法或少量结果的估值卡一般为 2,000—3,000 汉字。 这是完整度检查线，不是写作配额；交付前必须实际统计正文字符数并记录结果。统计只包括推进本题结论的分析；来源清单、原文摘录、附录长表、方法或交付说明、验收记录、通用边界和更新流程不计入，也不得跨专项复制或批量套用同一句式后只替换变量。低于下限时先逐项复查并补足被压缩的核心能力；实质分析已经完整且差距不超过下限 10% 时，可记录偏差后交付，不得为贴线补字。差距超过 10% 且不属于局部或有限披露模式时，不得作为完整专项报告交付。超过上限时检查重复结论和同义改写。


估值卡保留核心摘要、研究范围、方法判断、关键输入、结果或暂不计算原因、主要限制和下一步。完整估值报告按以下顺序展开：

1. **核心摘要**：一句话说明估值对象、主要方法和价值结论，再列价值区间、当前价格或交易条件的关系、关键参数、翻转变量和主要限制。
2. **研究范围与估值口径**：估值对象或证券、合并/分部边界、企业价值/股权价值/资产价值、权利层级、估值时点、财务和情景期、币种、股数及决策用途。
3. **估值资料与假设**：列资料来源、审核状态、事实/分析调整/情境/待核实分层及数据时点。
4. **方法选择与适用性**：列主方法、交叉检查、有限参考和不适用方法及理由。
5. **规范化指标与调整桥**：从报告值桥接到估值输入，说明一次性、会计、分部和其他调整。
6. **企业价值—股权价值—每股或每单位价值桥**：处理债务、现金、优先权、少数股东、非经营项目、稀释和股数。
7. **各方法计算**：给出公式、关键参数、数据来源、计算过程和结果。
8. **情景与价值区间**：列基准、上行、下行情景，说明经营输入、资本投入、融资/稀释、估值参数、价值结果及触发条件。
9. **敏感性、翻转变量与压力测试**：说明取值依据、结果响应、翻转点和违反业务或数学约束的组合。
10. **交叉检查与方法差异**：解释结果差异、不可比项及是否使用权重。
11. **当前价格、交易条件与隐含要求**：将市场价格/对价、模型价值、隐含经营要求和研究预期差分开。
12. **综合结论与后续**：给出条件化结论、关键限制、反例、观察信号和可复用结果。
13. **其他说明、附录与待补证内容（按需）**：放无法归入正文的口径说明、详细公式、来源定位、材料限制和补证任务。

非上市商业尽调仍使用上述十三节。第 5 节呈现最低可用估值财务和规范化桥；第 7—10 节完成市场法、适用时的 DCF、三层价值情景和方法交叉检查；第 11 节分开当前交易条件与 IPO 情景的隐含要求。核心摘要并列展示当前独立经营价值、经营改善上行情景和条件化 IPO 情景，并说明价值差来自哪些里程碑、资金、稀释和时间条件。具体方法读取 [非上市企业商业尽调估值](非上市企业商业尽调估值.md)。

每项判断先写清方向明确的命题，再使用 `成立｜条件成立｜不成立｜暂不判断`。例如：`当前价格隐含的收入增长处于已验证经营边界内｜不成立`。价值输出优先为区间；若任务必须呈现中点或单一情境值，必须同时保留区间、假设和用途，不能伪装成确定目标价。

可供后续任务使用：

`对象/时点｜价值口径｜方法与适用性｜关键输入｜调整桥｜情景价值区间｜敏感性/翻转点｜当前价格/交易条件｜隐含要求｜判断状态｜限制｜不可回写项`

## 三、其他交付物

### Excel 估值模型

实际估值计算、情景区间、敏感性或反向估值触发带公式工作簿。工作簿按[估值方法、公式与工作底表](估值方法、公式与工作底表.md)使用七表结构：

`00_设置与输入｜01_规范化与调整｜02_可比与交易｜03_DCF｜04_SOTP_资产_里程碑｜05_价值桥与敏感性｜06_结论与交接`

按任务保留适用工作表和区块，但至少覆盖输入与假设、规范化调整、实际采用的方法、EV—权益桥、情景与敏感性、交叉检查、数据来源、计算过程和限制。不适用方法在方法选择表说明理由，无须建立空计算页。

| 其他触发条件 | 交付物 | 最低内容 |
|---|---|---|
| 只需交换一张可比对象、交易或输入长表，且没有公式 | `.csv` | 对象、日期、价值和财务口径、币种、来源、状态、可比理由和限制 |
| 用户明确要求单独估值图或展示版 | 可编辑图源及展示文件 | 数值、情景、区间、时点和口径与报告及模型一致 |
| 没有独立数据交换或展示需要 | 不生成其他附件 | Markdown 与适用的 Excel 构成完整交付 |

CSV 和截图不能代替需要公式的估值模型。

## 四、保存与命名

- 保存位置按[专项工作流程](专项工作流程.md)：有路由时使用任务卡指定位置；单独启动时默认保存到当前任务工作文件夹；用户指定位置时按其要求保存。
- 主报告：`YYYYMMDD_研究主题_估值分析.md`。
- 估值模型：`YYYYMMDD_研究主题_估值分析模型.xlsx`。
- 其他附件：`YYYYMMDD_研究主题_估值分析_附件名称.扩展名`。
- 研究主题写清公司、分部、项目、资产、证券或具体交易；版本号按需添加。用户或项目另有命名规范时优先遵守。

## 五、信息缺口

只有缺口可能改变方法选择、主要输入、价值口径或价值区间时才发起补证：

`待证主张｜缺失字段｜对象/证券/期间/币种｜优先原文类型｜建议检索方向｜本次用途｜缺失时如何降级｜授权或付费边界`

市场价格、可比公司、交易、利率和资本结构数据都有时点性，补证时保留估值时点。缺口未解决时，改用宽区间、有限参考或暂不计算，只限制受影响的方法和结果。

## 六、交付条件与交付前检查

研究结束或暂停受影响判断的依据记入交付检查；正文说明影响结论的未解决事项。

估值对象、口径、时点和方法已经确认，主要输入有来源或明确情境，价值桥可追溯，适用的情景、敏感性和交叉检查已完成，新增一般材料不会改变方法和主要区间时即可交付。交付前检查：

- 核心摘要先给价值结论、关键条件和限制，研究范围单独成节；
- 企业价值、股权价值、控制权价值、资产价值和证券权利层级没有混用；
- 历史、LTM、预测、情境、价格日、币种、股数和分子分母匹配；
- 规范化、净债务、优先权、稀释、少数股东和非经营项目均有调整桥；
- 情景、敏感性、终值、折现率和翻转点有依据，方法差异未被机械平均；
- 当前价格、模型价值、隐含要求和投资判断分开；
- 实际生成工作簿时，输入、公式和输出分开，已完成重算、代表性输入联动、保存后重开及关键结果回读；
- 实际生成模型时，报告与模型的数值、口径、结论、文件名称和相对链接一致。

## 七、其他注意事项与专项要求

本 Skill 负责可直接阅读的估值 Markdown 主报告、估值模型、公式和计算审计。PPT、品牌化视觉版和跨专项公司或投资综合报告不属于默认交付；呈现加工不得改变分析结构、公式、数值、情景或精度。
