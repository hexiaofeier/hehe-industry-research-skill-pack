## 6. 重复解释与共同原因

| 检查组 | 表面上的多个驱动 | 共同原因/重复中介 | 是否有独立增量 | 处理方式 | 不能合并的差异 | 对结论影响 |
|---|---|---|---|---|---|---|
| R01 | | | | 合并/保留多路径/组合驱动/暂不拆分 | | |

重点检查：

- 政策发布、融资增加、企业扩产和产品发布是否都来自同一政策/资本窗口；
- 搜索、讨论、媒体数量和产品数量是否只是同一热度的多个代理；
- 收入、订单、出货和回款是否处在同一经营链的不同端点；
- 总额、增速和份额是否混入价格、结构、并购、汇率和口径变化。
