# 行业驱动力分析工作流程

本文件与同目录的 `SKILL.md` 配套，说明本专项从启动到交付的两条路径。分析方法和专项验收仍以主 Skill 为准。

## 1. 选择启动路径

- **由 `hehe-industry-researcher` 调用：** 收到任务卡和材料索引后直接执行，不重新启动路由或开题。
- **用户直接调用本 Skill：** 本 Skill 独立确认问题和范围并执行，不把 `hehe-industry-researcher` 或其他 Skill 作为启动条件。

## 2. 接任务或确认范围

- **由路由调用：** 先读任务卡中的研究范围、专项问题、已有材料、待补字段和预期交付，再按材料索引读取原文。已经说明的信息不重复询问；仍有会改变分析结果的歧义时，交回路由补充确认。
- **单独启动：** 先读取用户描述和已有材料，在对话中确认会影响结果的对象与范围。用户已经说明的内容不重复询问；Agent 的推断不能冒充用户确认，不要求另外制作开题文件。

无论从哪条路径进入，都要在分析过程中确认：

`行业对象｜目标结果｜变化指标/表现｜地域｜观察期｜比较基准｜判断截止日｜核心分群`

这些是 Agent 需要查清的归因范围，不是要求用户完整提供的输入。只有行业边界或要解释的结果存在重大歧义时才向用户追问。

目标结果必须可观察、可对齐，例如：

- 需求、采用、采购、销量、使用或续费；
- 价格、折扣、客单、费率或价值口径；
- 供给、产能、交期、库存或交付能力；
- 行业经营收入、成本、利润、现金或资本占用；
- 节点权力、价值分配、进入退出、集中度或竞争结构。

“行业发展”“政策利好”“技术进步”不是合格结果。若行业边界、目标结果、基准或时间暂不清楚，先提出暂定口径；只有不同口径会明显改变归因时才向用户确认。

已审核材料或已有分析结果应保留原限制；待补证和拒绝使用材料不支撑核心路径。

## 信息搜索

### 组合模式

读取调用方 `hehe-industry-researcher` 的 `references/信息搜索流程.md`，沿用任务卡、材料索引及审核记录，发现缺口再定向补搜，完成后继续本专项分析。

### 独立模式

先查看用户已有材料；没有材料就搜索，有材料时确认是否需要补搜。已确认的搜索安排不重复询问；用户明确不联网时，只分析现有材料。

1. **设计关键词。** 根据上文所列资料需求，有 `sou-cha-ling`（搜查令 Skill）就调用对应专项的行业或企业关键词组件；没有则自行组合对象名称、业务/指标、地域和时间，并扩展中英文名、简称、旧称、同义词及上下位概念。
2. **选择搜索能力。** 检查当前实际可调用的能力，按下表选择；示例包括但不限于所列工具，不要求全部使用。

| 能力 | 示例 | 用法 |
|---|---|---|
| 网页搜索与浏览 | Web Search、WebFetch、内置或已连接浏览器 | 广泛发现来源，再打开具体页面读原文 |
| 信息采集 Skill | `tanzi`、`last30days`、`agent-reach` 等 | 跨平台、批量或社区采集；读取已安装 Skill 的用法后调用 |
| 搜索与数据 MCP/API | Exa、Tavily、Serper 或其他已连接服务 | 补充垂直搜索与结构化数据；付费、登录按用户授权使用 |
| 原始网站与专业数据库 | 政府统计、监管/交易所、公司官网、招投标、行业数据库 | 直接取得数据、披露、政策、交易与执行记录 |
| 学术论文与预印本 | arXiv 网站或 API | 涉及学术概念、算法、AI 模型或前沿技术时必查；保留标题、作者、摘要、日期和链接，核读关键论文 |
| 网页与文件提取 | URL 正文提取、PDF/Office 解析、OCR | 已知网址或文件时直接读取正文、表格和附件 |

3. **找回原文。** 围绕目标行业结果、候选原因、时滞、反例和替代解释发现线索，再打开原文；优先官方、监管、财报、统计、标准或论文等一手材料，搜索摘要只作线索。
4. **补齐缺口并留来源。** 一个渠道覆盖不足或调用失败时换其他可用能力，不让所有工具重复同一查询。保留标题、来源、日期、链接或文件位置、关键摘录及未取得的材料；按本专项原有交付规则整理进材料表或分析底稿。

### 材料审核与自检

有 `baojie`（保洁 Skill）时调用它；不可用时至少核对原文、主体、时间、地域、目标结果与指标定义、单位与分母、重复和冲突，并在交付前自检核心问题覆盖、因果链断层、共同原因、反事实和最强替代解释。证据不足时降低结论强度，不把相关性写成驱动力。

## 4. 分析与自审

按主 Skill 的分析方法完成任务，不要求先调用其他专项 Skill。发现关键缺口时先补证；暂时无法解决时，只降低或暂停受影响的判断，其余可确认部分继续。

提交前按主 Skill 的验收要求自审，至少检查研究范围、材料来源、时间、定义口径、单位或分母、重复、冲突、不确定性、反例和不可外推范围。

## 5. 交付与返修

按 [行业驱动力分析交付模板](行业驱动力分析交付模板.md) 的输出结构、载体和文件命名规则交付。

- **由路由调用：** 保存到任务卡指定的 `02_专项分析/` 或项目对应位置；交回实际文件清单、使用及新增材料、未解决问题。`hehe-industry-researcher` 二次审核后如退回，修正受影响部分并再次自审后提交。
- **单独启动：** 自审后直接交付，默认保存到当前任务工作文件夹；用户指定位置时按其要求保存，不等待路由审核。

用户明确不落文件时，在对话中完成专项交付。单独专项只回答本专项问题，不自行扩成完整行业或企业报告。
