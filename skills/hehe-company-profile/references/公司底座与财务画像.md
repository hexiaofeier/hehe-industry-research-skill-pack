# 公司底座与财务画像

本参考用于完整经营画像中的公司底座和基础财务画像。只读取与当前研究问题有关的部分，不把字段清单机械写满。

## 一、公司底座

| 维度 | 需要查清的内容 | 保留标准 |
|---|---|---|
| 创始人与核心成员 | 创始人、实际控制人、董事长、CEO及关键业务负责人；任期、职责、重要变动 | 只保留影响控制权、核心业务、战略或经营结果的人物事实 |
| 企业发展历程 | 创立、业务转型、关键产品、重大扩张、收缩、危机及里程碑 | 说明节点如何塑造当前业务，不写流水账 |
| 母子公司结构 | 控股集团、上市主体、核心子公司、品牌和业务分部之间的控制或经营关系 | 优先呈现影响合并范围、收入归属、资源调度或风险隔离的关系 |
| 组织与团队 | 主要业务组织、区域组织、关键团队、员工数量及结构变化 | 说明组织是否匹配业务，不凭组织名称推断能力 |
| 投融资与股东 | 主要融资轮次、上市及再融资、控制权变化、主要股东和重要投资者 | 融资额、估值、持股比例和公司经营结果分开 |
| 并购与重组 | 重要收购、出售、分拆、重组和关停，以及对应业务与财务影响 | 只保留改变业务边界、资产结构或战略方向的事项 |
| 经营地域与关键资产 | 总部、主要市场、生产或研发基地、牌照、产能及关键设施 | 说明资产对交付、成本、合规或扩张的作用 |
| 重大争议与失败 | 重大诉讼、处罚、产品事故、减值、失败项目和退出 | 只纳入可能改变公司判断的事项，并保留状态和公司回应 |

人物经历、历史故事、子公司名单或股东名单本身不是结论。最终要说明这些事实如何影响控制权、业务形成、组织能力、资本来源、战略执行或风险。

## 二、关键经营关系

| 关系 | 需要回答 | 判断边界 |
|---|---|---|
| 客户 | 谁购买或付费；前五大和最大客户占比；重要客户涉及什么业务；集中度如何变化 | 集团集中度不能代替分部集中度；合同、中标和案例不能直接算收入 |
| 供应商 | 采购什么关键原料、部件或服务；集中度、单一来源、交期、价格和替代能力如何 | “建立多元供应链”等公司措施属于自述，需用缺货、涨价、库存、交付或停产结果验证 |
| 合作伙伴 | 对方承担技术、生产、渠道、内容、品牌、资金或交付中的什么角色；合作进展到哪一步 | 签约或联合发布不等于收入、利润或长期协同；只保留与经营有关的伙伴 |
| 竞争对手 | 每项核心业务与谁争夺同类客户、预算、渠道或使用场景；主要替代方案是什么 | 公司画像只列主要对手和竞争原因，不完成行业玩家全表、份额排名或完整横向比较 |

对象名称、交易金额或集中度未披露时写明缺口，不根据客户案例、供应商传闻、合作新闻或常识补造。关系判断最终要落到收入稳定、成本与交付、产品能力、渠道触达、议价权或经营风险。

完整经营画像应分别呈现四张清单：

1. 客户清单：既列具名重要客户，也列未披露的前五大客户、主要客户类型及集中度；不要把终端用户、经销商、广告主和合作伙伴混成同一种客户。
2. 供应商清单：同时列具名关键供应商和未披露的关键供应类别；采购稳定性必须结合替代能力、价格、交期、中断和库存判断。
3. 合作伙伴清单：逐一说明伙伴名称、承担角色、合作进展和经营意义；同一对象兼具供应商、客户或股东身份时分别写明。
4. 主要竞争对手清单：按核心业务列出最直接的对手和替代者；资料不足的业务保留待补行，不用常识补齐名单。

## 三、基础财务画像

公司画像中的三表分析用于判断经营质量，不替代完整财务专项。优先使用近 3—5 年可比数据；只有季度或有限披露时，按实际期间分析并说明限制。

### 1. 核心数据表

按适用情况选取：

`收入及分部收入｜毛利及毛利率｜经营利润及利润率｜净利润及净利率｜研发/销售/管理费用｜经营现金流｜资本开支｜简化自由现金流｜现金及短期投资｜应收｜存货｜固定资产/在建工程｜商誉及无形资产｜有息债务｜应付及合同负债`

不要求为凑表格加入不适用指标。至少保留期间、主体或分部、币种与单位、数据来源和可比性说明。

### 2. 三表分别回答什么

- **利润表：** 增长和利润变化来自哪些业务、量价、结构、费用、并购或一次性项目，是否可持续。
- **资产负债表：** 增长占用了多少应收、存货、产能和资本，现金与债务能否支撑继续经营。
- **现金流量表：** 利润是否转成现金，现金主要用于经营投入、资本开支、投资并购、偿债、分红还是回购。

### 3. 至少检查的联动关系

- 收入和利润变化能否与应收、存货、应付及经营现金流相互解释；
- 资本开支能否与固定资产、在建工程、折旧及产能变化相互解释；
- 并购和投资能否与现金流、商誉、无形资产、少数股东或减值相互解释；
- 融资、偿债、分红和回购能否与现金、债务和权益变化相互解释。

明显背离时提出经营原因、会计或口径原因及其他可能解释，不凭单一指标下结论。

### 4. 输出深度

基础财务画像最终回答六项：增长质量、盈利质量、现金质量、投入质量、资产负债结构和财务韧性。通常使用一张核心数据表、必要的分部或变化表和简洁解释即可，不机械罗列比率。

需要标准化与勾稽三表、详细科目拆解、完整比率体系、资本效率深算、预测情景或公式工作簿，且当前可用 `hehe-financial-analysis` 时，由其完成；已有结果时直接吸收已确认结论。该专项不可用时仍完成基础财务画像，不在公司画像中另建深度模型。

## 四、有限披露

非上市公司或资料不足时，只使用可核对的收入、毛利、订单、回款、融资、负债、员工、纳税、采购或其他代理信号。明确哪些三表项目无法判断，不用融资额、估值、GMV、合同额或员工数补造成完整收入、利润或现金流。
